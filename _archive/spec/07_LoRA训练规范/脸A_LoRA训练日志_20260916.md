### 0.4 对照实验 —— **病根已锁定：预量化 fp8 基模**

同数据（`ai-toolkit\datasets\wuyin_face_lora\5_wuyin`，88 图 + 88 标注）、同 200 步、同 seed。
**实测速度约 11 秒/步**（旧文档"1.5–2 it/s"是错的，慢一个数量级）→ 单组约 38 分钟。

| 组 | 基模 | 参数 | 结果 |
|---|---|---|---|
| **A** | `flux1-dev-fp8.safetensors`（预量化） | dim32/alpha16/lr2e-4 | **失败**，见下 |
| **C** | `D:\HF_CACHE\FLUX.1-dev`（bf16 diffusers） | 同 A | **loss 2.73 起步**（A 是 6.34） |

#### A 的三步定性（全部有硬证据）

1. **复现了旧失败**。A 的 LoRA 出图 = 满屏均匀彩噪，与 `wuyin_face_v1/comparison/step200` 一模一样。
2. **链路本身没问题**。同一工作流**无 LoRA** → 干净汉服人像；挂**已知可用的 RealSkin LoRA** → 也干净。
   → ComfyUI、工作流、基模文件在推理侧都是好的。
3. **不是"权重太烫"**。强度扫描：0.2 正常、0.5 严重劣化、0.7 近摧毁、0.9/1.0 纯噪声，
   **可用区间 ≤0.2 ≈ 不可用**。但权重统计反而**最小**：

   | LoRA | mean\|w\| | max\|w\| | 能用 |
   |---|---|---|---|
   | A（坏） | **0.0019** | 0.535 | 爆炸 |
   | RealSkin | 0.0034 | 0.348 | 正常 |
   | Hanfu_Elegant | **0.0232** | 2.92 | 正常 |

   Hanfu_Elegant 权重比 A 大 12 倍却在强度 1.0 下正常 → **幅度不是原因**。

#### 真正的判据：loss 不降

A 的 avr_loss **卡在 5.5 左右几乎不降**（6.34 → 5.47 / 200 步）。
FLUX 正常训练 loss 应降到 **0.1~1.0** 量级。

**坏目标函数 + 权重数值正常 + 用起来爆炸** = 训练时的基模本身就是坏的。

#### 根因

`flux1-dev-fp8.safetensors` 是**预量化**的 fp8 单文件（ComfyUI 生态用法）。
而 `fp8_base_unet = true` 的正确语义是「**让 sd-scripts 把 bf16 模型自己量化成 fp8** 来省显存」。
两者叠在一起 = **二次量化**，得到的基模是坏的，LoRA 学的是对坏基模的补偿
→ 推理时挂到正常基模上，直接把残差流打爆。

#### 最终验证：C 的 LoRA 在强度 1.0 下完全正常

| 出图条件 | 高频能量 | 结果 |
|---|---|---|
| 基线（无 LoRA） | 6.56 | 干净 |
| A（fp8 基模）s=0.6 | 29.51 | 摧毁 |
| A（fp8 基模）s=1.0 | 29.28 | 纯噪声 |
| **C（bf16 基模）s=0.6** | **5.88** | **干净，且 LoRA 明显生效** |
| **C（bf16 基模）s=1.0** | **7.78** | **干净** |

同数据、同参数、同步数、同 seed，**唯一变量是基模**。A 崩、C 好 → 因果确认。
（高频能量＝相邻像素差均值，越低越正常；噪声图会飙到 25+。）

#### 这一条推翻了什么

之前记录的「wuyin face LoRA 过拟合全噪」**彻底错误**。真相是：
**基模配错导致训练目标失效**。补再多数据、调再多学习率都不会有用——
这也再次印证了「先查病根再补数据」的顺序是对的。

**可复用的硬判据（下一次训练直接用）：**
1. **训练 loss 卡在 5 以上不降 = 基模或目标函数坏了**，不是数据问题。正常 FLUX 应降到 0.1~1.0。
2. **LoRA 出图噪声时先做三连对照**：不挂 LoRA / 挂已知好 LoRA / 挂被测 LoRA。
   前两个正常 → 问题在被测 LoRA 或它的训练配置，不在推理链路。
3. **不要用 `flux1-dev-fp8.safetensors` + `fp8_base_unet=true` 训练**。
   正确组合：bf16 基模（`D:\HF_CACHE\FLUX.1-dev` 的 diffusers 目录）+ `fp8_base_unet=true`。

配置文件：`training\configs\diag_A_old_params.toml` / `diag_C_bf16_base.toml`
（原计划的 B「新参数+f8」已作废——既然病根是基模，换参数测不出东西）
体检工具：`training\tools\inspect_lora.py`
