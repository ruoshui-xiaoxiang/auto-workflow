## 2. 分类判据（一条主判据 + 三条辅助测试）

**主判据（沿用你自己定的那句）**：
> 这句话能不能从一个**没看过我们片子的人**嘴里说出来？
> 能 → 通用层。不能 → 项目层。

三个可操作的辅助测试，用于主判据判不动的边界情况：

| 测试 | 做法 | 判读 |
|---|---|---|
| **T1 名词剥离** | 删掉角色名／道具名／画风名／项目代号／镜号，看规则是否仍完整可执行 | 仍完整＝通用；残缺＝项目，**并把剥离出来的那一坨登记成通用规则上标注的"填充槽"** |
| **T2 换项目是否需重做** | 问"新项目要不要重新实测/重新设计才能用这条" | 要＝项目层；只是换个参数值＝通用层带槽 |
| **T3 是否被机器写死** | 值出现在 `config.yaml`／yaml 默认值／`prompt_rules.py` 词表里 | 属项目层，**且额外标 ⚠「机器侧仍按上一个项目写死」**——这是风险登记，不是分类 |

⚠ **T1 的关键推论**：通用层不是"删掉项目内容剩下的东西"，而是**带着空槽的规则**。
例：通用层写「道具锁必须带**尺度**与**封口描述**」（机制：H07 镜内那根杆被重解释成一颗缠布子弹，因为杆尖朝镜头+手部特写导致尺度线索消失）；

**换项目带走的是槽里的值，不是规则本身。**

## 4. 项目层统一表格式（每条规则一行，五+三字段）

沿用 `prompt_rules.py` 的 `id/src/say/bad/fix`，追加 `上位/关系/失效条件`：

| 字段 | 含义 | 例（武昭君仪 · 法条 R1） |
|---|---|---|
| `id` | 项目内编号，前缀项目代号 | `WZJY-R1` |
| `say` | 这条规则要求什么 | 提示词一律不出现「矛头／金属／刃」，不写免责句 |
| `bad` | 字面禁词 | 矛头/金属/铁杆/刃口/露刃/见刃/刃 |
| `fix` | 替身写法 | 只描述看得见的布；里面藏了什么一个字都不提 |
| `src` | **可回溯出处（文件:行）** | `武昭君仪_剧本与资产盘点_v1.md:86` |
| `上位` | 通用层哪一条 | `G3-R5 正向物理描述＝判据`；`G4-槽1 道具锁必须带尺度` |
| `关系` | **补充 / 收窄 / 例外 / 冲突** 四选一 | **收窄**（把"描述看得见的材质"收窄到"只许写布"） |
| `失效条件` | 换什么项目就不成立 | 若新项目道具本身是金属外露兵器，本条整条不适用（改走 `G4-槽1` 的通用写法） |

**四种关系的定义（要统一，否则两人理解不同）**：
- **补充**：通用层没规定，项目层新增。例：仙女星系「设定_帝国与联邦」里的舰桥尺度口径。
- **收窄**：通用层给了范围，项目层选一个更严的子集。例：通用允许"正向描述材质"，武昭君仪禁到"只许写布"。
- **例外**：通用层有规则，本项目**反向**成立，且必须给实测理由。例：通用「视频首帧一律走云端 Seedream」，无音早期项目部分首帧是本地 FLUX 出的（09-24 之前的历史片）。
- **冲突**：两层说法不一致**且未裁**。⇒ 冲突项不许留在表里当规则用，一律进 `R_作用域与例外登记表.md` 的待裁队列，并在正文里显式标 ⚠。

## 5. 关键设计决定：通用层是"视图"还是"新真源"（**已裁：新真源**）

~~原推荐"视图"~~ → **用户 2026-09-27 裁定：通用层当新真源，上游降级为存档。**

选新真源后，通用层必须**能独立站住**（自足到"不翻上游也知道该怎么做"），因此每条规则要比"视图"写法承载更多内容：
判据/公式 + 出处 + **机器执行者** + **项目填充槽** + 实测反例。代价是通用层 9 篇的写作量比视图方案大得多，
且 §0 那三条强制约束不可省（否则与机器闸分叉）。

原「视图方案的机器校验」仍然要做，且升级为**双向校验**（见 §0 第三条）：
`99_维护\check_layers.py` 做四件事，全部只报不拦：
1. **指针有效性**：通用层每条 `出处:` 指向的文件+锚点是否还存在、是否被改名（防漂移）；
2. **名词剥离自检（T1 自动化）**：扫通用层 9 个文件，命中角色名/项目代号/具体道具名即报 ⚠ → 保证通用层真的干净；
3. **反向索引完备性**：项目层每条 `上位:` 指向的通用条是否存在；通用层 `R_作用域与例外登记表` 是否登记了对应项目条（双向都缺就报）；
4. **冲突项清点**：`关系=冲突` 的条目列成待裁清单，数量必须等于登记表里的未裁项数。

⇒ 这样通用层坏了能立刻发现，而不是等你按旧规则跑废一批才察觉。
