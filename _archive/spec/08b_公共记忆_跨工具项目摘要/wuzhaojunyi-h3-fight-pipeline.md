## 工作流详情

### 1. 本地 H3 打斗管线（免费主路径）

- **8 步 Turbo 正确用法**：LoRA 链序 = `底模 → Turbo(1.0) → 内容LoRA(Bunny 0.5) → Attention`。FL2VA 路线才是 8 步（`minimax_h3_fl2v_turbo_8step_v1.0` @1.0，dual_clock_euler/native_flow）；Ref2VA 官方 turbo 是 **4 步**（`ref2v_turbo_4step` @1.0）。**「8步+shift6:3 的 Ref2VA」是非官方组合，曾致双重脸**。
- 落地：`tasks.py` 的 `fight_fast8` profile（≈82s/镜，比 20 步快 2.07×，画质基本持平）。
- 帧网格：124 / 175 / 192 / 209 / 243 / 362 帧（≈5.2 / 7.3 / 8 / 8.7 / 10.1 / 15.1 秒）。736×416 低分辨率下 362 帧 16GB 扛得住；1344×768 高分辨率下 192 帧即 HostBuffer 失败。

### 2. 三阶打斗多镜打包驱动（fight_multishot.py）

- 12 镜链式：提交 → 轮询 → **抓末帧 → 作下一镜首帧** → 全部 concat。
- 三阶结构：P1 空手八极（力量吃亏）→ P2 裹布棍法 → P3 解布裸枪法（枪杆弯曲借力、压杆崩弹）。每阶段 4 镜 × 4 动作 = 48 动作。
- 踩坑：`cv2.imwrite` 写不了中文路径 → 用 `cv2.imencode('.png', fr)[1].tofile()`；末帧目录要先 `mkdir(parents=True)`。
- **末帧接力会吃掉起势**：下一镜开头动作无起手，解法 = 【Motion】连续性句 + 时间戳前移（见规则 R17 与经验）。

### 3. 首帧锁站位 + 换脸 + 超分（人物一致性三件套）

- **方位靠首帧图（视觉）锁，不靠文字**：纯文字控制不住「正前方 vs 背后」，fl2va 单首帧硬锚后 H3 从正确方位出发。
- **换脸**：H3 特定人脸保持上限 ≈0.57，到不了 0.6「同一人」阈值。用 inswapper_128 逐帧换脸到目标脸（`junyi_face_real.png` 写实脸锚），相似度 **0.57 → 0.70~0.84**，是唯一能锁脸到 0.7+ 的手段。
- **超分**：`4x-UltraSharp.pth` 逐帧超分（ComfyUI 内嵌 python + spandrel 推理），4x 后 lanczos 缩回 2x。

### 4. 万相 3.0 云端接入（便宜、视觉强、但跨镜漂）

### 6. 线稿主体库方案（本次新增，跨镜一致性根治）

> 起因：用户反馈旧 8 镜「人物没锁住」。ArcFace 实测 8 镜 vs 参考 **sim 全部 0.05-0.24**（正常锁定应 ≥0.5），且 P2B 两人性别互换、P1D 君仪画成戴剑重甲男、P2A 混混画成西方络腮胡男。根因：可灵 Element 绑定锁的是「风格/主题」（机械臂大致在、亚洲人在），**不锁「脸几何」**；每镜 prompt 只写「<混混>在右侧」没规定脸，模型自由发挥。

**方案（用户提出）：把参考图转成线稿当结构锚点**，模型只锁身形/发型/服装/武器轮廓，脸交给模型自由发挥。

流程：
```
角色三视图（照片）→ 可灵转线稿（omni3 + image_to_image，1 灵感值/张）
→ 线稿作 cover+secondary 建 Element（角色/道具标签）
→ kling_batch_lineart.py：线稿 Element + 场景参考图 + KEEP 约束句 → 12 镜机位首帧
```

- **转线稿提示词要点**：`clean black ink line drawing on pure white background, manga sketch style, no color, no shading, no gradient, no grayscale fill — only clean black outlines`，并明写「face rendered as simple minimal oval with two dots for eyes and a thin line for mouth, do NOT draw detailed facial features」。
- **KEEP 约束句**（喂给后续出图）：`严格保留所有人物的身形轮廓、服装、发型、武器位置与比例，仅在轮廓内填色、赋材质、加光影，不要改变线稿定义的人物数量、位置、姿势、武器位置和朝向。`
- 产出：`首帧图/线稿素材/`（jy_line_front/side/back、hh_line_front/side/back、qiang_wrapped、qiang_bare）、3 个新 Element（`武君仪线稿` 322414104237101 / `粗臂男线稿` 322414122246869 / `白麻布长枪线稿` 322414162230524）、12 镜首帧 `首帧图/线稿机位图/`。
- **效果**：无角色互换、君仪不再被画成男性、机械臂结构跨 4 镜一致、体型/服装基调统一、枪四态（背/裹布横持/裸枪斜指/弯杆蓄力）全锁、P3C 弯杆崩弹演出来了。
- **残留小漂移**：君仪发髻在部分镜掉成披发、衣色黑/白会飘、混混偶加胡须、P3D 右上角冒「武君仪」招牌字（违反无字规则）。

### 7. 质检链（生成后自动核查）

- **ArcFace**（insightface buffalo_l）：人脸跨图/对参考的余弦相似度，>0.5 才算「同一人」。
- **VL**（qwen-vl-plus）抽帧核查四维度：①道具形态（枪还是剑、一根还是两根）②空间关系/朝向（谁面对谁）③动作到位 ④动作质感（高手过招 vs 乱扑乱抓）。**不能笼统问「主体在不在」**——单帧识别分不清「运镜转走」和「主体消失」，会误报。
- **ASR**（faster-whisper small）：抓台词乱码。
- **机械 QC**：解码/音轨/24fps/帧数/黑帧冻结。

### 跨模型通用规律（不止 H3）

- **负面表述会激活概念**：写「no dialogue / no weapon / no speech」反而让 H3 出声乱码、让可灵画出亮着的手枪。**只写正向/肯定描述**（「全程不出声、不张嘴」「赤手空拳、双手空空」）。
- **台词乱码的正解**：按官方规范写 `<d>[中文]台词</d>` + speaker ID（如 武君仪 S1 / 粗臂男 S5）；**无台词角色不给 speaker ID**，并明写「全程不出声、不张嘴」；屏幕文字用双引号逐字。ASR 验证后三句台词全准。
- **【Motion】连续性句 + 时间戳前移**：解决「后段动作被吞」。句式为 `every movement in this shot flows into the next without pause, freeze, hesitation or abrupt jump — 本镜的每个动作演满自己的时间，一个动作不间断地流向下一个，不许拖长前一个动作而挤掉后一个动作。`
- **时长跟信息走**（R17）：信息量大的镜给长时长，少的给短时长；拉长时间不能增加动作步数，只会让已有动作拖长反复。

## 经验总结（沉淀，供参考）

1. **跨镜人物一致性分两层，要分开治**：
   - **身体层**（身形/发型/服装/武器/装备轮廓）→ **线稿结构锚点**可根治（本次验证）。
   - **人脸层** → H3 模型本身保持上限 ≈0.57，**只能靠 inswapper 换脸**到 0.7+。
   - 只做一层都会「看起来不像同一个人」。
2. **可灵 Element 绑定的真实能力边界**：锁「风格/主题」（机械臂、亚洲人、大致气质），**不锁「脸几何」**。要锁身体轮廓，喂**线稿**比喂照片有效。
3. **线稿转绘对风格转换很稳**：可灵 omni3 + `image_to_image` 把写实角色照转纯墨线白底，1 灵感值/张，脸只留极简轮廓（两眼点 + 嘴线），后续上色时模型不会去纠结五官——这正是「绕开脸锁问题」的关键。
4. **三模型格局**（当前实测）：
   | 模型 | 成本 | 强项 | 弱项 |
   |---|---|---|---|
   | H3 本地 | 免费 | 动作编排可控、可换脸、可 LoRA | 人脸 0.57、复杂动作超能力、需 GPU 时间 |
   | 万相 3.0 | 0.3 元/s 起 | 单镜清晰、场景准、原生音频、便宜 | **跨镜漂移明显**、抽卡成本不低 |
