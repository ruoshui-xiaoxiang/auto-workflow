## 一、运镜：为什么动、怎么写（补 R2-05 的「理由层」）

| 条 | 判据 | 机器 | 依据 |
|---|---|---|---|
| **R3-01 动机槽** | 每条运镜归入三类之一：①新信息入画 ②跟随主体动作 ③情绪/权力转折。归不进＝炫技，删掉或改固定镜 | 半可判：动机字段填没填 `[人]` | Deakins「camera moves for a reason」；ASC；Nielsen 功能分类 |
| **R3-02 缓入缓出** | 运动起止不硬启停；AI 默认匀速 ⇒ 提示词写「缓缓起步 / 收住」类可见时间感，不写 speed-ramp 术语 | 可测（速度曲线） | dolly grip 实操；10-05「even pace＝滑行」同族 |
| **R3-03 长镜分段** | 超约 8s 的镜头按时间轴分段写运镜，每段一型，不重叠、不既固定又环绕 | 可判 | Seedance/Hailuo 官方分段 |
| **R3-04 景别与运镜分离** | 两字段各自写死；禁用「电影感」笼统带过 | 可判 | FilmBench；R2 同向 |
| **R3-05 位移≠变焦** | Push/Pull（机身）与 Zoom（焦距）互斥；叠加运镜 ≤2 种 | 写法可判 | CAMVLM；官方 §4.3 |
| **R3-08 高难运镜降预期** | dolly zoom / 真环绕不写成必达；能出普通推拉可接受 | `[人]` | Hailuo/ShotVerse OOD |

**写法仍以 R2-05 为准**：运动类型（官方 12 行）＋幅度/速度**仅在有意义时**加；一镜一条；禁器材名词。

## 二、切镜与动作相位（剪辑层进提示词）

| 条 | 判据 | 机器 | 依据 |
|---|---|---|---|
| **R3-12 动接动** | 切点落在动作中段（最快拍附近），不落在起止静止点 | 可测相位 | 术语定义；诛仙「接触不连续」 |
| **R3-13 相邻够不同** | 换镜须带来新信息：主体/景别/空间关系/状态之一明显不同；同主体同景别禁止相位重做 | `[人]`+VL | 相位不重叠实测；官方「cut = new information」 |
| **R3-14 默认硬切** | 非硬切须写理由（时间流逝/意象相撞），禁用溶解交代「过了三天」 | 可判 | 官方 + Murch |
| **R3-18 只改距离用运镜** | 仅距离或微角度变化 → 不切，改运镜 | 文档 | 官方 §4.2 |

**相位不重叠**（本机铁律）：同主体相邻镜必须落在轨迹不同段（被击中/腾空/下坠/落地）或换主体换景别；禁止「已伸腿→又提膝」。

## 四、构图最小集（进提示词的可观察项）

只收**能写进生成词且可核验**的，不写美学论文：

1. **视线留白（lead room）**：主体看向的一侧留空间；故意不留须有叙事意图（孤立）。
2. **注意力层级**：本镜主信息（脸/手/接触点/出口）不得被最亮/最锐/唯一运动区抢走——首帧先解决遮挡与布局。
3. **打戏空间地图**：第一镜建立「谁左谁右、距离、出口」；轴线用**正向** facing/toward 句（R18），不用禁令句。

（R3R10 中光比/饱和等待标定阈值项 → **不进本条**，归 R10 待审，避免假精确。）

## 八、为剪辑而生成（2026-10-09 用户裁定写入）

> 剪辑能补流畅，但**素材必须可切**。运镜/生成按「拍完还要剪」设计，不指望单镜无缝长戏。

| 条 | 判据 | 落点 |
|---|---|---|
| **R3-20 出入点余量** | 单镜叙事结束后仍留 **≈0.5s** 可裁尾；起手可裁头。不写「顶死最后一帧才结束」 | 写词 + 拼片 |
| **R3-21 同拍 coverage** | 重要接触拍可另备「另一景别/另一侧」同拍稿（不必同轮全渲） | 分镜表可选列 |
| **R3-22 运动方向与轴线** | 一镜内位移方向不掉头；跨镜 **出画向 = 下镜入画向**（或明写换侧） | R18 同族 |
| **R3-23 运镜可收束** | 缓起→跟动作→缓收；禁全程匀速拖；打戏优先 **小幅度 Tracking / Static**，大幅度环绕慎用 | R3-02 |
| **R3-24 命中可辨** | 接触点在画面内读得清（谁碰到谁），切点才敢落在最快拍 | R3f 卖力 |
| **R3-25 前景遮挡资产** | 雪/尘/衣摆/发丝保留为转场胶水，不全清空 | 提示词可写飘动物 |
| **R3-26 声音可桥** | 环境底噪跨镜连续；勿每镜「寂静起步」 | R2-10 |

**剪辑侧配合**（生成管不到的）：切在动作中段、动接动、声音桥、速度曲线、甩镜/遮挡转场、相位不重叠用景别差盖接缝。

**与 R3-12/13 关系**：本节保证「有可切的料」；R3-12/13 管「往哪切」。

## 九、写词后镜头冲突自检（LibTV 06 H3 化）

| 冲突 | 检查 |
|---|---|
| State | 是否既写锁定机位又写 pan/track/shake |
| Geometry | 是否同帧前后同看 / 低机位+俯视 |
| Optical | 是否同帧多焦段 / 过近长焦 |
| Temporal | 拍数是否超时长 / 顺序事件写成同时 |
| Continuity | 是否无动机越轴 / 行进反向 / 道具换侧 |
| Physical | 是否不可能加速度 / 穿模 |
| Visibility | 关键动作是否出画 / 要脸却遮挡 |
| Priority | 装饰风格句是否压过镜头动作 |

修复用**最小改动**，保留戏剧目标。
