一条提示词，把上面四条对策写进去：单舰占满画幅、大平面→分块→细部→微细节四级台阶、低角度侧向冷主光让每条缝长投影、暗部抬起保留层次。手填、关 LLM 润色、1344×768。

## 结果

**首轮（SDXL，批次 20260922_235720）——判废。** 三张全是**二战航母浮在海面上**：桅楼、飞行甲板、防波堤、拖船、云天。结构能量 343–453，平均亮度 87–114（完全不是近黑太空）。
病根＝提示词的海事语汇把 SDXL base 的先验拽走了：`warship / armour planes / bridge superstructure / turret bases / battle-worn gunmetal / oxidised plating / chipped paint / soot streaks` 全是海军词。

**改法（把海事词换成太空词）：** `warship→starship`、`armour planes→hull plating panels`、`bridge superstructure→command spire`、`turret bases→weapon emplacements`、`oxidised/chipped paint→scorch marks and abrasion`，并前置 `deep outer space / starfield on every side / pure vacuum`。

**第二轮 SDXL（批次 20260923_000105）**：语义修好了（三张都在太空），但上限没变——结构 352–482，亮度 54–108 仍偏灰。其中一张被 `recessed craft bays with lit interiors` 带成了**内舱走廊**（又一个词级跑偏）。

**第二轮 FLUX（批次 20260923_000142，20 步 / guidance 3.5）**：明显赢。结构 **875 / 1066 / 1057**，亮度 29–38（影调对了），三张都是可辨识的大型主力舰＋分层上层建筑＋成排舷窗灯＋蓝引擎光。

## 结论（四条）

1. **通道定：硬表面太空战舰走 FLUX，不走 SDXL base。** 差 2–3 倍，且 SDXL 语义更脆（两个词级跑偏）。
2. **本地能到参照的 45–55%，不是"本地不行"。** 但剩下的差距**不是模型能补的，是设计**：FLUX 给的是"合理但无辨识度的船"，你能在设定表那艘上指出舰桥/炮塔/机库/灯带，FLUX 这两张只是一堆相似结构。
3. ⚠️ **别把这条曲线读成"上超分就行"**。拉普拉斯奖励高频，可灵那张 1719 里有一部分是超分锐化出来的**纹理**，不是**设计**——我批评它的正是这一点。补高频不等于补质感。
4. FLUX-3 右下角漏出数字 `1075` ⇒ "no text" 在 FLUX 上也只是减弱，不是消除；含字/含号镜仍要按逐字锁那套走。

### 拆出来的五条（都跟细节无关）

1. **画框切断船体。** 两块巨型舰体都**冲出画面上沿**，观众知道它还在继续——这是全图最强的一条重量线索。我们所有图都把整艘船完整地框在里面，等于宣告"就这么大"。
2. **机位看腹部，不看顶面。** 仰视舰底＝体量；俯视顶面＝平面图。上一轮我猜对了这一条（M 批确实变重了），但用力过猛。
3. **行星当背景。** 整片地球云层铺满背景，一次干三件事：给出行星级尺度参照、把**冷反光照进舰腹**（所以死黑 0%，体积读得出来）、并且船**挡住了一个大陆**——遮挡即体量。
4. **死的暗部 vs 活的暗部。** 参照图 0% 死黑、亮度 84；我们 M1 是 43% 死黑、亮度 40。**我们把暗部压成了纯黑，等于把厚度信息擦掉**。厚重需要"暗但可读"的腹部。
5. **小参照物要完整、大的要残缺。** 左下角那艘护航艇**完整入画**并拖着尾焰，母舰**被裁切**——这个不对称就是尺度阶梯。我们的小艇画得太大、也太完整。

### 修正后的处方

- 主炮/旗舰镜一律改成**船体冲出画框**的构图，宁可看不见全貌；
- 表面**减细节**：大平面＋大面积软污渍＋极少量成排的小灯（灯是唯一的尺度线索，要小到"数得清但每个都很大"）；
- **加一个行星/云层背景**当反光源（⚠️这与原剧本"浩瀚无垠的星际虚空"冲突，属设定层改动，需用户拍板：只在旗舰登场那一段用，还是全片允许出现行星）；
- 暗部**抬回来**：目标死黑 <8%、亮度 45–85，用行星反光照舰腹，而不是靠环境光提整体；
- 上一轮"狰狞"那套（装甲齿／内发光腔体）**降级为局部**——只用在炮口、舱口这类"功能节点"上，别铺满全船。
