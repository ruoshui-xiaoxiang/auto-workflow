# 《机械战星》· 仙后级旗舰设定 + 舰桥尺度 v1

> 补充分档：为《机械战星》47镜分镜表新增的帝国主战力设定。
> 关联文档：`机械战星_分镜表_v1.md`

## 一、命名

**仙后级**（Cassiopeia 级）
出处：仙女座星系（M31）的伴星系 **仙后座矮星系（Andromeda VII / Cassiopeia Dwarf）**。
命名理由：短促有力，"仙后"自带王庭威仪，与"帝国"气质相符；与体系内既有的"旭日级"同为二字式命名，风格统一。

## 二、本战线战力分级（重要：旭日级被降级）

| 单位 | 尺寸 | 定位 |
|---|---|---|
| 帝国 旭日级 | 4500 米 | **常规战力** |
| **帝国 仙后级** | **约 1150 公里** | **主战力 · 灭星级** |
| 联邦 机械战星 | 3460 公里 | 终局巨物 |

仙后级 ≈ 战星的 1/3。1150 公里仍属巨物，同样受"尺度靠比例尺说话"的约束。

## 三、仙后级设计规格

| 项 | 值 |
|---|---|
| 尺寸 | 约 1150 公里（战星 1/3） |
| 造型语法 | 帝国：棱角、几何、直线、轴线、严格对称、纪律感 |
| 色 | **红**（引擎/炮光），与帝国舰队同源 |
| 能量来源 | **压缩恒星动力**（与战星同级） |
| 战力 | 灭星级 |
| 造型区分 | 必须与旭日级的"S3双体+中央主炮"**明显不同级**，一眼可辨不是同一级 |

### 压缩恒星动力的视觉证据（必须有）
- 巨型磁力约束环层层嵌套
- 从舰体内部孔隙透出的红光（一颗被封住的恒星）
- 能量导管网络沿主结构分布
- 靠近核心的区域结构明显更密、更亮

## 四、舰桥尺度：城市级

按战舰惯例，指挥中枢占舰长约 1/50 ~ 1/100：

| 部位 | 占舰长 | 实际尺寸 |
|---|---|---|
| 指挥大厅（单层） | 1/500 | ~2.3 km |
| **舰桥主厅** | 1/60 ~ 1/100 | **11 ~ 19 km** |
| 单扇舷窗 | — | **数公里宽** |
| 舰桥外壳凸起（外看） | 1/20 | ~57 km |

**结论：仙后级的舰桥就是城市尺度。普通舰桥锚图（人尺度）不能复用。**

### 展示原则（反直觉，但必须遵守）
1. **绝不整间展示**。一旦观众看全整间厅，尺度就封顶了。
2. **只给局部**：人 + 一段操作台 + 舷窗的一段。
3. **用深度传达尺度**：从指挥席看向舷窗，中间隔着数公里的空场、多层结构、远处的另一侧内壁。
4. **外部侧证**：舰体外壳上的舰桥结构本身是一座 ~57 公里的建筑群（观众可自行推算）。
5. **人物是唯一锚**：全片无正脸，只有背影。人类尺度的背影 + 城市尺度的空间 = 尺度差。

## 五、构图规则：旗舰与战星相反（关键）

> **仙后级是全片最后一个"能被完整看见的东西"。**

| | 仙后级旗舰 | 联邦机械战星 |
|---|---|---|
| 轮廓 | **给完整剪影**，观众能读出一艘船 | **永不完整**，只给弧面、地平线、局部 |
| 作用 | 尺度阶梯的"已知最大" | 尺度阶梯的"不可理解" |
| 同框时 | 完整轮廓在前景 | 近乎平坦的曲面在背景 |

"看得见的巨大 → 看不见的巨大"是全片尺度递进的终点。**旗舰的可辨识轮廓与战星的永不完整必须形成对照，否则战星的压迫感立不住。**
