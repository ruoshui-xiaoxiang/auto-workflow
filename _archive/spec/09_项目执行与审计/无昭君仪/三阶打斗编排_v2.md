## 一、结构：三阶 12 镜 / 48 动作 / 62.0 秒

| 阶段 | 镜 | 武学 | 力量关系 | 时长 |
|---|---|---|---|---|
| **P1 空手八极** | P1A 拦路 / P1B 试探 / P1C 吃亏 / P1D 力不敌 | 挂耳格挡、撑锤 | 她**吃亏**（力量破不开蛮力） | 5.17×4 |
| **P2 裹布棍法** | P2A 激发 / P2B 棍架 / P2C 棍扫 / P2D 过载 | 一架一拨、连拨带扫 | 均势→她占上风 | 5.17×4 |
| **P3 解布枪法** | P3A 亮枪 / P3B 枪花 / P3C 崩弹 / P3D 点喉 | 拦拿、五花枪、压杆崩弹 | 她**碾压** | 5.17×4 |

**弧线设计**：P1 让她真吃亏（观众才知道 P3 的碾压有多贵）→ P2 均势（棍法补力量差）→ P3 解布＝战力跃升。**P2D 角力被压 vs P3C 借杆弹反杀是镜像**——同一局面两种解法，凸显"解布"这个动作的分量。

## 二、编排遵循的规则（G1–G6 / R11–R17）

| 规则 | 在这 12 镜里的落法 |
|---|---|
| **G1 衔接性** | 每镜带 `MOTION_FLOW` 句；打斗镜带 `FIGHT_EXTRA`（接打一体＋两条硬底线） |
| **G2 因果链** | 每拍有前因后果：挥拳→落空→失衡；被扯→拖滑→压杆→撞胸 |
| **G3 抽象转具体** | 不写"借力打力"，写"顺着这一扯沉肩转腕把杆往下压" |
| **G4/R15 容量** | 剧烈镜动作形态 ≤4（审计 v2 口径，见下） |
| **G5/R17 时长** | 逐镜算信息单元→吸附帧网格；**P1A 从 124→175 帧**（唯一超载镜） |
| **G6/R14 底线** | 每镜写死"拳头绝对没有碰到她的脸和皮肤"；P3C 写死"压弯的瞬间必须清楚可见""崩飞要演足" |
| **R12 接打一体** | 格挡与反击同拍（"一架一拨→顺势一送"），不留"等对方前冲"的空档 |
| **R16 一镜一场景** | 12 镜全在 SC03 霓虹巷道 |
| **承接句** | P1B 起"不重新喝问、不重演上一镜的拦路"；P3A 起"不重新角力"——治末帧接力吃掉起势 |

## 三、审计（v2 口径）与 P1A 时长的实测反转

**v1 判据是错的**：它把「对方出招＋我方化解」这种**接打一体**的复合拍当成"多一个动作"，八镜全被判超甜点。但 G1/R12 恰恰要求这么写——拆成两拍会演成"停一下再躲"的分步断层。（同类误判 Qoder 在 H04 犯过："剧烈度判据在混写的镜上会误判"。）

**v2 口径**：动作形态数＝模型要单独完成几个不同的动作姿态。接打一体、动作＋物理结果（崩飞→撞墙→瘫坐）、招式＋展示细节（枪花→弹抖→连点）**都算 1 个**。

| 结果 | 数值 |
|---|---|
| 12 镜动作形态 | 全部 3.5–4.0（剧烈甜点 2–4 内） |
| 审计判"超载" | 仅 P1A（4 形态＋2 台词＝7.0 单元 vs 5.17s） |
| **实测反转** | **P1A 维持 124 帧，不改 175**。同 seed 对照：124 帧 ASR 三句全准（旧版已验）；**175 帧后两句乱码**（"悲傷果的什麼什麼／隱隱的我"）。⇒ R17 对 P1A 的"超载"预测**没发生**，拉长反而坏了音频。归档 `三阶打斗_P1A_175帧废` |
| 结论 | **R17 的"超载→拖长/吞"只在极端塞入时成立；P1A 这种 7 单元/5.17s 属 H3 能自行消化的范围**。时长改动必须有实测背书，不能只靠公式 |

其余 11 镜**不动**：动作形态在甜点区、时长在 R17 带宽内。

## 四、首帧策略：混合 v3（P1A 线稿 ＋ 其余全接力）

**09-27 两次修正，逐张放大看才看清**：

1. **v1（全接力）**：旧 12 镜末帧接力，人物身份跨镜漂（ArcFace 0.05–0.24、角色互换）。
2. **v2（全线稿首帧）**：可灵线稿主体库出 12 镜首帧。**拼对照板逐张放大后发现：8 张 P1–P2 里只有 P1A 服装正确**——P1B 君仪灰白/混混赤膊、P1C/P1D 黑衣/赤膊、P2B/P2C 白袍、P2D 黑白+重甲+能量光；P3 四张同样漂。之前"8 张正确"是被压缩小图骗了。
   **关键结论：线稿主体库锁的是身形/发型/武器轮廓/性别，不锁服装颜色**（白/黑/黑白/灰全漂过），混混的背心也易丢。
3. **v3（当前）**：**P1A 用线稿首帧**（唯一服装正确的锚）＋ **P1B–P3D 全部接力**（服装从 P1A 连续继承，藏青+背心贯穿全片）。P3 的"解布"从 P2D 末帧"布被震松"自然延续。

**代价与对冲**：接力会丢下一镜起势 ⇒ 每镜起句带承接句（"不重新X、不重演上一镜的Y"）；接力会把上一镜缺陷焊进下一镜 ⇒ P1A 这个锚必须人眼审过（已审：服装/站位/四拍/台词全对）。

**给下一个工具的教训**：首帧质检**不能看压缩小图**——服装颜色、武器裹布状态这类关键维度在 600px 宽的缩略图上分辨不出，必须逐张放大到原尺寸看，或拼对照板。
