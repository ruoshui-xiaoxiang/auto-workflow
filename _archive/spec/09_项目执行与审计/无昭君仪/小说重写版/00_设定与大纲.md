# 《武昭君仪》创作提示词与大纲

爽文版 v1.0 ｜ 2026-09-28 ｜ 类型：赛博朋克 × 古武穿越 × 大女主打脸升级

> **本轮口径**：只保留人物设定（武君仪、小Q）。原 v0.5 的哲学内核、反爽文纪律、随机穿越无使命、归途不承诺、四卷开放结构**全部作废**。本稿是唯一执行依据。

---

## 一、一句话定位

一个武周将门之女，背着一杆裹着白布的长枪闯进赛博朋克下层区——这个世界没有一套系统能算出她的动作，因为古武根本不在它的模型里。

## 二、八维创作提示词

### 1. 题材定位
赛博朋克底层崛起 + 古武降维打击 + 大女主打脸升级。舞台是第44号下层区，一路往上打通公司城。

### 2. 世界观设定
**上层公司城**：秩序井然、义体普及、算力即权力。人被"可预测、可建模"。
**下层区（第44号）**：官方力量薄弱，帮派与私人武装维持局部秩序。义体、非法改装、废弃设备与普通人混居。货币是贬值的**信用点**，载体为不记名储值卡；**银**是低价工业原料；**黄金**稀缺。
**身份ID**：上层一切的通行证。无ID者为黑户，进不了正规仓、办不了正规事——这是主角前期最大的现实门槛。

### 3. 主角人设〔保留〕
**武君仪**，武周时期武氏旁支将门之女，师父是名将**王孝杰**。

- 从小练枪，基本功扎实，内息初成；**没有江湖阅历**，对陌生义体、现代火力、复杂地形仍需学习。
- 大家闺秀的教养 + 将门的风骨。外在清冷，遇事肯撑住，但也会害怕、好奇、犹豫、兴奋。
- 性格底色是**待不住**——离家不是被逼，是那个地方装不下她。留了信，没打招呼。
- 随身：**沉铁长枪**（整杆裹白麻布）、母亲留下的**金簪**、家传**玉佩**、粗布钱袋（少量碎银）。
- 语言习惯带古意（"借问""劳烦""使得"），是身份标记。

### 3b. 出门行头与"身份误认"〔首卷核心爽点引擎〕

**她身上穿的是什么**

武君仪出门那天穿的是武周将门之女的正式行头，不是便服：

- **紫绫短襦**，领口与袖口用金线绣云纹；外罩一件织暗花的半臂
- **织锦长裙**，裙摆压着泥金暗纹
- **蹀躞带**——武周贵族与武将才系的腰带，缀着几枚玉饰（这是武人的标志，寻常闺秀不系）
- 发间**金步摇**（母亲所赠的金簪即在其中）与珠钗
- 腕上一对**金跳脱**，腰间一只**锦缎香囊**
- 脚上是**锦靴**（她爱枪马，不穿绣鞋）

**在下城区人眼里，这套行头意味着什么**

1. **全手工织造，没有工业编码。** 这世界的衣服都是合成纤维、批量压制、带公司标识。她那身料子，扫描仪读不出成分，也读不出产地。
2. **金线是真金，玉是真玉。** 不是镀层，不是仿料。
3. **没有任何义体。** 在下层区，没义体＝穷；但在上层顶层，**不装义体反而是身份的象征**——那层人不需要靠机械强化自己，纯肉身被视为血统干净。
4. **她说话带古意**（"借问""劳烦"）。下层区人听不懂，但听着"有派头"。

四条合起来，下城区任何一个有点眼力的人都会得出同一个结论：

> **这不是下城区的人。这是上城区某个家族的嫡系，多半是微服下来的。**

**这条设定怎么变成爽点**

- **打脸**：没眼力的人（混混、收保护费的、骗子）把她当肥羊动手 → 被秒 → 旁边有眼力的人看得脸色发白。
- **装逼**：她**自己完全不知道**这身衣服有多唬人。别人对她毕恭毕敬，她莫名其妙；别人问她来历，她答不上来——她连身份ID都没有。
- **反差**：真实身份是"连身份ID都没有的黑户 ＋ 穿越古人"，全世界却当她是上城大小姐。**这个反差本身就是笑点和爽点。**
- **反派误判**：阿罗不敢下死手，因为动上城的人等于灭门；裴先生愿意压价，一半因为她的枪，一半因为怕得罪"上城"。
- **悬念**：屠姐那边会去查上城有没有"武家"——查不到。**查不到比查得到更让人忌惮。**

**使用纪律**
- **不能让她自己解释。** 她越困惑、越答不上来，效果越好。
- **不能每次都靠衣服赢。** 衣服只负责"让对方犹豫半拍"，真打起来还是靠枪。
- **有人不吃这套。** 青蝉、铁面这种纯打手只看战力，衣服对他们无效——所以它不是万能护身符。
- **金簪玉佩别动。** 衣服唬人，但值钱的是簪和玉；这两样首卷不能真出手，否则"上城大小姐"的假象会当场崩掉。

### 4. 核心冲突
**她 vs 一个只认数据的世界。**
这个世界的一切——义体强度、反应速度、胜率预测——都建立在可建模的数据上。她的古武是模型外的变量。她要做的，是从下层区一条廊道开始，用一杆枪把自己写进这个世界的规则里，再往上，一路打到公司城。

### 5. 爽点设计
| 类型 | 形式 | 频次 |
|---|---|---|
| 小爽点 | 一句话噎住对方、一个动作镇住场面、当众打脸看不起她的人 | 每章至少 1 个 |
| 中爽点 | 以弱胜强的正面对抗、身份反转、当众碾压义体高手 | 每 3–5 章 |
| 大爽点 | 解布亮枪、境界突破、势力易主、立名 | 每 8–12 章 |

**打脸对象分级**：混混 → 义体打手 → 帮派头目 → 区霸 → 公司执法官 → 公司嫡系。逐层往上，不跳级。

### 6. 节奏规划
首卷八章完成"落地 → 摸规则 → 第一战 → 立名"完整闭环。每章至少一个小爽点，章末留钩子。第 7 章解布（大爽点），第 8 章立名（卷终高潮）。

### 7. 配角框架
- **小Q**：Unit-Q7 老旧民用家用辅助机器人。七八岁孩子高，黑色面屏、变色灯球、机械臂，手掌有温热的仿生触感，有语音。忠犬型伙伴 + 情报辅助 + 搞笑担当。**它的"有限"是萌点，不是负担**；可以逐步解锁功能，但不抢主角风头。
- **周师傅**：下层区修理匠，嘴冷心不冷，第一个承认她"有两下子"的本地人。
- **阿莲**：下层汤摊女人，市井精明，最早给她饭吃的人。
- **费主管**：费记仓管，只看规矩不看人，被她用实力说服。
- **阿七**：费记义体工，起初嘲笑她"素体"，被打脸后成为头号服气的人。
- **阿罗**：锈牙帮在这条廊道的小头目，C 级。首卷主要反派。
- **屠姐**：第44号下层区区霸，B 级。首卷只提名字，不出场。

### 8. 开篇钩子
穿越即开打。她睁开眼，第一眼是赛博霓虹，第二眼是三个混混正在拆一个会说话的小机器人——她开口制止，然后被打脸的人变成了他们。

## 三、金手指：古武降维〔规则与上限〕

武周的"练气"练出的**内息**真实存在。内息不属于这个世界的物理模型，因此：

| 能力 | 表现 | 限制 |
|---|---|---|
| **数据干扰** | 低阶义体、传感器、瞄准与预判系统在她面前失真、延迟、报错 | 只能干扰电子，不能凭空造物；对纯机械大力无效 |
| **肉身强化** | 速度、力量、抗击打远超常人；发力贯通后可碎义体外壳 | 内息有限，用尽即虚脱；境界不到硬撑会伤身 |
| **听劲预判** | 感知他人动作的"预兆"，在对手出手前一线做出反应 | 只能读身体，不能读心；对完全陌生的机械结构需先适应 |
| **枪意** | 沉铁长枪为家传旧物，解布后可承载内息，是她的本命兵器 | 裹布期间只有"棍"的威力；解布后才有"枪" |

**成长机制**：内息靠"喂"——高强度战斗、濒死危险、以及赛博世界的特殊能量源（义体能量核心、城市能源场）都能催动境界突破。

**上限声明**（防止无脑开挂）：她打不过纯机械的重型力量，也读不出机械结构的预兆；面对组织化武装会吃力。**每一场胜利都要付出代价。**

## 四、力量体系

### 主角境界（古武线）
| 境界 | 特征 | 解锁章节 |
|---|---|---|
| **练气** | 内息初成。感知敏锐、身法快于常人、可干扰低阶义体 | 第01章（起点） |
| **明劲** | 发力贯通，一拳可碎义体外壳 | 第03章突破 |
| **暗劲** | 内息可透体干扰电子，枪尖点中即废义体 | 第07章突破 |
| **化劲** | 内息外放成势，一人可镇一条街 | 第二卷 |
| **抱丹** | 内息凝实，正面硬撼公司执法官 | 第三卷 |
| **罡气** | 内外一体，踏入上层公司城 | 第四卷 |

### 对手分级（义体线：即时战力最高，但保质期短）
| 级 | 身份 | 特征 |
|---|---|---|
| E | 街头混混 | 零散义体，一把短刀或黑市短枪 |
| D | 义体打手 | 单件强化，动作快、力大 |
| C | 帮派头目 | 全身义体 + 战术芯片（阿罗、青蝉） |
| B | 军用级 | 铁面、屠姐。开始出现早期排异 |
| A | 公司执法官 | 全身军用 + 实时链路。**开始出现赛博精神病** |
| S | 公司嫡系的刀 | 顶级义体。**基本半疯，寿命很短** |

### 对手分级（基因线：前期弱，后期强）
| 级 | 名称 | 战力参照 |
|---|---|---|
| 三 | 民用级 | 略强于常人 |
| 二 | 家族级 | 相当于 C–B 级义体 |
| 一 | 嫡系级 | 相当于 A 级 |
| 核心 | 血统液 | **超过 S 级**，但要几十年培养 |

**两条线的关键差异**：义体是耗材，用完就扔；基因是血统，慢慢养。上城大人物身边的保镖和刀，几乎全是义体派。

## 五、全书卷纲

- **第一卷 霓虹下的枪**（8 章）：落地、摸规则、第一次解布、立名。目标：在下层区站稳，拿到自己的第一条廊道。
- **第二卷 锈牙**：与帮派正面开战，打下整片下层区。化劲。**卷末引爆"武家"——屠姐去中环打听，打听回来的结果超出预期。**
- **第三卷 上层的门**：她把整片区域治好了。**治安总署需要一个"给钱有用"的正面案例，于是给了她一个不领薪的虚名——第44号分区治安协理。** 她第一次有了名号，也第一次被绑上别人的船。**铁律安保出手（治安本来是它的外包生意）；上城武家派人下来认纹；第一次接触基因优化液——一等液，她排异，但撑住了。** 抱丹。
- **第四卷 公司城**：直面武家与公司嫡系。**核心液是全书最后一张牌——武家几百年配不出来的东西，就在她身上。** 而嫡系身边那把"刀"是顶级义体：半疯、不怕死、寿命很短。罡气。

### 贯穿全书的暗线：秩序

她从"打服一条廊道"开始，做的其实是别人都不做的事——**把秩序建起来**。上城不管、帮派只收钱，只有她在通排水、修灯、赔锅。

到第四卷，她进公司城的方式**不是打进去**，是让上城不得不承认：**她管的那片地方，比他们自己的更好。**

（这条线的完整设计见 `04_设定结合方案_秩序线.md`）

## 五·补、公司城武家〔后续核心线〕

> **口径**：这是"后边才揭"的设定。首卷**只埋伏笔，不点破**。

### 1. 武家是什么

**武氏控股**——上层公司城的主要股东家族之一。持股横跨能源、军工与义体供应链，下层区流通的义体，零件源头有一半在武家手上。

武家在上城是老牌家族，势力深，但行事低调，不常出现在明面上。这决定了它的登场方式：**不是"有"，而是"一查吓一跳"**。

**上城不是武家一家。** 牌桌上有四家：

| 集团 | 地盘 | 在故事里的作用 |
|---|---|---|
| **恒元** | 市政、能源、财政 | 下层区"给中环的份子"最后收进它账上。月底来收的那两个人就是它派下来的 |
| **原道生物** | 生物科技、芯片、基因优化液 | 武氏在基因赛道上的**新贵对手**。量产、标准化、便宜，上城中层也买得到三等液；但配不出一等以上 |
| **铁律安保** | 安保、情报、执法外包 | 上城大人物身边那些**顶级义体战力，多半是它养的**——便宜、强、是耗材、疯了就换 |
| **武氏控股** | 能源、军工、义体 + 生物制剂 | 最低调也最老的一家。核心液断代，家族内有继承之争，眼看原道越跑越快 |

四家的具体分工与叙事功能见 `04_设定结合方案_秩序线.md`。

### 2. 两条与首卷呼应的旧设定

- **嫡系不装义体。** 武家认为义体是工具，是给下人用的；血统干净的人才配用肉身。这条传统在上城是出了名的怪癖，但没人敢说。——**君仪没有义体，恰好撞在这一条上。**
- **家纹。** 武家有固定的家纹。而**君仪那块玉佩上刻的，就是这个纹样**。

### 3. 这条线怎么一步步引爆（爽点阶梯）

| 阶段 | 事件 | 效果 |
|---|---|---|
| 首卷 | 只有"上城大小姐"的猜测，裴先生摇头说"上边姓武的，我没听过" | 埋钩 |
| 第二卷末 | 屠姐派人去中环打听"武家"。打听回来的结果是：**不只是有，而且是股东之一** | 屠姐从"忌惮"变成"伺候"，君仪在下层区成了碰不得的人 |
| 第三卷 | 上城武家注意到"下层区有人打着武家的名号"，派人下来查。见面 → **认出玉佩上的家纹** → 态度剧变 | 身份线彻底翻转 |
| 第四卷 | 她进入公司城，面对武家。核心悬念揭晓 | 全书最大反转 |

### 4. 核心悬念：两个"武家"是什么关系

**暂不锁定**，两条路都留着：

- **路 A（血脉）**：公司城武家确实是武周武氏的后人，一脉千年不绝。那君仪按辈分是他们的老祖宗。爽点拉满，但需要把"传承"写扎实。
- **路 B（巧合＋权谋）**：没有血缘关系，纯属撞姓。但武家自己也不确定，为了面子与利益，主动"认下"她。她成了武家手里的一枚棋，也成了她自己的机会。

**两条路可以并行一段时间**：先让所有人都以为路 A 成立，再在第四卷揭出真相是哪一条。

### 5. 使用纪律

- **首卷绝不点破。** 玉佩只在正文里露一次面，不作任何解释。
- **不能让君仪主动冒用。** 她从没说过自己是上城的人——这个"假身份"完全是别人替她造出来的。这一点必须保持。
- **武家的态度要有层次**：先怀疑（查）、再试探（派人下来）、再震动（认纹）、最后是各怀心思（利用/认亲/清除）。
- **别写成"认亲大团圆"。** 武家内部有继承之争，她这个"从天而降的嫡系"对某些人是资源，对另一些人是威胁。

## 五·补二、上城的另一条路：基因优化液

### 1. 上城分成两派

**义体派**：用机械替换身体。见效快、便宜、可升级、可拆换。是下层区和上城中间层的主流。在上城顶层眼里，义体是工具——装在身上的东西，坏了能换，也就意味着"不是你自己的"。

**基因派**：不动刀，不改装，用**基因优化液**改自己。贵、慢、不可逆，一旦失败没有回头路。但肉身完整，被视为血统与正统。

上城顶层家族绝大多数走第二条路。**"嫡系不装义体"这条规矩的真正来历不是清高，是路线不同。**

### 2. 基因优化液分级

| 级 | 名称 | 效果 | 流通 |
|---|---|---|---|
| 三 | 民用级 | 强身、抗病、延寿，外表看不出来 | 上城中层可买，极贵 |
| 二 | 家族级 | 力量、速度、感知全面提升 | 家族旁支、护卫 |
| 一 | 嫡系级 | **外在表现接近"异能"**：爆发力超常、能感知预兆、能干扰身边的电子设备 | 只有嫡系能用 |
| 核心 | 血统液 | 不流通。每家一套配方，与家纹对应 | 只在家族内部传承 |

**关键**：一等与核心级的外在表现，**和君仪练出来的内息、听劲、枪意是同一类东西**。

### 3. 为什么这个世界"算不出"她

上城对基因优化的建模本来就粗糙——样本极少、数据不公开、每家配方保密。所以低阶设备遇到基因派的人会失真。

而君仪身上那套东西，**比任何一家的核心液都更"干净"**：她是自己练出来的，没经过任何配方调和。

### 4. 武家的核心液断了

不是失传，是**配不出来**。武家几百年里试过无数次，能配出一等，配不出核心。缺的那一环是什么，谁也说不清。

所以他们才那么在意"血统干净"这四个字。

### 5. 君仪能从这条线拿到什么

- 她练出来的内息，和基因优化液提供的东西**同源**。
- 液不能让她"学会"新东西，但能**补底子**：让她突破更快、更稳、更不容易伤身。
- 越高级的液效果越强，代价也越大：体质不合会排异；上城家族会盯上她。
- **这是她化劲之后的主要成长路径**：抱丹靠武家的一等液，罡气靠核心液。

### 6. 爽点与悬念

- **武家看她是什么**：一个活着的样本。他们花了几百年想复现的东西，她身上天生就有。
- **她看武家是什么**：一条能让她变强的路，和一个可能帮她找回家线索的机构。
- **核心悬念升级**：武周的"练气"和赛博世界的"基因优化"，是两条路走到同一个地方，还是本来就是同一条路？
- **第三卷动作**：武家派人下来 → 认纹 → 试探她的底子 → 给液 → 同时给她套上枷锁。

### 7. 使用纪律

- **液不是万能药**。它只补底子，不替代练功；喝了液不打，照样输。
- **不能让她轻易拿到核心液**。核心液是全书最后一张牌，第四卷才动。
- **排异要写出来**。第一次用一等液必须有代价，否则爽点廉价。
- **白鸦的来历留白**。她"不换、是练出来的"这句话，可以是天生，也可以是基因派流落下来的——两条都留着。

## 五·补三、义体派的顶级战力

### 1. 两条路线的强弱不是线性的

基因优化液**前期战力不高**。它需要时间——液要一针一针打，体质要一轮一轮调，几年才见效，中途不能停。上城家族培养一个一等，要十几年。

义体改造不一样。它**当天就能装，装完就能打**，可以无限叠加、随时更换、批量生产。

所以在中期以前，**义体派的战力天花板高于基因派**。

### 2. 义体派的天花板与代价

顶级义体改造的战力非常强，强到能一个人清掉一支小队。代价有两条：

| 代价 | 表现 |
|---|---|
| **赛博精神病** | 装得越多越容易精神崩坏。幻听、暴怒、失去共情、把人当零件。顶级战力往往都是半疯的 |
| **身体缺陷** | 肉身与机械的接缝出问题。神经排异、组织坏死，需要长期用药或定期更换。装得越满，寿命越短 |

两条合起来，决定了顶级义体战力的**保质期很短**。

### 3. 上城大人物怎么用他们

正因为保质期短，上城大人物用起来毫无负担——

- **便宜**（相对基因派）
- **强**（即时战力最高）
- **是耗材**（疯了就换，坏了就丢）
- **不用当自己人**（不是血统，不占家族名额）

所以上城顶层身边的保镖、执行脏活的刀，**几乎全是义体派**。家族嫡系自己走基因路线——不是因为义体弱，是因为义体是"别人"。

**一句话**：基因派是自家人，慢慢养；义体派是工具，用完就扔。

### 4. 对主角线的意义

- 君仪的古武前期打得过中低阶义体，遇到**顶级义体**会非常吃力。
- 她越往上走，遇到的义体战力越强、越疯。**"对手会疯"这件事本身要写成她的麻烦**——一个不在乎自己命的疯子，比一个高手难打得多。
- 白鸦是例外：不装义体，纯练出来的。在下层区这是极罕见的事。

### 5. 更新后的战力对照

| 君仪境界 | 义体派同档 | 基因派同档 |
|---|---|---|
| 练气 | 街头混混 / 单件义体 | 三等（民用） |
| 明劲 | 义体打手 | 三等上 |
| 暗劲 | 帮派头目 / 军用级（早期排异） | 二等（家族级） |
| 化劲 | 公司执法官（**开始出现赛博精神病**） | 二等上 |
| 抱丹 | 顶级义体（**半疯，寿命短**） | 一等（嫡系级） |
| 罡气 | 无——义体已到极限 | 核心液 |

### 6. 使用纪律

- **义体不是弱**。别把义体写成劣等品——它是这个世界最成熟、最普及、即时战力最高的路线。
- **基因不是强**。前期它就是弱，要写出来，不然武家为什么急。
- **顶级的疯要具体**。不是笼统的"疯了"，要有具体表现：说话断片、对痛觉没反应、把人叫"件"。
- **别让她靠"打义体"通关**。越往后对手越强，她必须靠基因优化液补底子。

## 七、写作纪律

1. **每章至少一个小爽点**，不能平淡流水；每章有明确矛盾推动；章末留钩子。
2. **主角能力要有可感知的递进**——从"能自保"到"能碾压"，中间必须有代价。
3. **反派不能太蠢**。阿罗是生意人，不是莽夫；他的每一步都要有他自己的算盘。
4. **小Q 不抢戏**。它负责情报、萌点、陪伴，关键胜利永远属于君仪。
5. **账目与器物连续**：碎银、储值卡、营养膏、金簪玉佩、长枪裹布状态，一章一章对得上。
6. **语言**：君仪说话带古意；**其余所有角色一律现代口语**。器物、制度、货币、身份、义体按赛博朋克呈现。
7. **古武不是万能**：写清楚她赢在哪、付出什么、还差什么。
