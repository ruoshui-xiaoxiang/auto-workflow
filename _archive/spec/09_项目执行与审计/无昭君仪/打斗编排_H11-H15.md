## 一、这五镜是什么戏

第一章「巷战」：君仪在巷口拦下三个欺负小Q的混混，从对峙到收场。五镜是一条完整的**力量关系反转弧**：

| 镜 | 帧/秒 | 步数 | 性质 | 这一镜在弧线上的位置 |
|---|---|---|---|---|
| **H11** 挑衅 | 328 / 13.67s | 4 | 从容 | 她出声拦人 → 三人转头 → 灯牌扫出她裹布的长杆 → 对方发问、粗臂男逼近。**她还没出手**，戏在对方那边 |
| **H12** 被扯 | 362 / 15.08s | 4 | **剧烈** | **全场唯一她吃亏的一镜**：杆被攥住猛扯、脚底在湿地拖滑半步、杆几乎脱手。然后不退反进、压杆、撞胸、对方扶墙 |
| **H13** 短刀 | 328 / 13.67s | 4 | **剧烈** | 对方升级武器（短刀先扎面门）→ 她偏身让过（险）→ 磕腕 → 连拨带扫逼墙 → 绊倒、刀落地 |
| **H14** 制喉 | 362 / 15.08s | 4 | 中速 | 绿发男掏黑短匣 → 她旋身把杆送出、布端抵喉 → 喝止 → 对方手垂下 |
| **H15** 收势 | 362 / 15.08s | 6 | 从容 | 让位、放三人走、同伙劝住、退到巷口一点蓝光、她枪尾落地 |

**为什么 H12 必须让她吃亏**：五镜里如果全是碾压，观众看不出高低——高手感来自"**被压制之后仍从容**"，不是"一路平推"。这是 C 线 previz（P1C/P1D）借过来最值钱的一条相位，**借的是相位不是剧情**（不拆布、不改台词）。

## 二、本轮的四处编排改动（都是零成本改词，不重渲已渲镜）

### 1. H12：5 步·剧烈 → 4 步（R15 / G4）

- **原**：攥杆猛扯 → 拖滑半步几乎脱手 → 顺势沉肩转腕压杆 → 送臂撞胸 → 对方扶墙她收势
- **改**：攥杆猛扯、脚底拖滑半步几乎脱手 → 顺势沉肩转腕压杆 → 送臂撞胸 → 对方扶墙她收势
- **依据**：剧烈动作甜点 2–4 步，5 步起糊+漂（R15）。而"攥杆猛扯"与"拖滑半步"**本来就是同一个力的因果**（他扯 → 她被拖），拆成两拍等于给模型一个"扯一下、停一下、再滑"的空档。并成一拍既进甜点区，也更符合 G1（衔接性是唯一铁律）。
- **没做的**：没有为降步数删掉任何相位——"力量吃亏要演成身体结果"（脚底拖滑、杆几乎脱手）这条 C 线相位原样保留。

### 2. H13：5 步·剧烈 → 4 步（R15 / G4）＋ 末步去"追"字（R7）

- **原**：刀尖扎面门她偏身让过 → 枪尾磕腕 → 连拨带扫逼墙 → 绊管头坐倒刀落地 → 小Q"后面"她收住不追
- **改**：刀尖扎面门她偏身让过顺势磕腕 → 连拨带扫逼墙 → 绊管头坐倒刀落地 → 小Q"后面"她收住这一势
- **依据①（步数）**：把"偏身让过"与"磕腕"并成一拍——让过的**同一瞬间**就磕腕，这正是 G1/R12「接打一体」；拆开写会演成"让过 → 停 → 再磕腕"的分步断层。C 线借来的"对方先出刀、她险险让过"这个相位保留在 **承** 里（"刀尖只擦着她鬓边的碎发过去、绝对没有碰到她的脸和皮肤"）。
- **依据②（收势）**：末步原文"她收住**不追**"，被 R7 的判据（末步含"追"＝对方在出招）误判成"收势会被挤掉"。改"她收住这一势"——**语义没变**（本来就是她收势），只是把误伤的措辞换掉。

### 3. H14：5 步 → 4 步（G1）

- **原**：旋身见黑短匣抬起 → 心口一紧枪送出 → 白麻布抵喉 → "别动""放下" → 手垂下
- **改**：旋身见黑短匣抬起、心口一紧顺势把杆送出 → 白麻布抵喉 → "别动""放下" → 手垂下
- **依据**："旋身"与"杆送出"是**同一个动作**（旋身的同一瞬间杆已经递出去）。拆成两拍，H3 容易演成"转完身、站定、再递杆"——而这一镜的紧张感全在"毫不迟疑"。合拍后 4 步。

### 4. H11：末步落回主角（R7）

- **原**：收钱袋"放开它" → 灯牌扫过衣裙与裹枪 → "裹的什么？新武器？" → **粗臂男逼近**
- **改**：收钱袋"放开它" → 灯牌扫过衣裙与裹杆 → "裹的什么？新武器？" → **她侧身端稳长杆、目光压住走近的粗臂男**
- **依据**：R7 要求末拍留给主角收势/定格，否则会被下一个动作挤掉。原末拍是对方在出招（逼近），改后末拍落回她——**戏没变**（还是粗臂男走过来），只是把镜头的最后一口气留给她。
- 顺带把 beat 里的"裹枪"改成"裹杆"（beat 是设计稿不进提示词，但保持一致）。

### 5.（附）H04：清掉一处误报

- **原**：…→ 阔叶滴水**打肩** → …
- **改**：…→ 阔叶上的水珠**落在肩头** → …
- **依据**：H04 是古代线环境镜（13s、无打斗），"打肩"的"打"撞上剧烈度词表 → 被误判成"5 步·剧烈"。**改词不改规则**（Qoder 的原话："同一个字在不同语义下会撞同一张词表，改词比改规则便宜"）。镜本身没变。

## 三、G6 底线句：故意留成对照组（不要动）

| 镜 | 有无底线句 | 说明 |
|---|---|---|
| **H12** | ✅ 有 | `FIGHT_EXTRA` 的英文硬底线（杆不脱手不倒地、任何拳刃碰不到脸）＋ 承里的身体结果 |
| **H13** | ✅ 有 | 同上 ＋ 承里写死"刀尖只擦着碎发、绝对没有碰到她的脸和皮肤" |
| **H11 / H14 / H15** | ❌ 无 | **故意不加** |

**为什么故意不加**：H11–H15 正好构成 G6「底线句到底管不管用」的天然对照——H12/H13 写了、H14/H15 没写，五镜同场景同人物。**加了就把对照组毁了**。等这五镜成片出来，看"写了底线句的镜是否真没出现拳打中脸"，再决定 G6 升不升级（现在它是**参考级**，机器对 18 条点到脸/头/咽喉的镜只报 info）。

## 四、没做的事（以及为什么）

1. **不改任何镜的时长**。按 R17 字面算，H12（4 单元 / 15.08s＝3.1×）等镜都"超配"，但 R17 的空转侧已被 `motion_curve.py` 的 8 镜光流实测**否证**（"秒/单元"与"尾塌"相关性方向还相反）⇒ 不为"把时间填满"改时长，也不据此返工。
2. **不烧正向渲染流派句**。六臂 arm2 实测：＋66 字渲染流派句与 arm1 **无可辨差异** ⇒ 那一层不吃词。画风走**换锚**（见下条），不走加句。
3. **不借 C 线的剧情**。C 线（三阶 12 镜）已定性为 previz、不进片：P3「亮枪／不裹布」撞"两章内不拆布"设定，7 条台词正文查无。**只借相位**（力量吃亏演成身体结果 / 接打一体 / 对手有落点 + 末拍收势 / 承接句）。
4. **不加"无字"之外的替身句**。赛博街景招牌长出可读汉字是这一挂画面的**结构性问题**，不是措辞问题 ⇒ 留待整批跑完后做"烧字位置清单"，遮/补/重拍由人定。

## 五、同时落地的两条非编排改动（同批）

- **撤掉真人感脸锚**：`CAST_ANCHOR` 从 `{H12: A09, H13: A08}` 清空。依据＝画风基线实测（A09 皮肤高频 5.78、A08 11.57，都属"真人照片感"，而首帧里唯二两张偏真人感的正是 H12_first 与 H13b_s0）。撤锚后 H12_kf/H13_kf 挂图由 5 张减到 4 张。
  - **补偿**：配角改由 `CAST_LOCK` 逐镜给"一眼可辨的形貌"承载身份（H12 壮硕平头男／H13 瘦高个，措辞与 H15 同源，跨镜形貌一致）。依据＝H08 的教训（正文没给可视特征 → 模型拿手边最近的一张脸填，克隆出第二个君仪）。
  - **留痕**：arm5（同时撤 P01＋A09）里那名男性**仍是真人感** ⇒ 撤锚本身未必改画风，这条 n=1 只给方向；真正的判据是「同配置重掷噪声底」，先量方差再谈换锚有效性。
- **删"打结"**：`SPEAR_LOCK` 里"两端把布收细打结、完全封口"→"两端把布层层缠绕收拢、完全封口"。依据＝六臂实测：锁句里的动作名词会被**字面执行**（写"打结"，arm4 真在杆端长出一个绳结块；写"收细打结"，arm5 真散成绳头），而 P01 资产图实际是"缠绕收尖"。**正确改法是删掉这个词，不是加形容词修饰它。**
