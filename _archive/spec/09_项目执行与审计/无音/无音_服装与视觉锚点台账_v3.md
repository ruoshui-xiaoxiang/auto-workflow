## 二、换装可变维度（每集从中取 2-3 项组合）

- 外衣形制：襦裙 / 衫裙 / 褙子 / 半臂 / 袄 / 斗篷 / 罩衫
- 色系：月白 / 鸦青 / 黛色 / 藏蓝 / 藕荷 / 缃色（料旧、洗得发白为底）
- 纹样：素面无纹 / 暗纹（水波、回纹、折枝）/ 缘边配色
- 季节件：披帛（春）/ 竹笠·团扇（夏）/ 半臂·褙子（秋）/ 袄·斗篷·手炉（冬）
- 职业小件（不建套，提示词追加）：摆摊围裙、袖套、墨渍
- **他人给的痕迹**（每卷至多 2-3 件，叙事用）：见下表"来源"列

## 五、生产规则

1. 一套一次生成 + 一次目检；目检不过不进该集首帧生产。
2. 该集所有首帧提示词必须复述五件永锚 + 本套外衣描述；禁跨集挪用锚文件。
3. 同集内禁换装；回忆/闪回镜头引用来源集锚文件并在台账记"复用"。
4. "他人给的痕迹"物件一旦入妆，后续集持续在场（连续性），不得消失。
5. 每套定妆照出 3 种光照（晨/午/夜）+ 正面/3/4 侧/低头书写四角度，入资产包（圣经 §9.3）。
6. 台账状态流转：待设计 → 待生成 → 待目检 → 在用 → 退役。
