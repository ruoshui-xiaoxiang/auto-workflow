## 1. 试点镜选择（推荐镜4）

**推荐镜4「金属球击中额头」**（穿越特效动作镜核心，难度中）——帧级拆解已齐：

- 首帧 300：球正中额头，电光四溅，皮肤凹陷
- 315：头猛然后仰，长发后飘，双眼圆睁，瞳孔骤缩
- 330：书滑落，五指松开，手臂无力垂下
- 345：瞳孔扩散，眼神涣散
- 360：画面从边缘向中心变黑
- 尾帧 390：全黑（身体软倒隐藏黑暗，留白转场）

选它因为它锁的是**角色动作 + 物体下落 + 机位**（头后仰、书滑落、手臂垂下），最能检验「灰模锁动作」这条假设；且与镜3（光球坠落）同属穿越事件，验证后顺带覆盖镜3 尾帧=镜4 首帧的衔接。备选：镜3（纯特效轨迹）、镜13（小Q环绕+女主后缩，走位/机位）。

## 3. M1 步骤

0. 修 Godot 灰色帧 bug（场景切换后视口未更新，约 0.5h 定位）
1. 取镜4 帧级拆解的动作意图（头后仰 / 书滑落 / 手臂垂下）
2. Godot 白模：简单体块女主（或复用 char_e01）+ 石凳 + 书道具，对齐镜4 机位（特写·仰角·焦距）
3. 摆关键姿态：头后仰角度、长发飘散方向、书下落轨迹、手臂位置，约 10~15 个
4. 插值平滑，检查连贯（无穿模、节奏对）
5. 渲染灰模帧序列（480p 低分辨率够）
6. 抽首帧 / 尾帧 / 中间 3~4 个关键帧
7. 🚦 **人工审核**：灰模序列 + 关键帧给你看，确认动作/机位还原意图
8. 路线 A：灰模关键帧 → 火山 Seedream `--input` i2i 出图（3~5 张）→ 对照「灰模姿态 vs AI 出图姿态」验证锁动作强度

## 4. 预算（M1 单镜）

- previz 软件：¥0（Godot 免费）
- 出图验证：火山 Seedream ¥0.3/张 × 3~5 张 ≈ ¥1~1.5，含重跑上限 ≈ ¥3
- 时间：修 bug 0.5h + 白模/机位 1h + 摆姿态 1~1.5h + 渲染抽帧 0.5h ≈ 3~3.5h（首镜含搭建，后续镜复用资产降到 1.5~2.5h）
- **结论：M1 几乎零货币成本，主成本是时间（约半天）**
