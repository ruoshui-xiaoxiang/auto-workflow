## 3. Agent 常规工作流

```bash
cd D:/AIWorkflow/tools
py -3.12 -m fanxing workflow --agent h3-spider \
  --project "C:/Users/若水/Movies/Hub/Projects/未命名项目/h3" \
  --out "C:/Temp/fanxing_runs/h3-spider_001" \
  --shots U01 U02 --through gate

# 真正提交 GPU 才加：
py -3.12 -m fanxing workflow ... --through run --execute-run
```

- 阶段：`precheck → build → qc → gate → run`；默认停在 gate，`run` 标 `skipped`，不伪装通过。
- 每次写 `workflow.json`（agent/项目/镜头/阶段/耗时/产物/overall）；退出码 0 PASS / 1 BLOCK / 2 身份或用法错误。
- 直接调用 `h3_spider batch` / `h3_run_project.py` 只算调试/逃生门，不带 `agent_id`，不算接入。
- 跑前闸要求：8 腿齐全、verdict PASS、`trace_sha1` 匹配、卡文件在 spider 之后未被改；缺腿/改卡 → BLOCK。
- **改了 `shots.yaml` 必须重跑 spider**；否则 gate 报「卡文件在 spider 之后改过」拒跑，这是闸在工作。

## 4. ComfyUI 画布同步

- `h3_run_project.py` 每镜写 `<out>/<tag>_workflow.json`（UI 格式，已 patch 真实图片/提示词/时长/输出前缀），并原子写 `ComfyUI/user/default/workflows/_fanxing_latest.json`。
- ComfyUI 页面 DevTools Console 粘贴 `D:\AIWorkflow\tools\h3_spider\canvas_sync.js`；它轮询 latest，版本变化才 `app.loadGraphData`。
- `FANXING_CANVAS_SYNC=0` 只关 latest 自动加载；per-shot 文件仍写。
- 已验 U05（31 节点，0 error）、U08（33 节点，0 error）；同步只改画布显示，不绕过闸，也不证明 GPU 出片质量。
