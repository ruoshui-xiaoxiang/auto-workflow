**场景层（Robert McKee《故事》）**
- 场景 = 地点 + 价值 + 冲突；由 beat 组成，由"开场价值/收场价值"界定。
- **硬判据**：一场戏必须让价值翻转（正↔负）；开场与收场价值相同 = 「非事件」（non-event）→ 该删。
  ⚠10-02 已降为**带作用域**判据：只对分镜表里标了 `climax: true` 的场生效，其余场不强制（见上文裁定块①）。
- turning point = "事情发生变化"的那一刻；人物目标与对抗力量都用不定式写。

**场景序列层（Dwight Swain）**
- Scene（动作）= 目标 → 冲突 → 灾难（用 "没有，而且…" / "有，但是…" 收尾）。
- Sequel（反应）= 反应 → 困境 → 决定；决定生成下一个目标。
- 交替排列因果才清晰；结果不改变任何事 = 没有赌注 = 该删。

**情节层（Save the Cat 15 节拍，百分比位置）**
- 开场画面 1%／主题陈述 5%／铺陈 1–10%／**催化剂 10%**／争论 10–20%／**进入第二幕 20%**／B 故事 22%／游戏与乐趣 20–50%／中点 50%／坏人逼近 50–75%／一无所有 75%／灵魂黑夜 75–80%／进入第三幕 80%／结局 80–99%／终场画面 99–100%。
- 百分比可套任意时长：2 分钟的片，出事该在第 12 秒、踏上主线该在第 24–30 秒。　⚠10-02 裁定：百分比一律**只作参考**，不换算成秒来排事件（问 3）。

**镜头节奏层（Average Shot Length 实测）**
- 动作片：《谍影重重2》2.4s；现代主流剧情：《通天塔》3.3s、《美丽心灵的永恒阳光》4.7s、《迷失东京》6.6s。
- 慢导演（整片统一风格，非逐镜抒情）：库布里克《2001》13s／《闪灵》12.9s、《德州巴黎》12.6s。
- 换算：90 分钟 900 镜 → ASL 6s。
- **结论：主流 3–6 秒/镜；超过 10 秒属"长镜风格"，必须整片统一，不能每镜都慢。**

**覆盖与剪辑层**
- coverage = 完成一场戏所需的全部镜头；先拍 master（主镜/全景）再拍各景别/过肩/insert，剪辑时挑。
- 剪辑规律：**相邻镜头景别至少差两级**切换才不跳；越过动作轴线 = jumping the line。
- 迁移到 AI：**"生成长度 ≠ 镜头长度"**——一条 15s 生成当 master，成片可剪成 2–3 个短镜；"景别变化"靠多生成几条或对同一条做裁切（裁近景）。
- **落地分工（2026-09-13 定）**：拼接/黑场换幕/音量统一/按时间点裁切/字幕/导出**全由 agent 用 ffmpeg 自动做**（用户明确不碰时间线、说"我剪不好/给我素材我也剪不成电影"）。长镜要切短时，切口先用 **ffmpeg 画面变化/运动量检测**自动标出候选，再给用户 2–3 个候选切口让他"点头"，不要让他自己剪。

**竖屏短剧节拍（一集 1–2 分钟）**
- 单集节拍：**开场钩子 0–5s／冲突推进 5–40s／情绪回报 40–75s／集尾留扣 最后 5–10s**。
- 每集结尾必须留悬念；"爽点隔几集给一次、越给越大"，别一集塞三四个反转。
- 台词：单句 ≤15 字，一集有效台词 200–300 字（全篇约六七百字）。

**⚠️ 尺度不变性（2026-09-13 用户追问"从电影角度看这个认识过程时间还长么"后补正）**
- **百分比尺度不变，秒数随总长缩放**：同一个 20–25%，2 分钟片＝24–30s、8 分钟片＝96–120s、90 分钟长片＝18–22 分钟。　⚠10-02 裁定：百分比一律**只作参考**，不换算成秒来排事件（问 3）。
- 所以"前置太长"这个判断**必须先定目标总长**才有答案：本片前置 99.5s（目标「天堂」约在 114s 处）→ 按 2 分钟短片算是晚 4 倍（崩）；**按 8–10 分钟短片算正好**；按 90 分钟长片算反而太早（该把"认识"写长）。
- **别把竖屏短剧的尺子套到横屏片**：本片画面 1024×576 **横屏**，不是竖屏短剧，那套 1–2 分钟/集节拍不适用。
- **与总长无关、永远要修的**：每镜都同一个"缓→停→缓"、没有快慢对比就是闷——这是**节奏问题不是长度问题**。（体检法：逐场问价值翻转；本片镜2–7 已逐条对过，**都成立**，前置不"平"。）

**剪辑师 pass 实操五原则（2026-09-15 首次实跑第01集得到，⚠️ 我方提出、用户尚未验收）**
背景＝第01集 194.0s 素材一镜未删重剪成 166.2s（−14.3%），改动只在**每镜给几秒 + 从哪一秒切进来/切走**。三幕（结构最重复的一段）压掉 22%。
1. **撞出去的强拍更短**：拍案、墨溅这类物理撞击压到 **1 秒以内** —— 撞击靠"顿"不靠"看"。
2. **该沉的更长**：全片唯一的缓推镜、沉默对峙、核心情绪动作**给足 5s**。
3. **晚进早出**：动作起手直接切进来、动作没完就切走；**不要每一镜都演示完整动作起止**（原片 S02"坐起→叠被→挺直"、S07"拉抽屉→放钱→收钱"就是典型"一格一格演示"，节奏闷）。
4. **同一动作语汇出现三次要递减**：第01集有三次「她举一张纸朝向镜头」，原设计都完整给 3–4s 静止；改成 1.5s → 1.0s → 4.0s（前两次只当节拍，第三次才是宣言）。
5. **镜内"遮丑"靠早出**：AI 生成镜的脏尾/崩尾，用早出切掉比修图便宜。
- **⚠️ 数字正常 ≠ 节奏对**：第01集 ASL 3.5s 落在主流 3–6s 区间内，**但全片挤在 2–5s 窄带、没有一处快过也没有一处慢过 → 节奏是"平的"**。所以判节奏不能只看 ASL，要看**分布有没有起伏**。这条是本文件已有的"永远要修的：每镜都同一个缓→停→缓"在剪辑层的量化版。
- **硬边界**：剪辑只能在现有素材范围内删/压，**做不了加法**。第01集二幕 13 镜、三幕 12 镜里 **0 个全景可用** → 景别梯度补不了，要补必须回分镜层加镜。**效果上限在生成那一刻就定死了。**
