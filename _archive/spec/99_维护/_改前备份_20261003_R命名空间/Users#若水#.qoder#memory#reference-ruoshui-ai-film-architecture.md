## 框架的适用面（10-02 用户定调，优先级高于任何单项目交付）

**「这个框架是跨 agent 跨项目的，不必先认定某个项目」**＋「哈希比对可以延后，主要是框架搭建」
⇒ ① 注册表／规则／校验器一律写成**与具体项目无关**的形态：只登记身份、取值域、落点，

② 长耗时、只服务单项目的测量（如外部资产哈希比对）**让位于骨架闭合**，别拿它占进度。
③ 报"框架到哪一步"要按七层逐层说闭合与否，不要报百分比——他关心的是**还差哪几件结构件**。

### 这一轮学到的（四条，都是"我以为没问题"的地方）

16. **"这批人给过"必须与"文件里写着默认"分开**（★本轮最大的发现）。
    `run.py` 的参数是 `yaml args 默认 ∪ --set`，合完分不出谁是人动的；

    这批**没做过任何决定**也能过闸，正好把「不润色也要显式写 false」的裁定吃掉。
    解法＝`ctx["explicit_args"]`（`--set`∪`--resume`，且必须同步进 `reserved` 保留字表——
    这条是 `test_stage_d` 的 ctx 键对账逼出来的，它抓得对）。裸 CLI 没这清单 ⇒ 降级但**必须 warn**。
17. **`false` 是决定，不是空值**：判"给没给"只看**在不在**（`str(v) != ""`），
    写 `str(v or "")` 就把 `False` 当没给。同一条坑在 `record_run_decisions` 的缺项判定里也差点犯。
