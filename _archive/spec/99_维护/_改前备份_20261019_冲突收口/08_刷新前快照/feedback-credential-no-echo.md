**明文凭证（API key／私钥／账号口令）连片段都不许出现在对话、文档或记忆里**，只允许出现"类型"和"存在与否"。

**Why:** 2026-09-28 我用"把连续 ≥8 位字母数字替换成 `<TOK len=…>`"的脱敏脚本 dump `E:\密钥文件\阿里多模态.txt` 的结构，**阈值取宽了**——那把 key 的前 17 个字符（`sk-ws-H.…` 那段结构）因为分段都很短而没被掩掉，进了对话记录；96 位主体掩住了，但已经是一次真实泄漏。同一天我确实需要知道这份文件里有"两把 PAYG＋一把 Token Plan"，但**"知道类型"不等于"可以打印头部"**。

**How to apply:**
- 探测凭证只输出**派生结论**：类型（`sk-ws-`／`sk-sp-`）、长度、是否有效（HTTP 状态码），**永不输出任何原文字符**。
- 需要键值时只在**本轮进程**里读（`KEY=$(python -c "...print(re.findall(...)[0])")` 这种形态是安全的：命令文本里没有值），用完 `unset`。
- 写完任何含取数过程的产物后自检：`grep -roE 'sk-[A-Za-z0-9._-]{20,}' <产物>` 应为 0（注意 `disk-organization-rules` 这类**文件名会假命中**）。
- **出了这类偏差当场自报**：哪一段漏了、主体是否掩住、有没有落盘，并给出"要不要轮换"的建议。不要等对方发现，也不要说"应该没事"。
- **给远端脚本传口令：别走 stdin**。`ssh … 'bash -s' <<'EOS'` 里 heredoc 已经占着 stdin，
  脚本内 `read -r PW` 拿到的是**空**（2026-10-04 真挂过一次；那次脚本正确地"拒绝空口令"才没写坏配置）。
  正解＝本地临时文件（`%TEMP%`）→ `scp` 到远端 → 远端 `chmod 600` 读用 → `shred -u`（或 `rm`）→ 本地立刻删；
  全程**不 echo、不进 argv（argv 会出现在 ps）、不进对话**。
- **换口令要连带轮换会话密钥**：只改 `adminHash` 不轮换 `tokenSecret` ⇒ 旧 token 仍然有效，等于没关后门。
- **CLI 需要登录态时优先"服务器侧签 token 落 600 文件再 scp 下来"**，而不是拿用户口令去登录：
  既不用碰口令，也避免把口令写进任何命令行/日志；临时 token 文件下载后即删，本地那份 chmod 600。
- **不要为了"能用"去 `journalctl` 翻用户当年首次启动打印的口令**。他没说"帮我找回"就别找；
  顶多告诉他日志里有、或让他自己定一条新的（并如实说明强度风险一次，不劝退也不替他决定）。
