# 跨镜连续性：场景锚定段 + 道具抽帧

## 一、场景也要抽成"场景锚定段"，逐镜一字不改带上（2026-09-13 用户定）

用户看废土镜成片后否掉场景写法：「**荒漠场景还要细化一下，不然现在的画面场景还是单调了**」。之前场景只写「废土荒漠，龟裂沙地，散落垃圾堆」，模型给的画面**"干净得像布景"**、没有纵深也没有材质。

**How to apply:** 场景描写按**可复用锚定段**写（地位同角色锚定），凡用该场景的镜都逐字带上。要素清单：

1. **地面材质** —— 龟裂的盐碱沙地 + 风吹出的细沙纹 + 砾石带
2. **废弃物材质清单** —— 锈蚀汽车残骸（只剩骨架与轮毂）/ 掀翻的塑料桶 / 扭曲的钢筋 / 破轮胎 / 褪色的广告布 / 碎玻璃；并**点名材质质感**（斑驳红锈 / 褪色发脆 / 玻璃反光 / 破布边缘抽丝）
3. **半埋构件** —— 大块构件半埋沙里只露出一角（拉空间层次）
4. **远景轮廓** —— 起伏沙丘 + 风蚀岩脊 + 地平线上**残缺的高架废墟轮廓**
5. **空气** —— 低空浮尘，远景被热浪与空气透视轻微扭曲
6. **前景遮挡** —— 近景放一处半埋轮胎/扭曲钢筋挡一层，画面立刻有纵深
7. **分层光影（关键）** —— 光分三层：**近景落在偏暗的阴影里、中景被日光打亮、远景被雾化的暖灰压平**（空气透视）

## 二、跨镜道具：从"上一镜成片"抽帧当参考图（2026-09-13 用户定）

用户原话：「把这一镜要用到的上一镜里边的道具**抽帧出来**，就是那个伞，然后**作为参考图，一起**」——即跨镜要复用的道具，直接从上一条**已通过的成片**里抽帧，与角色锚点一起作 `reference_image` 喂给下一镜。

**Why:** shot06 要复现 shot05 那把破伞。只靠文字写"破旧遮阳伞"，模型会各渲一把；把上一镜的帧挂上去才能锁住**同一把**。

**How to apply:**
- 抽帧选**道具与场景同框、道具形态完整**的帧（本例 t=6s 最好，另取 t=3.5s 作第二角度）；用**全分辨率原帧**，别用缩略图；抽完拼对照图交用户确认再挂。
- **⚠️ 最大的坑：提示词必须跟"成片实际样子"走，不能跟"灰模/原始设定"走。** 本例灰模 previz 里那把伞是**荧光绿**，而 shot05 成片渲出来是**褪色发白的灰帆布伞**——提示词若仍写"荧光绿"，文字与参考图会互相打架。处置：措辞改中性（"褪色发白旧帆布伞"）+ 补一句「**与参考图里那把伞完全一致：褪色发白的帆布伞面、多处撕裂破洞、伞骨外露、伞柄磨旧**」，让参考图去锁形；"要不要回到原设定色"单独交用户拍板。
- 同理适用于任何跨镜道具（武器/器皿/载具）：**先看成片里长什么样，再写提示词。**
- **⚠️ 抽帧若含写实人脸，会被真人检测拦（2026-09-13 镜2 实测）**：镜2 拿镜3 成片收尾帧 `prev_end.png`（含无音写实 CG 脸）当 `@图片3`，提交报 `InputImageSensitiveContentDetected.PrivacyInformation`（"may contain real person"）。**修法**：换成**不含清晰人脸**的道具抽帧（`prop_umbrella_a.png`，早先已验证过检），或裁掉人脸只留道具局部。**抽帧前先问"这帧里有没有清晰人脸"**——含角色的收尾帧尤其危险（镜4 的 `@图片3` 同样是 `prev_end.png`，跑前也要换掉）。

## 三、接镜：抽上一镜的"收尾帧"当下一镜「开始时」的锚（2026-09-13）

做"苏醒"镜时，`@图片3` 直接抽**上一镜（镜3）成片的最后一帧**（伞撑在她头顶、小Q 扶着伞柄、她仰面平躺）当下一镜的参考图，职责写「用于本镜**开始时**的空间关系与那把伞…**只采用伞的样式与三者之间的相对位置，不采用图中的画风、杂物分布与裁切范围**」。

**Why:** 承接关系的镜（同一场景、同一姿势的延续），最难的不是道具长得像，而是**上一镜怎么收、下一镜就得怎么起**——三者左右前后关系、伞的张开角度、光从哪来，全靠文字描述容易对不上。把收尾帧挂上去，等于把"接点"直接钉死。

**How to apply:** ① 有明显承接关系的镜，**优先抽上一镜的收尾帧**当参考图，而不是只抽道具特写；② 同一张抽帧可以同时承担两件事（道具锁形 + 空间关系锁位），职责句里把"只采用…"写窄，把它不该带的东西（画风、杂物分布、裁切）逐条排除；③ 抽帧一律用**全分辨率原帧**、`-sseof -0.5` 取尾帧；抽完自己先看一眼再挂（本例抽出来那帧正好把伞、小Q、她、废土全貌都收齐了）。

## 四、★动作／打戏的跨镜判据是"相位不重叠"，不是"末态硬接"（2026-09-21 实测改写）

上面第二、三条（抽上一镜收尾帧当下一镜首帧、必须继承真实末态）是**对白／静镜**的做法。做**打戏／动作序列**时它被更省、更有效的规则取代：

**同一主体的相邻镜，只要落在一条轨迹的不同相位（被击中／腾空／下坠／落地）就不算重复；或者干脆换主体换景别。** 观众不会拿上一镜的末态去比下一镜的首态——诛仙成片每 0.5 秒换一镜，因为相邻镜景别与主体都不同。《双姝》刺眼是因为 02 段结束时腿已伸直、03 段又重新提膝＝**同一相位做了两遍**。

**Why:** 2026-09-21 用五镜闭环实测，v1 判废、v2 加空间轴、v3 才通；结论是"硬接末态"在我们的生成能力上代价过高，而"相位不重叠 + 方向匹配剪辑"零额外成本就能掩盖每段独立生成的状态重置。

**How to apply:** 动作镜先排相位表（谁在哪个相位），再排景别（相邻镜别撞车）；只有**同一相位的延续镜**才需要抽末帧硬接。完整七条语法与"施术者与受术者不同框"见 [[feedback-combat-shot-grammar]]。

## 五、★片内切镜回人物＝脸漂；正解是三段链（中段无人在场）（2026-09-24 剑来·剑指 243 帧四切镜实测）

一条 243 帧片内 `[Shot N]` 四切镜、三次切回同一骑士，用户判"**人物没锁住**"。病根不是锚点，是**片内切镜回人物**——每次切镜都是一次重掷，脸每回漂一次。

**修法（三段链）**：A 段＝人物起手单镜（124 帧内不切镜）；B 段＝纯特效 spectacle（剑阵／爆炸／落地，**画面里不出现人物**，漂无可漂）；C 段＝人物收势，**首帧直接抽 A 段成片末帧**（与 A 同源，身份不续不漂）。拼片 A→B→C。

**How to apply:** ① 想要"人物→大特效→回人物"的戏，别用片内切镜，按三段链拆；② C 段首帧必须抽 A 段**成片**末帧，不能回设计稿/首帧图（同本节第三条，但这里锁的是身份不是空间）；③ 这是 [[feedback-split-long-shots]]"默认不分段"的已验证例外——不是时长撑不住才拆，是"切镜回人物"这个动作本身致病，只有这种镜才拆。

相关：[[feedback-character-reference-image]]（角色锚点同理；配饰靠锚点带、不挂就丢）、[[feedback-video-quality-standards]]（同框极远距离做不到、同一镜内画风必须统一；#43 群体特效写法）


## 六、★重渲某一段＝凡"首帧抽自该段末帧"的后继段必须跟着重渲（2026-09-24 剑来 v4 实测）

v4 只打算重渲镜1、镜2，镜B 与镜5 复用 v3。做完镜2 才查出：**镜5 的首帧当初是抽自 v3 镜2 的末帧**——镜2 一换，这条依赖就断了。左右对比实测三处同时变：**人物大小差 2–3 倍、她离云海的高度关系完全不同、色调一边冷灰蓝一边青绿**，直接拼会明显跳变。

**Why:** 链式拼片里"抽末帧当首帧"是一条**真实依赖**，不是一次性动作。上游版本一变，下游的输入资产就失效；这属于"批准版本变更→按依赖复核"的具体形态，不是加戏、不是扩大范围。

**How to apply:**
- 每次重渲某段前，先列**下游清单**：哪些后继段的首帧／道具锚／空间锚是从这一段抽的？有就一起排进重渲，或在文档里显式标注"该下游已失效、暂不拼片"。
- **换首帧后提示词必须逐条按新画面重写**（同一批里镜2 就撞上：原稿写"短光柱刚点燃"，新首帧实际是"细闪电已经连到云顶"→ 事件改写成"细线暴涨成柱＋云顶裂口被撑炸"）。提示词与实际首帧互相打架时，模型会挑一个执行，另一个白写。
- 判接缝是否可用，**把"上游末帧"和"下游首帧"拼成一张左右对照图自己先看**，比等到拼完片再发现跳变省一整轮 GPU。
- 依赖修复属"已批准批次内的中间质检"，可直接办并留痕，不必回头逐次请示（见 [[feedback-collaboration-style]]）。

## 动作的"完成"必须落在同一镜内可见（2026-09-23 太空战镜23 被驳回）
分工成"上一镜充能 → 下一镜光束已经在扫"，用户判定为**"没开炮"**，且认为画面方向错位。
- 规则：主炮/出拳/引爆这类**关键动作要在一个镜内走完"起势→出膛/接触→可见结果"**，不能靠切镜暗示。
- 修法是**接续锚换成上一镜的收尾帧**（`last_22.png`：舰体正面＋炮口白热＋翼炮细光束刚出膛），
  提示词按秒写节拍（0–1.5s 转白热／1.5s 出膛＋炮口爆闪冲击环／2–5.5s 光束贯穿画框、远处小舰依次爆／
  5.5–7s 光晕占满下半框＋后坐抖动），并写明"舰体轮廓与位置全程不变，只改光"。
- 方向接续：出膛方向要与下一镜扫射方向一致（都向右），否则又会被判"错位"。


## 七、★批量改写（翻译／换措辞）时，跨镜一致性靠**公共段一次定译**（2026-10-03 英译批的方法论）

H3 真源要整体改成英文时，量出来 20 份稿子里有 **11 条句子是逐字重复 ×12／×11／×7／×6** 的
（基调句、"招牌无字"句、站位句、`Throughout:` 不变量句…）——**跨镜一致性靠的正是"逐字相同"**。
如果每份各自重译一遍，一致性就在这一次改写里漂掉，而且漂了看不出来。

**做法（可复跑）**：
1. **按句 id 替换，不"读一遍重写一遍"**：先切句（句号／分号／换行），段文本哈希当 key，产 manifest；
2. **公共段（出现 ≥2 次）一次定译成一张表**，逐份复用同一串英文；只逐条翻那些只出现 1 次的句子；
3. **台词 `<d>…</d>` 切句时先保护**，改前改后抽出台词序列逐字比对（条数＋内容都不许变）；
4. **落盘前六道验收，不过就不写**：译文齐全／数字串保真（时间轴、帧数、尺寸）／禁词零命中
   （器材词与 `gun|rifle|spear`）／不新增 `[Shot N] At` 切点／公共段份数不变／现役闸跑一遍不新增 error；
5. **派生件（合订本、快照）不进改面**——改完真源用它的生成器重生成。

**Why:** 这次数字保真检当场抓到我把 `0.0–1.1 秒` 写成 `0.0-1.2s`；没有这道检，它就会以"读起来很顺"的形态
进 12 份真源，之后按错节拍铺镜。相关：[[feedback-evidence-loop-trap]] 同族⑳、[[feedback-destructive-edit-boundaries]]。

## 批量翻译／改写真源时的纪律（10-03 批 15）

跨镜一致性靠的是「同一句话逐字相同」，所以**批量改写必须先抽公共段一次定译**，再按句 id 精确替换；台词与画面可见文字**字节级不动**；改完必须机检：
数字逐串保真（时间轴／帧数／画幅）、公共段重复次数不变、禁词零命中、语言闸 0 命中、格式闸不新增 error——**任一不过就不写盘**。人肉逐份改一定会漂。（来源：20 份 H3 真源英译那一批。）
