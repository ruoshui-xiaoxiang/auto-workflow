## 一、现成"带完整分镜的剧本"——基本不存在

**Blender Studio（开源短片）**：**2026-09 实况＝完整制作文件（含分镜/剧本/shot files）已收进订阅**，€17/月（季付 €11.50/月，季付总 €34.50；团队 €500/月起），**无免费档**，只剩零散 freebie（如 Charge 素材库）。→ **"免费拿现成完整分镜文件"这条路已断。**
- **成片仍免费可下**：CC-BY，**Wikimedia Commons 有 .webm 原文件**（Commons 只收自由许可 → 版权确定性最高），PeerTube video.blender.org 也有下载入口。
- **适合"从小的做起"的无对白短片**：`Caminandes` 系列（Llama Drama 2013 / Gran Dillama 2013 / Llamigos 2016，各 1.5–2.5 分钟，**全程无对白**）、`Glass Half`(2015, ~3min, CC BY 3.0)、`Wing It!`(2023)、`Charge`(2022)。
- **写实向**：`Tears of Steel`(2012, 真人实拍+CG+VFX, ~12min)、`Cosmos Laundromat: First Cycle`(2015, ~12min)。

**日式「絵コンテ集」＝唯一真正"带完整分镜的剧本"现成品**：絵コンテ 每个 cut 都带 镜号/画面/台词/音响/秒数，本身即分镜脚本合一。
- `《今 敏 絵コンテ集 妄想代理人/オハヨウ》`，復刊ドットコム 2023-08，600 页，**¥4,180 日元含税 ≈ ¥200**；收 1 分钟短片《オハヨウ》（NHK「アニ＊クリ15」，今敏生前最后一部完成作品）。缺点＝600 页大部分是 TV 系列，短片占比小；需海淘/代购。
- 选今敏的理由＝**"切点/转场"的世界级样本**，正对痛点。

## 二、淘宝分镜集筛选（三判据 + 实价，2026-09-15 实搜）

**判据（缺一不取）**：① 有明确对应成片、片名可查；② 是**分镜/絵コンテ**（带镜号/时间/动作/台词/运镜），不是设定集/原画集/线稿集（只有画）；③ 正版引进实体书，不是网盘素材包。补一句给卖家的问法：①有没有对应成片（要片名）②是拍摄用分镜还是概念图/AI 出图 ③原书扫描还是自制。

**已被筛掉（占搜索结果约九成）**：¥0.1–3 的"分镜集"（今敏/阿基拉/EVA/咒术/芙莉莲/攻壳/大友克洋…）＝原画线稿扫描或网盘截图，**无镜号、无时间、无运镜**，且不带成片对照；空白分镜本/分镜纸（¥8.8/¥38.7）；设定集与视觉设定集；AI 分镜提示词包（¥1.8–24）；短视频剧本素材包（¥18.8）。

**S 级（真人电影，实价 2026-09-15）**：

## 三、从成片反推分镜（抽切点/景别/运镜）：本地方法与硬限制

**本地件已齐，不用装新东西**（2026-09-15 实核）：
- `D:\AIWorkflow\ComfyUI_H3\python_embeded\python.exe` 带 **cv2 5.0.0（`calcOpticalFlowFarneback` + `DISOpticalFlow_create`）**、numpy 2.5.1、scipy、onnxruntime 1.29.0
- `custom_nodes\comfyui_controlnet_aux` 在装（DWPose/OpenPose，`pose_referee.py` 已在用）
- `D:\AIWorkflow\tools\ffmpeg.exe` 带 `scdet` / `select` / `mestimate` / `vidstabdetect` / `signalstats`

**三层能抽到什么**：
1. **切点与时长** —— ffmpeg `scdet`（或 `select='gt(scene,th)'`），确定性输出每镜起止时间码。最可靠的一层。
2. **景别与主体位置** —— DWPose 人框 → 框高占画面比映射景别，框心映射三分法位置。**盲区：人不在画面的空镜抽不出来，需手工标。**
3. **运镜** —— DIS 光流拟合全局仿射：平移→摇/移、尺度变化→推/拉、旋转→滚转；**抠掉人框只看背景中位流**即可分离"镜头在动"与"人在动"。落 5 类（固定/摇/移/推拉/跟）+ 幅度、速度两个数。ffmpeg `vidstabdetect` 的逐帧相对变换可作交叉校验。

**硬限制（必须先讲清）**：
- **推（dolly）与变焦在 2D 上本质不可分**（不靠深度判不了）——但对本项目够用，只需"在推"这个感觉，不需知道是机器在动还是镜头在动。
- **特写镜的运镜判不出来**（画面几乎全是表情，光流被主体吃掉）→ 这类直接标"不可判"。与 [[feedback-previz-closeup-limitation]] 是同一件事的两面。
- 手持微抖 vs 慢摇需调阈值：要用不同时间窗分离"抖动频率"与"运镜趋势"。

**"复刻"的三条路，按可用度排**：
- **A 结构复刻（推荐，唯一法律干净）**：抽出「切点序列 + 景别序列 + 运镜序列 + 每镜时长」当骨架，把自己的戏往骨架上套。借方法不借表达。
- **B 自产灰模驱动（已在跑）**：Godot 摆机位+运动 → 渲灰模视频 → 当 r2v `reference_video` 把运镜烤进生成结果。**本机 H3 无真人检测、这条路可行**；注意 `reference_video` 只锁运动不锁脸（[[feedback-character-reference-image]]）。
- **C 拿真人影视成片当 reference_video**：**云端不可行**（真人检测 + 版权 + 翻新判定拦——镜1 就是这么转灰模重渲的）；**本地 H3 已于 2026-09-15 打通并实测有效**（见下节"四"）。版权风险仍在用户侧，但他选择用「自造原创角色 + 只取运镜动作不取画风场景外观」来规避。

**⚠️ 关键限定**：抽出来的是**描述性数据**（"库布里克这里用了 13 秒"），**不是"我们这里该用几秒"**。后者是导演判断，必须人定意图。数据给人看，不给模型自动套。

## 四、整段复刻用的"真人影视片段"：来源分三层 + 多主角自造角色（2026-09-15 实跑）

用户 2026-09-15 定了方向：**「不用云端，用本地工作流复刻」** ＋ **「把一段完整的片段切分成 H3 接受的 15 秒内片段，分段复刻再合起来，看能达到原片多少效果」** ＋ **「多主角的画面可以再生成几个角色，你看着生成，尽量原创角色，避免版权问题」**。→ 这条把上面 C 从"不建议"变成"用户已选并授权"的路线。

**片段来源分三层（画质 / 版权 / 可用性）**：
- **① 授权干净可商用**：Blender 开放电影成片（全 CC-BY，**发表必须署名 Blender Foundation**）——`Tears of Steel`（**唯一大量真人实拍 + CG**）、`Sintel`、`Spring`（全片无对白）、`Caminandes` 系列、`Sprite Fright`/`Charge`/`Wing It!`；**注意都是宽银幕**（ToS 1920×800、Spring 2048×858，不是 16:9）。Vimeo 搜后按 License 筛 Creative Commons；Wikimedia Commons。
- **② 公有领域**：Internet Archive `archive.org/details/movies`（＋`Prelinger` 是 1950–70s 教育/工业/广告片，B-roll 富矿）——**画质普遍达不到"画质好"，且国内需代理**。
- **③ 画质顶级但版权受限（只私下练，不进成片不发表）**：**电影预告片**（1–2min、高密度精选镜头 → **适合练剪辑节奏，但碎剪没有完整动作段，不适合演员复刻**）、品牌广告 / Apple「Shot on iPhone」（30–90s、单人完整镜头多、可复现性强）、爱奇艺等官方剧集片段（实测《逐玉》带 iQIYI 水印 + 中英字幕，**提示词写"不得水印/字幕"能把它们压住**）。

**选段标准（实测筛出来的）＝ 真人实拍 + 单人 + 无对白 + 运镜完整 + 3–20 秒**。反例：**碎片式快剪 vlog 完全不能用**（《故梦》30+ 个 2–5 秒碎镜，没法复刻动作）；AI 生成的古偶短片（《月梦莲心》）多为双人戏、AI 感重，可用性一般。

**多主角＝配角自造原创角色**：复刻外部真人片时**不复刻原片演员的脸**——女主仍走无音锚点，**配角用 AI 现造原创角色当锚点**，双人镜两个角色锚 + 画风锚同时挂（图序＝`<Picture 1>`无音 / `<Picture 2>`原创男主 / `<Picture 3>`画风锚）。造角色沿用 **`STYLE_ONLY` 范式**：「画风、光影与渲染质感与参考图1严格一致，但人物面容、发型、年龄完全按以下描述，**不得参考参考图1的面容**」，范例见 `E:\创作\无音项目\工具\gen_wy3_assets.py` 的 `DZ` 字典。

**分段与拼接做法**：按 `ffmpeg scdet` 的**镜头边界**切（不跨镜切，否则一段参考视频里含剪辑点）；每段转 **24fps + `17n+5` 对齐帧数**当参考视频，生成长度也用同值（超出会被节点截断）；跑完按原序 concat，**拼片要重编码并加 `-vf fps:24`**（见 [[reference-ffmpeg-location]]），再与原片做并排对照评估效果。实测：42 秒原片 → 8 段（3–7.6s/段）。

**How to apply:** 用户提"找参考分镜 / 买分镜集 / 复刻运镜"时先走本文件判据；**不要用"买参考素材"来搪塞能力缺口**（他会当场识破）；优先推 **0 元的 CC-BY 成片 + 自抽数据**——省事省钱，且正是要建的能力的第一次运行。
