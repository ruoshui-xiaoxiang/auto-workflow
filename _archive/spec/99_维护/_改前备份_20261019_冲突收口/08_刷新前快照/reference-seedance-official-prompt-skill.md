```

npx --yes skills@latest add "https://arkdocs.tos-cn-beijing.volces.com/skills/" --skill sd25-pe --yes
```

装到 **`<工作区>\.agents\skills\sd25-pe\SKILL.md`**（单文件约 70KB），并 symlink 给 Qoder/Qoder CN/Trae/Cline/Codex/Cursor/GitHub Copilot 等。装完 `Skill` 工具列表里出现 `sd25-pe`（触发语：优化 text/story/multimodal references 给 Seedance 2.5 的文生视频、多参考、关键帧、分镜、blockout、视频/音频编辑、延长）。

## 官方模板（"带参考素材的生成"，分块写法）

```
【生成目标】            —— 视频类型/核心事件、核心主体、主要事件
【参考素材职责】        —— @图片N/@视频N/@音频N 逐份职责，每份都要写"不采用…"
【未采用素材】          —— 逐个列编号 + 禁止用于人物/场景/道具/动作/镜头/声音
【主体与关系】          —— 主体↔素材映射、主体之间的空间/道具/身份关系
【事件脚本】            —— 开始时 / 主要事件 / 结束时（三态，结束时写可观察状态）
【保持一致】            —— 锁身份与数量、服装、道具归属、空间方向、声音关系
```

要点：

- **`@图片N` 逐份职责必须带"不采用"**：如"@图片3、@图片4 用于那把旧遮阳伞的外观…**只采用伞本身，不采用图中的小Q、沈无音、荒漠场景与构图**"。跨镜道具抽帧里必然夹带别的东西，不点名排除就会被继承。
- **【未采用素材】**：素材多时逐个列编号禁止激活（"不要用一个总括句让模型自行分配"）。
- **简单任务可以合并相邻段落，但不得省略实际使用素材的职责。**
- **声音符号**：音乐 `()`、音效 `<>`、台词 `{}`、字幕 `【】`。用 `<>` 标音效时，主体名称不要再使用尖括号。
- **白模分两档**：**粗粒度**只取"动作路径/主体站位/机位/运镜/切镜/光影变化/声音节奏/空间关系"，且必须写**映射句**（"@视频1中的<白模主体A>对应<主体A>"）；**细粒度**保结构/动作/空间/镜头，只换形象、材质、颜色、场景。白模含轨迹线/坐标轴/控制器/相机锥体/文字标记时明确不采用。
- **情绪**写"情绪方向 + 触发事件 + **人物可观察表现**（眼神/眉头/嘴角/呼吸/视线/手部）+ 镜头/光线的可观察变化"，别堆满所有微表情。
- **摄影术语要展开为可观察结果**（浅景深＝主体清晰、背景如何虚化；移焦＝焦点从谁转到谁）；焦距/光圈/快门数值只能补充、不能代替最终可见结果。
- 运镜写"**热门运镜 + 作用主体 + 起始状态 + 方向 + 到达状态**"。
- 还有独立的 **视频编辑模板 / 视频延长模板（前/后延长）/ 关键帧锚点（首帧+其他参考、首尾帧、多关键帧顺序、宫格分镜与故事板）/ 输出合同 / 最终自检** 等章节。

**官方没有单独的负面词字段**（见 [[reference-ark-account]]），负面约束一律写成"不得…"放进 `【保持一致】`。

**Why:** 官方这套比我们自己写的自由散文严谨一个量级——它把"每份素材干什么、不干什么""事件从什么状态到什么状态"都写死了，正好治我们已经踩过的坑（跨镜道具抽帧夹带背景、人物姿势漂移、多素材误激活）。

**实测使用要点（2026-09-13 shot06 v1/v2/v3 三方对照）**：官方分块模板产出**更短更省**（v3 14.05s/303,300 tok ≈ ¥12.74，段落式 v2 20.06s/432,900 tok ≈ ¥18.18），且 `@图片N` 逐份职责的"不采用…"确实堵住了老坑（跨镜道具抽帧夹带背景、人物姿势漂移）。但**"运镜"与"关键动作"会被弱化**：（a）【镜头】的运镜段要写成不可省的硬要求，否则模型全程固定机位把运镜整段省掉；（b）关键动作要写它的**可见结果**并放进【事件脚本】的"结束时"。详见 [[feedback-r2v-prompt-camera]]。

**我们扩展后的块集（2026-09-13 起本项目统一用这套，共 10 块）**：官方 6 块（【生成目标】【参考素材职责】【未采用素材】【主体与关系】【事件脚本】【保持一致】）**＋ 自加 4 块**：

- **【场景与环境】** —— 放场景锚定段（废土荒漠那段，见 [[feedback-cross-shot-continuity]]），逐镜一字带上
- **【镜头】** —— 一条连续运镜的完整时序（起幅→中段→结束），并写明"不可省"
- **【风格与光影】** —— 全片统一基线：画风段 + 质感清单 + 光影（主光动机 + 光分三层 + 浅景深不过曝 + 胶片颗粒）+ **色调大盘（唯一按幕切换的变量）**
- **【声音】** —— 用官方符号写：`<环境声>`、`<角色音效>`；无对白时明确写"画面不显示字幕"

**Why:** 官方 6 块管的是"素材职责 + 事件结构"，但不含画风/光影/运镜/声音的落点；把这四样也块化成**全片统一基线**，才能保证"每条提示词逐字带上同一套画风光影"，同时让每镜只换主光动机与色调（见 [[feedback-video-quality-standards]] 第30条）。

**文档由脚本生成**：`gen_prompt_doc.py` import `seedance_r2v_rest.py` 的 `PROMPTS/CONFIGS` 直接渲染出桌面 `无音_提示词定稿.md`（含基线、场景锚定段、每条镜正文与素材清单、编号映射）——改完提示词跑一次生成器即同步，见 [[feedback-review-production-prompts]]。

**⚠️ 适用边界（2026-09-21 更正，别再越界套用）**：这套十块中文模板是 **Seedance 2.5 的官方语法**，**只对 Seedance／即梦成立**。我们曾把它原样套到本地 MiniMax H3 上当"通用标准"——**H3 的官方规范完全是另一套（三字段／六段英文，见 [[reference-minimax-h3-official-prompt-spec]]）**，这很可能就是 H3 那边"运镜写了不生效""站位距离锁不住"的直接原因。⇒ 写提示词前先确认目标模型，再选模板。

**它现在的定位（用户 2026-09-21 定）＝上游 IR，不是最终输入**：原话「**就算官方格式更好用，我们自己的这个还是有用的，只不过得换种用法**」。三条不可替代的价值：① **可审核**——他看桌面文档审提示词，十块能一眼扫出漏了什么，400 词英文散文没法快速复核（也连带保住 [[feedback-review-production-prompts]] 那道门）；② **可机器校验**——字段化才让 `check_preflight.py` 的 G3/G7 能查"缺【声音】""槽位身份与 sidecar 不符"，英文叙述体很难结构检查；③ **跨模型**——同一份分镜意图要喂 Seedance、H3、也许还有可灵，十块是共同真源。
⇒ 正确用法：**十块当分镜单/规格层，下面挂一个按模型分派的编译器**：`参考素材职责`→`subject_definitions`＋`retention_analysis`；`镜头`→官方受控运镜词表；`事件脚本`→`detailed_description` 的分镜时间线（并补上我们最缺的**毫秒级 `[Shot N] At MM:SS.mmm` 切点**）；`声音`→拆成 `overall_soundscape`＋`non_diegetic_music`。
**同时承认识别出的三处该改**：没有时间码概念（最大缺口）、"幅度小而慢"这类含糊修饰该换成 Type+Amplitude+Speed 三元组、【声音】该拆成环境音效与配乐两块。

**How to apply:** 写/改 Seedance 2.5 提示词时**优先套这个分块模板**；素材有编号引用时逐份写职责+"不采用"；每个镜的事件脚本必须补"结束时"的可观察状态；**素材编号必须与提交的 `images` 数组顺序对齐**（`@图片1` = images[0]，错位等于把职责句挂到别的图上）。用户对本条的态度是"这居然有官方提示词模板"→ 要求全部镜按官方重写。⚠️ 但"官方"分两家：Seedance 的官方是这套，**H3 的官方是 [[reference-minimax-h3-official-prompt-spec]]**，别混。
