r2v（reference_video 灰模锁动作）的提示词必须显式写运镜时序，不能只写角色动作和场景。

**Why:** shot05 v8 重跑运镜比第一版还差，用户评「角色都是对的，主要差在运镜上」。根因是提示词只写了角色动作和场景、没写运镜，镜头全靠灰模 reference_video 带；灰模运镜被改复杂（多段变速/平滑过渡）后 AI 复现漂移。用户纠我「运镜没有这么简单」——运镜有节奏设计（缓→停→急、中段停顿呼吸拍、穿云、跟坠），不是「固定/跟随/拉远」几个词能概括的。

**How to apply:** 用 shot04 第一镜提示词作模板，**内容上**要有「参考视频句（含运镜时序，用 → 连接）+ 画面内容 + 镜头 + 风格」四块，每块至少写一句明确的镜头运动描述 + 停顿呼吸拍；**排版上并成一整段**（见下）。写完灰模运镜关键帧后，把对应的运镜时序同步写进提示词，确保文字和灰模运动对得上。关联 [[feedback-previz-camera-rhythm]] [[feedback-review-production-prompts]]。

**⚠️ 当前标准＝官方 `sd25-pe` 分块模板（2026-09-13 起，取代下面的"并成一整段"）**：用户装上火山方舟官方 Seedance 2.5 提示词工程 skill 后要求"按官方重写"。现行写法是**分块**：`【生成目标】【参考素材职责】【未采用素材】【主体与关系】【场景与环境】【事件脚本】【保持一致】【镜头】【风格与光影】【声音】`，其中 `@图片N` 要逐份写职责**并写明"不采用…"**，事件脚本写"开始时/主要事件/结束时"三态。详见 [[reference-seedance-official-prompt-skill]]。**Why:** 官方模板把"每份素材干什么/不干什么""事件从什么状态到什么状态"写死，专治我们已经踩过的坑（跨镜道具抽帧夹带背景、人物姿势漂移、多素材误激活）。**How to apply:** 新写或改任何 Seedance 2.5 提示词一律用官方分块模板；`【未采用素材】`即使为空也要写"无，本任务的 N 张参考图均已分配职责"。

**（历史态，仅作演进参照）四块内容要并成「一整段」文字（2026-09-13 用户要求）**：曾要求提示词不再分「参考视频句 / 画面内容 / 镜头 / 风格」四段排版，全部合并成一段连贯文字。**Why（当时的理由仍然成立）:** 提交给 API 的本来就是一个字符串——**排版只是给人看的**，文档与 payload 一字不差，审稿才真的有效。这条现在被官方模板取代（官方本身是分块），但"**文档＝提交原文、脚本与文档逐字同步**"这个承诺不变（同 [[feedback-review-production-prompts]]）。

**⚠️ 但"写进提示词"在可灵上不够用，甚至无效（2026-09-22 太空战同帧实测）**：同一张 1344×768 首帧，可灵 `v3_0_turbo` 10 秒样片里我明写了"镜头沿战线缓缓横移"，**抽四帧看基本是同一构图——运镜没执行**；本地 H3 fl2va 同一条反而一直在换取景。根因是可灵服务端自己那句"**the input image is the primary driver**"：它忠实于首帧的构图与像素，**这让它不乱加东西（本地版会凭空长出蓝色行星，它没有），也让它不肯走镜**。
**How to apply:** ① 选引擎时把"**运镜执行度**"当独立一维看，别只看单帧质感/细节；② 在可灵上要运镜，得换手段（运镜句提到最前并写死起止景别、或试带 `story_mode`/`prefer_multi_shots` 的 v3_0、或干脆把"原地动"当氛围镜用、需要运镜的镜交本地）；③ 汇报对照结论时**必须明说静态帧抽样判不了运镜，要看片**——这条结论最后是用户自己看完下的，不是我推的。相关 [[feedback-low-expectation-external-capability]]。

**运镜只能用运动描述、绝不能出现摄影器材名词（2026-09-13，用户指出）：** 提示词里写「locked-off 三脚架锁死」「tracking 侧向轨道横移」「jib-down」这类带器材名的词，模型会把器材当实体渲染进画面——shot05 v8 r2v 的 05A 背景里就冒出几根三脚架状支架（运镜词反成穿帮道具）。改成纯运动描述：机位固定锁死／镜头向前推近／缓缓向后拉远／向侧面平移横移／向上抬升上摇／自上而下俯拍跟随。**Why:** 这类图生视频/参考生视频模型对器材名词是"字面理解"，不是"专业术语理解"。**How to apply:** 所有 r2v/i2v 提示词写运镜时，先检查有没有 三脚架/轨道/滑轨/摇臂/斯坦尼康/无人机/jib/dolly/crane/tracking 这类词，有就换掉。

**官方分块模板下还有两条必须补硬（2026-09-13 shot06 v1/v2/v3 三方对照实测）：**
① **【镜头】里的运镜段必须写成"不可省"的硬要求**——v3 提示词写了"中景起幅 → 随走近推近 → 末段拉远上摇"，成片却**全程基本固定近景、运镜几乎整段被省略**；光"写出来"不够，要写明"若省略任一段视为不符"并复述起止景别。
② **关键动作的"可见结果"要写进【事件脚本】的"结束时"**——v3 的收尾"把伞撑到她正上方"打偏了（伞偏到她侧上方），而 v2 段落式里写"...撑到她头顶遮住天光"反而更准。把结果写进"结束时"（"伞面完全展开、正对头顶、把她的脸笼在伞下的阴凉里"）比在"主要事件"里写动作更管用。
**Why:** 官方模板结构严谨、产出更短更省（v3 = 14.05s / 303,300 tok ≈ **¥12.74** ＜ 段落式 v2 = 20.06s / 432,900 tok ≈ ¥18.18），但"运镜"和"关键动作"这两类**过程性要求**会被模型弱化——需要额外的强度标记。
**How to apply:** 用官方模板写镜头时，【镜头】段一律加"不可省"的措辞；每个"必须发生"的动作都给它的**可见结果**并放进"结束时"。

③ **官方模板不保证"节奏"更好（2026-09-13 镜1 实测）**：镜1（第一幕一镜到底）按官方模板重写后跑出来 **7.07s / 152,100 tok ≈ ¥6.39**，画面完成度更高（空间碎裂的蛛网裂纹、坠入黑洞的涡旋都比旧版更完整），但用户评「**镜1 新版节奏反而没有旧版好**」→ **沿用旧版、新版作废**。
**Why:** 官方模板的结构（【生成目标】【事件脚本】三态…）善于把**素材职责、起止状态、禁止项**写死，但它是**描述性的**——只列出"发生了什么"，不像旧版那样把**节奏设计**（缓→停→急、中段停顿呼吸拍、每段大致时长）当作独立要求写进去。模型照着把 beat 走完，快慢由它自己均分，呼吸拍就丢了。
**How to apply:** 用官方模板时，**节奏要在【镜头】里显式写出来、和 beat 并列**：每段的"缓/停/急"、停顿呼吸拍的位置与时长（"中段停顿约 1 秒"）、整体时长分配；不能只写"依次发生 A→B→C"。判片时把"节奏"和"完成度"当两个独立维度看——**完成度高的版本不一定节奏好**（这次就是反面案例）。关联 [[feedback-previz-camera-rhythm]]。

④ **用「已渲染成片」当 reference_video 做「换画风重渲」（2026-09-13 镜1 定案）**：镜1 官方模板版「节奏不如旧版」后，用户拍板的新路线**不是恢复旧提示词**，而是**把已通过的旧版成片（`shot01_ref.mp4`，上传到 seedance_ref）直接当 reference_video 喂进去，让模型照它的运镜/节奏、用新画风重渲一遍**。职责句写成：`@视频1 用于本镜的运镜、动作节奏与事件时序（<时序>）；只采用运镜、节奏、动作与事件顺序，不采用参考视频里的画风、材质、色彩、光影与人物外观`。
**Why:** 旧版的好节奏就藏在那个成片里——官方模板是描述性的、用文字写不回节奏，但拿成片当运动模板就能原样保住，只换皮（画风统一到全片基线）。**How to apply:** 某镜画面/画风要改、但节奏/动作已经过了，就走「已通过成片当 reference_video + 换画风」；【镜头】段仍要写「缓→停→急→收 + 每段时长」双保险（见 ③）；**风险**＝参考视频若带写实人脸可能撞真人检测（本镜旧版是国漫CG写实、过了；写实风成片能不能当参考视频未验，需先探针一条）。**✅ 已跑通并定稿（2026-09-13）**：镜1 用旧版成片当参考视频换画风重渲 → `shot01_r2v_v8.mp4` 7.07s / 303,300 tok ≈ ¥12.74，用户评「镜1 合意」——这条路线成立。

**逐帧参考图的提示词要对应帧内容，且与整体提示词同格式、画风/质感/光影逐条写明（2026-09-13 用户要求）：** 给关键帧逐张出成品参考图（即梦 image2image）时，用户明确：「**这每张的提示词要对应好，画风，质感，光影都要写明，跟整体提示词的格式一样**」。**Why:** 一批关键帧若共用一句笼统提示词，各帧的动作/景别差异就没人管，出图和帧内容对不上；画风/质感/光影不写全，成片会在帧与帧之间飘。**How to apply:** ① 每帧一条独立提示词，开头是统一的参考句（"以这张 3D 白模预演帧为唯一构图、机位与比例依据，严格保持原图构图、机位、景别、人物位置朝向与画面比例完全不变"）；② 然后按该帧**实际内容**写「画面内容 / 镜头 / 风格」三块，并排成一整段（同本文件上面那条"并成一整段"）；③ 风格块里**画风（写实 CG / 非动画非插画）、质感（材质逐项）、光影（主光动机 / 逆光勾边 / 自发光 / 体积光 / 色调）都要逐条写出来**；④ 可按帧类型（角色近景 / 荒漠远景 / 高空云层 / 角色特写 / 尘雾砸击）预置 4–5 套风格块复用，但每帧的"画面内容 + 镜头"必须单独定制。关联 [[feedback-split-long-shots]]（关键帧怎么抽）[[feedback-video-quality-standards]]（画风统一）。
