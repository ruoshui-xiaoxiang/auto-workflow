用户多次做 AI 成本核算/积分 vs 按量对比，以下是一手定价来源（避免搜到转售商噪音页）。**价格会变，回答前先抓这些页，别凭记忆。**

- **Qoder credits**：https://docs.qoder.com/zh/account/pricing — Pro $20/月含 2000 credits；加购 1500 credits / $20（≈¥144，按 ~7.2 汇率 ≈ ¥0.096/credit）。**Lite 挡已于 2026-09-18 下线**，见下方"Qoder 模型挡位"。
- **DeepSeek 官方 API**：https://api-docs.deepseek.com/zh-cn/quick_start/pricing — V4 Pro 输入 miss ¥4.5/M、hit ¥0.15/M、输出 ¥13.5/M；V4 Flash 输入 miss ¥1.5/M、hit ¥0.05/M、输出 ¥4.5/M；高峰时段翻倍。
- **阿里云百炼 deepseek-v4-pro**：https://help.aliyun.com/zh/model-studio/deepseek-v4-pro — 大陆标准区输入 ¥12/M、输出 ¥24/M、缓存命中 ¥1/M（明显贵于 DeepSeek 官方）。
- **阿里云百炼 图像编辑/生成**（DashScope 原生 API，2026-09-06 实测）：
  - `qwen-image-edit-max`：**¥0.5/张**，支持 1-3 张参考图做角色一致性编辑，原生端点 `POST https://dashscope.aliyuncs.com/api/v1/services/aigc/multimodal-generation/generation`，认证 `Authorization: Bearer sk-ws-...`（key 在 `E:\密钥文件\阿里多模态.txt`）。图片以 base64 data URI 传入（`{"image": "data:image/png;base64,..."}`）。`prompt_extend: false` 关闭模型侧提示词改写。输出 832×1248。

  - **生视频按量（Seedance，按千 tokens 计费；5 秒视频约 50~100 千 tokens）**：
    - `doubao-seedance-2-5`（**2026-09-22 `arkcli pricing models` 全档，元/千tokens**）：**NV2V ¥0.070／NV2V1080 ¥0.077**／V2V ¥0.042／V2V1080 ¥0.046。**⚠️ NV2V 才是"文生／参考图生视频"那一档＝我们常用的档，比 V2V 贵 67%**；V2V 是带输入视频（视频编辑/续写）才用。本条之前这里只记了 V2V 两个数，害我按 ¥0.042 估 NV2V 的单、把云端看便宜四成。
      **计费量实测公式（2026-09-22 真账单）**：`tokens = 宽×高×fps×秒数 ÷ 1024`。720p/24fps/15s → 1280×720×24×15/1024 = 324,000（服务端回 324,900）→ **×0.07 = ¥22.7**。⇒ **时长与分辨率是唯一杠杆**，15 秒 720p＝三条 5 秒；同公式下 5s/720p ≈ ¥7.6。

    - `doubao-seedance-2-0-mini`：V2V ¥0.0056（折扣中）→ 折合约 **¥0.3~0.6/条**（便宜量大）

    - `doubao-seedance-1-0-lite`：T2V/I2V ¥0.01 → 折合约 **¥0.5~1.0/条**（最便宜）
  - **Wan2.1-14B**（方舟托管）：T2V/I2V ¥0.05/千tokens → 折合约 **¥2.5~5.0/条**
  - **一集国漫短剧（1~2 分钟 / 15 镜头）成本估算**：
    - 省钱方案（Seedream 4.0 + Seedance mini）：**~¥14/集**
    - 均衡方案（Seedream Lite + Seedance 1.0 Pro）：**~¥25/集**

- **云端视频生成全网比价（2026-09-07，《无音》定稿层选型；单价按 ~90s/集折算）**——「首尾帧」（首帧+尾帧双图控制）是 [[localai-video-model-plan]] 因果链结构改造的硬门槛：

  - **可灵 v3_0_turbo（2026-09-22 当场实测）**：**100 灵感值 / 10 秒 / 1080p ＝ 10 分/秒**，是 v2.5 的两倍；154 秒出片、输出自动升到 1904×1088、自带 aac 音轨（参数表里没有 enable_audio）。⚠️ 铂金余额当时只剩 1796 分 ⇒ 227 秒整片（≈2300 分）**买不起**，任何"整片交可灵"的估算必须先做这道除法再报，别拿 v2.5 的 5 分/秒套。
  - **海螺02（Hailuo-02）**：MiniMax 官方按量 768P6s ¥2 / 768P10s ¥4 / 1080P6s ¥3.5 / 512P6s ¥0.6（仅 i2v，首尾帧无 512P）；PPIO 价 6s/768P ¥1.8、6s/1080P ¥3.15（≈¥0.3-0.525/s），~¥27-47/集；**首尾帧官方支持**（POST api.minimax.cn/v1/video_generation，契约见 [[reference-minimax-api]]）；发布时全球排名第二。注意**海螺 2.3 更新但不支持尾帧**（与 02 同价；2.3-Fast 768P6s ¥1.35）；02/2.3 在定价页列「历史模型」但仍可调用
  - **MiniMax-H3**（2026-09 新旗舰）：768P ¥0.5/s、2K ¥0.8/s，4-15s 首尾帧+多模态参考，v2/video_generation 端点；H3-Max 极速版 480P/768P
  - **Vidu Q3**：¥0.4375-0.9375/s（pro 1080p = 30 credits/s），**首尾帧模型已上阿里百炼**（`vidu/viduq{2,3}-{pro,turbo}_start-end2video`，media 数组 [首帧,尾帧]，V3 时长 1-16s——与「因果装进 8-10s 镜内」结构方案匹配），~¥39-84/集

  - **腾讯混元生视频**：图生视频 480p 2积分/条、720p/1080p 5积分/条（≈¥0.1/s），~¥9-10/集最便宜但画质中档——省的钱可能被失败镜重跑抵消
  - **即梦 Seedance 2.0**：会员价 ¥1.38/s（~¥120/集），画质顶级但 ARK 账号未开通（见 [[reference-ark-account]]）
  - **Seedance 2.5**（2026-07-31 发布，2026-09-08 桌面调研媒体核算口径）：1080p ≈**2.7 元/s**、720p ≈1.7、480p ≈0.7；4-30s 原生、最多 50 个多模态参考（30 图+10 视频+10 音频）、多轮延长、原生出声；API id `doubao-seedance-2-5-260628`。与 ARK 按千 tokens 口径（¥1.7-3.3/条 5s）互为印证。定位为"长环境镜/首尾帧连续镜头"候选引擎，**未经 A/B 不切主引擎**

**How to apply:** 用户问「积分 vs 自己 API 谁划算 / 模型价格 / 任务成本」时先查对应页。经验判断：长 agent 会话成本大头是重复输入的上下文，**API 侧缓存命中率决定是否便宜**；Qoder 日志（会话 jsonl）的 usage/credits 记录在上下文压缩点后会中断，Lite 通道无记录——基于日志只能做有边界标注的估算，见 [[user-research-ai-profile]]。

**Qoder 会话级取数要点（2026-09-04 实测）**：个人账号无组织级 Usage API；IDE 右下角 Credits 按钮=总量预览、官网 Settings>Usage=按次 Credits Log，均不按会话归集。逐轮精确取数只能读本机会话 jsonl（`~\.qoder\projects\*\*.jsonl` 中 `message.usage.credits/billable/model`，Lite 无记录、压缩后中断）。2026-09-04 已建 `qc-monitor.py` 原型（replay/segment/watch）做会话成本量化，详见项目记忆 [[qc-monitor-cost-tool]]。

**经验规律**：① 成本≈**¥0.042 × tokens/1000**，只要拿到 `usage.completion_tokens` 就能当场报价；② **`reference_video` 是最贵的一项**（灰模全片那条把 token 抬到 77.85 万），去掉它省近一半；③ 参考图几乎不加价（2 张锚点 vs 1 张锚点差在时长而非图数）；④ **成片时长由模型定（`duration=-1`）→ 成本只能事后结算，事前只能按同量级给区间**。报价时按"同路线最近一次实测"给区间，别自己乘。

**"一键自动成片"平台调研（2026-09-27 全网横评，报告落 `一键成片平台对比-2026-09.md`）**

- **先分三物种，别放在一起比**：A 素材拼接型（剪映图文成片/快影/度加/即创/InVideo，**不生成像素**，阿里云官方文档自认"匹配素材库拼接"）；B 生成式单镜型（可灵/海螺/PixVerse/Vidu/即梦工具箱，5–30s 需人接）；**C 剧本级成片 Agent**（小云雀短剧Agent、火山剧创 DramArt、阿里万镜一刻、Vidu Agent、商汤 Seko、腾讯 HyCreator、百度一镜）。看到"一键成片"先问 A 还是 C。
- **★小云雀身份已本机 curl 验证**：`pippit.ai/zh-cn` → **302 → `xyq.jianying.com`**＝剪映官方域＝字节/剪映团队出品＝Pippit 国内形态。与他既有 `pippit-tool-cli`/`xyq-skill` 同源。**小云雀与即梦账号不互通**，小云雀走 Agent 路线、即梦走模型+工具箱路线。
- **"完成度最高"和"效果最好"分属两个冠军，且不在同一出口**：完成度＝小云雀（10万字剧本一键直出、多集连发、全局角色/场景妆造映射；爱范儿实测确认为**真生成式非模板拼接**，角色还原超预期、读懂人物关系）；效果＝模型层 H3 / Wan 3.0 / Seedance 2.5。**但小云雀 API 侧据第三方整理只走 Seedance 2.0/fast、720p**，而字节自家 2.5 已原生 1080p/4K ⇒ 管子最完整的不是画面最好的。
- **★剧创 DramArt 折算价≈裸模型 API 价，编排层加价很少**（用手上 token 公式交叉验算过）：剧创列 Seedance 2.0 720P **1.5 元/秒**，按 `宽×高×fps×秒÷1024 × ¥0.07/千` 算出 **1.51 元/秒**，吻合；2.5 720P 一档约 ×1.5。1元=100积分、开通送 1 万积分、**同页聚合 Seedance 2.5(1080P 5.61/720P 2.27)＋Wan 3.0(1080P 1.98)＋MiniMax H3(2K 1.32/768P 0.83)**。**⇒ 贵的从来不是"一键"，是抽卡次数**（一条可用镜头海外实测要 8–15 次重试）。
- **AA Arena 榜（T2V/I2V With Audio）测的是单条片段观感，不含跨镜叙事/剪辑/字幕**；榜首≠能一键出成片。2026-09-22 数据：T2V 1 Gemini Omni Flash 1233／2 Wan 3.0 1229／3-4 **MiniMax H3 Max 1227·H3 1220**／5 Seedance 2.0 720p 1210／8 **HappyHorse-1.1 1147**（排在 Veo 3.1 1088、Kling 3.0 1095、Sora 2 1083 **之上**，他本地有 happyhorse prompt skill，未验）；I2V 带音频 H3 全球第 1/2。**⇒ 他本地 H3 的单镜上限不低于这些平台。**
- **★反面对撞（最重要）**：掘金《AI短剧市场全链路调研报告》推荐流程原话＝**"都不要直接文生视频，更稳的流程是：先做人设图锁角色→再做场景图锁空间→逐镜头图生视频"**——正是他现有手工链路。同类：澎湃直评小云雀**"镜头级精细控制做不到"**；钛媒体评即梦**"超过一分钟短板显现"**；从业者记录 15s 复杂动作镜头**抽 97 次**；新华社 2026-09-02 点名 AI 短剧"长相雷同、表情僵硬"并要求加 AI 标识；AI 短剧**爆款率 0.124–0.47%、每 77 部只 1 部回本、每分钟算力约 2000 元**。
