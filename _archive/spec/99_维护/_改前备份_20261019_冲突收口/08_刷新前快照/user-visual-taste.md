# 用户的角色 / 服装审美口味（2026-09-16 从新脸与服装盲选里推出来）

## 脸

那轮从 6 张候选脸里，他连挑了 B3 / A1 / A3 / B1 四张。四张的共同点很集中，可作为以后给他出脸/选脸的默认方向：

- **清冷素净那一挂，不是明艳浓颜。** 四张都偏冷调、没有暖血色，五官不夸张——鼻头精致、下颌收得干净、没有攻击性。他**没有**选 F01–F12 里"明艳大气""狐狸眼妩媚"那两个方向。
- **唇是重点。** 四张唇形都饱满，而且都有明确的唇彩光泽。连挑四张不是偶然。
- **碎发压面。** 四张都有发丝盖在脸颊或额角。留白被打破，脸才不像证件照。
- **"贵气"来自湿亮高光。** 鼻梁、颧骨、唇珠上那种湿亮高光一致出现，皮肤的通透感全靠它撑。（但**别放大过头**——A1 那版鼻梁湿亮已接近涂油，属过量。）

### ★★"清冷"来自"素"，不来自"锐"——眼睛别去改（2026-09-16 他亲自推翻我的方案）

我做过一轮"只改眼睛"的 A/B（6 张，把参考脸的"眼尾上挑、眼神锐利"加回去），他看完直接否：**"这几张眼睛有点过头了，对比了一下还是之前的那个效果好看"**，并让 A1 原图重新定为脸的基础。

**Why（机制，比结论更重要）**：
- 我原先断言"参考脸的眼睛锐利、我们出的脸太温顺"——**这个归因是错的**。那张脸上的"锐"主要是**眼镜**撑起来的结构感（见下条），不是眼型本身。
- 更根本：**这张脸上的"清冷"来自"素"——不施妆、不笑、眼神平。加了眼线和上扬之后，不是更冷，是更暖、更现代，变成"化过妆的美人"**，方向反了。
- 附带代价：改眼睛会连脸型观感一起动（B3 那版机位还漂了），不是干净的单变量操作。

**How to apply**：想让脸更有"结构感/攻击性"，**去加上庭的小物件，不要动眼睛、不要加眼线类妆容**。这条优先于"要更惊艳"。

### ★眼镜那件事（他推翻过我的判断）
我建议脸锚去掉眼镜，他先同意了，随后自己补拍一批无眼镜的，再回来说 *"我感觉这个眼镜对她这个脸加分很多的"*——**他是对的**，去掉眼镜那版整体"软了一档"。所以**别把配饰当干扰件默认删掉**；它承担的是结构性职能：给眼睛加框（全脸唯一强横线）+ 与繁复珠宝形成"一繁一简"对位 + 疏离气质。机制拆解见 [[feedback-character-reference-image]]。

### 发色：三个方向都成立，但尚未定
墨黑（对比最强、"贵"一档）、暖栗棕（更柔更暖、锐气少）、银白（最飘、缺压场重量）他都看过、都没否。**但这批是连着新眼睛一起出的，被污染了**——要定发色，得拿 A1 原图**只改发色、眼睛不动**重跑一轮。

### ★机位会掩盖（或暴露）妆容问题——判断必须看正脸（2026-09-16）

同一套眼部处理，**正面机位读作"眼线飞线"（他判"过头"），四分之三侧机位读作"睫毛浓密"（他判"看着还行"）**——因为飞线的尾巴转到脸侧去了、露不出来。他把 A1 起点那三张否掉、却对 B3 起点那三张说"看着还行，不过没有正脸，不好确定"，差异就出在机位，不在处理本身。

**How to apply**：① 他给"过头/怪"这类判断时，先确认**他看到的是哪个机位**，别急着改方案——换机位可能就散了；② **要判断一处改动是否可接受，先出正脸**；只有四分之三侧样本时，结论不可靠；③ **转正脸做对照时不要顺手改那个变量**（写死"不改变眼型与眼部妆容的处理方式"），否则 3/4 与正面就不是同一个 look、没法比；④ 反过来也成立：某个处理只在某一个机位好看时，它是**机位专属**的，不能当角色通用设定。

### ★最终定脸＝同一个人的 5 个机位/光照（2026-09-16 收尾）

他在 A1/A3/B1/B3 之外又把 **B2** 补进名单，说 *"这几张的脸我觉得已经是很好看的了"*——**脸这条线到此收尾**。五张拆开看其实是**同一个人**的 5 种呈现：A1 正面硬光 / B1 正面顶光 / A3 正面暖背光 / B3 3/4 暖侧光 / B2 3/4 顺光。

**How to apply**：他挑脸看的是**骨相与气质是不是同一路**、认不认这张脸，**不是单张的光好不好看**。所以给他出脸候选时，**同一个身份的不同机位/光照比"5 张不同气质的脸"更贴他的用法**（后者他会纠结，前者他能直接定）。相关：[[reference-lora-training-infrastructure]]。

### ★定妆/短剧主角脸要"偶像感/精修好看"，不是"写实真人感"（2026-09-21）

《烬骨辞》定妆他连否本地三版：FLUX 与 SDXL"都好丑"、majicMIX(SD1.5 写实)"稍微好点但没有那种偶像感"。→ **他对主角定妆脸的门槛是"偶像级精修美"，光"真实自然"不够交差。** 这跟前面"清冷素净/别加浓妆"**不矛盾**：他要的是**顶配骨相＋素净妆**（脸本身要惊艳，妆别重）。给这种脸时别拿"写实/自然"当卖点——写实模型那条路他判过、不够，这种精修美基本是即梦/Seedream 的先验地盘。

## 硬表面 / 科幻舰体（2026-09-23 太空战项目里新摸出来的一层）

他对"船"这套语汇的判断跟对脸一样具体，而且**同一根轴：排斥现成的好莱坞模板，要原创**。

- **"太眼熟了"＝剪影撞上了星战帝国级。** 我连着两轮把本地 FLUX 出的太空主力舰给他看，他两次都判"还是太眼熟"——他一眼认得出"楔形舰体＋顶部塔楼舰桥"就是歼星舰。**这条跟服装那条"排斥偏西方剪影"是同一个口味，不是新问题。**
- **他要的三件事：棱角分明、战争利器的狰狞感、秩序感。** 这是他亲口给的形容词，不是我的推断。其中"秩序感"落成了可写的东西：严格左右对称＋同一模块等距重复成排＋长直基准线；"狰狞"落成：前掠装甲齿、内发光腔体、战损凹坑、成组武备。
- **"厚重感"是他最在意的维度，而且我一开始给错了药。** 我拿拉普拉斯方差当尺子把细节密度从 160 一路顶到 2281，他仍判"不够厚重"；他递来 COD:AW 奥林匹斯山号截图，同尺子一量只有 **57**（比我们最空的还空近三倍）⇒ **细节是尺度的敌人**。机制已回写 [[feedback-video-quality-standards]] 第 40 条。
- **他会主动供参照图，而且期望我先量它再评论。** 裸路径递图＝我自己去读＋用同一把尺子跟已有素材并排量，别只给观感。⚠️ 反面教训：**当他说"不够 X"而我的指标显示"更好了"，先假设我量错了维度**，不是假设他不懂。
- **认可的方向**：单体几何／大平面＋软污渍＋极少量成排小灯（灯是唯一尺度线索）；"重工业粗野"（外露桁架＋散热鳍＋缆束）在细节密度上实测最强（1637，顶到可灵那一档）。
- **不认可**：把"狰狞"那套密集细节铺满全船（会毁掉体量，只配当炮口/舱口的局部点缀）；纯文字描述出来的任何"原创"舰形（FLUX 一律回落到帝国级，见 [[feedback-local-first-generation]]）。

**How to apply:** ① 出舰体/机械类先问"这个剪影能不能从一个没看过星战的人嘴里说出来"，说不出就是模板；② 要体量感时**先减细节、先裁画框**，再考虑加结构；③ 他给形容词（厚重/狰狞/眼熟）优先于我的量化指标，并立刻把形容词拆成可写的物理量；④ 借第三方设计＝借"形状祖先"（如青铜钺的比例）不借具体设计，给模型一个**具体的非好莱坞形状来源**比给它十条禁令有效。

## ★画风介质：3D CG 特效被判"太卡通"，真人实景是现口径（2026-09-24 剑来）

用户把薇拉"剑来"测试从"3D CG 圣骑士"整体改为**真人实景仙侠**（原话"整体画风都要真人实景的"），并直接供两张豆包参考图＝白交领广袖纱袍＋黑发高马尾＋银凤冠＋云海——仍在"清冷素净＋东方剪影"同一根轴上，只是**介质从 CG 换成实拍摄影质感**。他的"卡通"判词打的是整体材质词（translucent violet swords＝玩具），不只是颜色。**他直接递参考图＝期望拿来即用**（裁切、去水印是 agent 的事）；两图若不同人（实测脸相似度 0.451）要点名让他定，别默认当同一角色。

**★10-01 追加：他会用"太保守／像旧时代"来判造型，这一判打的是设计语汇，不是布料多少**

复刻誓约胜利之剑那条，他先要"真人亚瑟王＋年轻漂亮＋呆毛＋西方骑士大剑＋鬼刀风格华丽梦幻"（**明确点名西式，这是他对"排斥西式四元素"那条边界的有意越权，别再拿旧边界去挡他的显式要求**），
出图后两轮判词：①「**太塑料感了**」②「**还是不太好看，主要裙子不对，那种一圈一圈的看着有点别扭**」③「**太保守了，审美好像是旧时代一样**」。

**三条判词是三根独立的轴，不要混着治**（我上一轮就是混着治，见 [[feedback-prompt-iteration-priors]] ⑱）：
- 塑料＝**成像材质**轴 → 摄影词治（胶片颗粒／单向硬光／毛孔／磨损氧化）。
- 一圈一圈的裙子＝**形制**轴 → 正解在**他自己的素材库**里：`E:\BaiduNetdiskDownload\中世纪欧洲人物` 与 `西方奇幻人物` 两库的武装女性**下半身没有荷叶层布裙**，一律是「**分片战裙／分片软甲**（金属·皮革竖条片）＋修身长裤／皮裤」或「骑马长袍**两侧开叉**＋**合身马裤**＋高筒靴**外翻靴口**」；华丽写在**铆钉·皮带银扣·丝带·发箍这些件数**上。
- 保守／旧时代＝**设计语汇年代感**轴 → 治它的是六个动作：**不对称**（只一边有肩甲、另一边整个露着）／**一个结构主角**（砍掉多件并列）／**配色有主次**（低饱和主调＋唯一一条高饱和点缀）／**三段对比**（硬甲·软绸·空肩与开衩）／**editorial 光**（大面积暗＋一条窄硬光，正面不补光）／**构图偏离中心＋地平线压低**。梦幻**靠风不靠漂浮光点**。

**⚠ 一条他自己认过的取舍：「华丽」和「当代」不是同一根轴。** 治"旧时代"那轮把画面做成冷·狠·当代，代价是**不再华丽**（裙变成素色柱形）。⇒ 要华丽回来走**材质与结构**（真丝垂坠／细银链／拖地长摆／风拉绸带），**不要回到件数堆叠**。

**"保守"的读法要摊开确认。** 我把它读成**设计上的胆小**而不是"布料少"，理由是他 09-30 自己试过紧身胸衣＋蝶翅＋渔网一轮即自否（见下条）；我把这个读法连同反读法一起摆给他了。⇒ **他给抽象贬义词（保守／旧时代／塑料）时，先拆成可写的物理量并说明我读成了哪个轴，让他有机会纠我的读法**——延续 09-30「别用我自己的分类替换他点名的现象」。

**"找参考图"这条路对他经常是走不通的，别把方案建在"你去随便找一张"上。** 同一轮他说「找不到合适的」，最后是他一句判词＋我回库挖词表解决的。
⇒ 他要参考时，**给"单用途真照片"的拆法**（一张馆藏板甲治高光／一张实拍人像治磨皮／一张夜沙地治光比），不要让他找"一张完美的整体造型图"——那种图不存在。

## 服装

**★他排斥"偏西方"的剪影。** 2026-09-16 他看 C1（冷青银白长裙）说 *"这个就有点偏西方了，没那么好看"*。这四个元素叠在一起就会触发该判断：**立领包到脖子 / 紧身胸衣（corset）结构 / 及踝球状裙撑 / 肩部天使羽翼**。要往东走就换成：**交领或立领露颈 / 云肩或披帛 / 织带束腰（平系一道，不做漏斗形）/ 垂坠直落加飘带**。主色不用动，冷青银白在东方语境照样成立。

**★服装立不立得住，看"硬 / 软 / 空"三段。** C2（他选中的）胸口是**硬晶体**、腰胯是**硬银甲片**、底下是**软纱**、再往下大腿是**完全留白的皮肤**——硬、软、空分明，所以有层次。C1 从肩到脚只有纱和蕾丝、没有一处实的，结果"糊成一片、眼睛找不到落点"。这跟东西方无关，是全纱无对比的必然结果。

**★上庭不能空。** C2 头饰几乎为零，结果是视线往下滑、停在胸口——跟眼镜那件事是同一个病，只是 C2 没解决。

**How to apply:** ① 出脸默认往"清冷素净 + 饱满唇 + 碎发 + 湿亮高光"靠，别往浓艳大五官走；② **脸的"结构"靠加上庭小物件，绝不改眼睛 / 加妆容**；③ 出服装先自检三条——有没有东方剪影、有没有硬材质做对比、上庭压不压得住；④ 拿不准的取舍（删配饰、改发色、东西方路线）就出对照让他选，别替他拍板；⑤ 他给否定判断时，先把它拆成可复用的元素清单（像上面那份西式四元素），下次直接避开。

**★"女主角必须好看"优先于"忠于原著设定"，他自己会承认，别替他保守。** 2026-09-25《武昭君仪》我把他改的服装（唐制宫装）落进文档时，他的原话是 *"虽然不想承认，但是没有一个美丽的女主角，看的人的确不多"*。含义：**当原著/设定要求朴素实用、而市场要求好看时，他选好看**，不需要我拿"原著不是这么写的"去劝。可行做法＝**顺着他的方向找专业依据把它做对**（武周＝唐，宫装反而补上了原书没写的朝代形制），再单独标出唯一真问题（将门之女＋习枪＋搬货 vs 大袖长裙），给"唐制·出门穿法"这种两全解（齐胸襦裙＋半臂收口窄袖＋披帛动手前解下搭臂弯；干活段换唐制胡服/缺胯衫），让他点头而不是我拍板。**顺带收益值得明说**：素色（月白／鸦青／银灰）而非明艳红金才符合他的"清冷来自素"；金簪从袋里道具变成头上道具；湿透的素丝绸变深变重＝"体面被弄脏"自己会说话。

**★走"好看女主"路线时，磨皮美颜是必须项，不是可减项（2026-09-25 他直接纠正我）**。我为了"清冷素净"在定妆提示词里写了"皮肤有真实毛孔与细纹、不磨皮"，Seedream 就把这句实现成**满脸雀斑**（六张全中）。他的判断是：*"既然要走好看的女主，就不能不看颜值，磨皮美颜都要有才行，越好看越好。"*
⇒ 正确写法＝**"偶像级美貌、五官精致对称、皮肤白皙细腻柔焦磨皮、瓷感无瑕、T 区与颧骨湿润高光、伪素颜（不要眼线眼影）、美颜开满但看不出开了"**，并正面禁掉雀斑/痣/斑点/毛孔粗大。
**"清冷"仍然靠"素"（素色服装、不浓妆、不改眼型），不靠"糙"**——这条不冲突。代价要照实报：美颜开满会把唇色推向玫红、把丝绸画成半透明纱（离"将门之女"更远），发现后逐条补约束或让他选。

**★"美颜开满"会走向"油腻"，两者要分开要。** 2026-09-25 我按他"越好看越好"写了"湿润高光／T区颧骨高光／美颜开满"，出图唇变玫红、丝绸变半透明湿纱、脸上一层反光——他一句 **"怎么感觉油腻腻的"** 判废。

## ★2026-10-04：他把"色彩光影"认定为下一个能真正提升画面的抓手（不是再加机器）

  ⇒ 机械筛（按冷暖属性＋L／S 阈值出候选、出对照图）归我，**"进不进常用板"那一刀必须他报号**（[[feedback-i-am-not-the-beauty-judge]]）。

### ★10-04 同日第二句纠正：「色彩和打光不是一个东西吧」

我把 742 色的 HSL 阈值当"清冷素净"的尺子用，他当场分开这两件事。**含义三条，比技术细节重要**：
① 他的"素净"不只在色上——**低饱和很多时候是光的属性**（柔光＋大面积反射自然压饱和），
所以色板筛出来的只是"可用色域"，"素净"那一半得去布光配方卡里筛；
② **两份卡、两套验收**：色板可枚举可本地渲、按 ΔE 与面积比验；打光枚不出色卡，只能同 seed 出图看阴影与明暗结构；
