## 2. 三条使用规则（都是拿崩过的代价换来的）

1. **一批只跑一种挂法。** 纯控制臂夹在"控制＋LoRA 臂"之间跑 **0/3 必崩**
   （`comfy/ldm/lumina/controlnet.py:29` device 冲突：控制分支权重退回 CPU 仍被复用）；
   连跑 4/4 成；混跑前必须先 `POST /free {"unload_models":true,"free_memory":true}`。
2. **参考图是截图就必须先裁 UI。** 未裁的抖音截图会让输出把状态栏／图标列／底部文案条原样画进画面
   （文案带边缘密度 0.78 %→5.71 %）。裁完还要保证宽高比＝输出比，别硬拉。
3. **"复刻风格"和"换人物"是两件事，别指望同一档同时做到。** 实测（ArcFace 余弦，buffalo_l/w600k_r50，
   只作相对读）：

   | 档 | 与源人物本人的相似度 | 读法 |
   |---|---|---|
   | i2i d45 | **0.366** | 保人最好 |
   | i2i d65 | 0.272 | denoise 提一档，身份掉一档 |
   | S6 控制＋风格词 | 0.368 | 与 i2i d45 同级 |
   | S1 控制 | 0.335 | 同上 |

   而"底图仍是参考图、只把提示词换成另一个人的描述"这三帖，与原参考图人物的相似度是
   **i2i65→0.307 ／ S1→0.381 ／ S6→0.489** ——
   **canny 锁得越死，人越换不掉**（S6 那帖 0.489 基本还是同一个人）。
   ⇒ 要"同一个目标风格 ＋ 不同人物"，正解是 **拿目标风格图当 i2i 底、把 denoise 提到 0.65、提示词写新人物**
   （实测 Lab 相关仍 0.980、身份降到 0.307）；
   要"保住这个人"，用 **i2i d45**。
   ⇒ 反过来：**i2i 复刻的是底图自己的风格**。拿真人照当底就出真人照的味儿
   （H2 白底短发照 Lab 相关 0.528、H3 暗背景古装照只有 0.266），它不是"目标风格迁移器"。

## 3. 已知边界

- 全部只在 **768×1344／8 步／cfg 1.0** 这一档量过；σ 建立在 n＝3~4 上，是量级不是精度。
- `Lab 直方图相关` 只量**颜色与亮度分布**，不量质感／笔触：S6 换人那帖肉眼已经很接近目标族，
  读数只有 0.005。别拿它当唯一判据，要和 IRE／光比／人眼一起看。
- 身份相似度跨"真人照 ↔ AI 生成脸"会有系统性偏低（域差），只用于**同批相对比较**。
- 同 seed 逐位相同这一条是走缓存拿到的；**冷启动（重启 ComfyUI 后）同 seed 是否仍逐位相同没验**。
