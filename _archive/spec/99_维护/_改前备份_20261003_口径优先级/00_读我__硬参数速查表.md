## 12. 剪辑节奏与时长基准

| 项 | 值 | 属性 |
|---|---|---|
| ASL 主流 | **3–6 秒/镜**；>10 s 属「长镜风格」，必须整片统一 | 外部行业基准 |
| 实测片值 | 《谍影重重2》2.4／《通天塔》3.3／《美丽心灵的永恒阳光》4.7／《迷失东京》6.6／《2001》13／《闪灵》12.9／《德州巴黎》12.6 | 外部 |
| ⚠ ASL 落在 3–6 不等于节奏对 | 要看**分布起伏**。第 01 集实测 194.0 s→166.2 s（−14.3%），ASL 3.5 s 但全片挤在 2–5 s 窄带 → 节奏「平的」 | 本机实测 |
| Save the Cat 节拍 | 开场 1%／主题 5%／铺陈 1–10%／催化剂 10%／争论 10–20%／进入第二幕 20%／B 故事 22%／游戏乐趣 20–50%／中点 50%／坏人逼近 50–75%／一无所有 75%／灵魂黑夜 75–80%／进入第三幕 80%／结局 80–99%／终场 99–100% | 外部；**百分比尺度不变，秒数随总长缩放** |
| 竖屏短剧一集 | 钩子 0–5 s／冲突推进 5–40 s／情绪回报 40–75 s／集尾留扣最后 5–10 s；单句 **≤15 字**、一集有效台词 **200–300 字** | 外部＋项目口径 |
| ⚠ 横屏片别套竖屏节拍 | 20–25% 折算：2 分钟=24–30 s／8 分钟=96–120 s／90 分钟=18–22 分钟。判「太长」必须先定目标总长 | 尺度不变性 |
| 剪辑规律 | **相邻镜头景别至少差两级**；越过动作轴线＝jumping the line；**生成长度 ≠ 镜头长度**（15 s 生成当 master，剪成 2–3 短镜） | 外部 |
| 剪辑师 pass 五原则 | ① 撞击强拍压到 **<1 s** ② 该沉的给足 **5 s** ③ 晚进早出 ④ 同一动作语汇三次**递减**（1.5→1.0→4.0 s）⑤ 镜内脏尾靠早出 | ⚠ **我方提出、用户尚未验收** |
| 反打硬条件 | 轴线不跳；**切点落在动作最快那一帧**；单镜内部要有接触证据；反应幅度匹配动量；相邻单人镜景别必须交替；**同一组来回第三次要比第一次短**；配比＝少量双人全景定空间 + 大量单人镜做攻防 | 本机实测 |
| 诛仙节奏基准 | 每 **0.5 秒**换一镜（相邻镜景别与主体都不同）；豆包那条 ASL 7.51 s、只有 4 个硬切 | 本机实测（只看画面不读音轨） |
| 激烈结构 | 外部片逐秒：0–4 s 全 <0.09 → 15–24 s 持续 10–24 → 25–29 s 掉回 <0.4。**激烈＝「静 5 s + 持续爬升 10 s 爆发 + 静 5 s」的结构**，不是开头爆一下然后衰减 | 本机实测 |
| 单镜时长 | 默认 **5–10 s**；总时长 ∈ 目标 **±5%**；成片时长 = Σ镜 + 黑场 | 项目约定 |
| 排镜表算术 | 段数 = 总长下限的乘数：5 段 25.9 s／6 段 31.0 s／7 段 36.2 s／8 段 41.3 s | 项目约定 |
| 时长-台词重算 | `Σ台词字数 / 4.7 + (轮数−1)×0.6`，与动作下限取大（**别信摘要里给的时长**） | 本机实测 |
| 时间轴规则 | **一律按成片秒数累加**，不按生成帧数累加（否则每镜背 0.2–1.5 s，45 镜漂出十几秒）；余量一次性交给结尾黑屏 | 项目约定 |
| 多段拼片 | 每段首帧抽上段末帧 + 拼片 **0.15 s 淡接**；合片只去后五段重复的第一帧；**默认硬切，绝不逐段淡出到黑再淡入** | 本机实测 |
| 拆段规则 | 默认**不分段**（一条连续生成优先）；⚠ 唯一已验例外：**片内切镜回人物**必须拆成三段链 | 用户拍板＋例外条款更晚 |
| 关键帧抽取 | 按提示词点名的关键镜抽；重复帧组只留首尾（像素差 ≤3.6 算重复，去重后**重编序号重烧标签**） | 项目约定 |
