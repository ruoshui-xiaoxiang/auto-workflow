# 剧本创作原则 + 质量铁律 QC + 创意细化链

## 剧本创作原则（阶段 0 按需读取）

先读 [专业决策卡](craft-foundations.md) A/B，确认场景目的、人物目标与策略、观众需要的信息，再安排分镜。剧本初定即按 [资产前置](asset-planning.md) 盘点需求与已有素材；获授权的基础资产批次可与分镜并行，不把所有资产工作拖到镜头出图时。

跨场叙事另看A3的人物／观众知识表与铺垫回收；声音看E3的主导／让位／交接。需要验证时间组织时可用 [静态故事板试剪](previz.md)，但它不证明动作或模型执行能力。

- 日常切入、少依赖解释性旁白、背景逐步解锁，是已有项目偏好，不是所有影视作品的强制规范；以当前创作意图为准。
- 用进入关系 → 互动／变化 → 留下结果理解场景功能，不要求每场拍进门和出门。
- 信息密集处检查是否需要反应、等待或消化；不机械在每两个信息镜之间塞空镜。
- 台词/配音走试听候选制。
- **动作拍写成“状态A → 关键事件 → 状态B”**，前后态可辨识，中间因果明确，不只写“缓缓／逐渐”。剧本不配帧，分镜再落实画面与动作节拍。
- 设计时理解招式因果与支撑关系，成片可以合理省略；不是每个姿势都切成独立生成，也不是每镜必须展示完整起止。每镜先问“它新增什么、能否不拍”，不能用镜头数量替代叙事选择。

## 质量铁律（QC 层）

- 必查叙事逻辑、信息顺序与节奏起伏，不能仅凭平均镜长合格判节奏好。
- 逐拍拆解、角色锚定、不冲突首帧；慢动作只用于明确强调拍，不把所有表演压成慢推。
- 含字镜逐字锁内容与版式；对白逐镜并排核对在画人物、开口者及台词。
- 场景空间／光照主要在本镜首帧与素材职责中落实，同时检查跨镜位置、道具、光位；不等于忽略跨镜连续性，也不等于复制上一镜姿态。
- 参考图可能带入杂物与姿态；必要时从干净场景重制，保留必需角色／道具锚，不反复硬修污染参考。
- 对偶镜保持同通道同源和可比条件；画风、人物与场景不能各自漂移。

## 四道审核与动作分项

| 门 | 必查 |
|---|---|
| QC① 剧本／分镜 | 场景作用、跨场信息与揭示、时长、必要动作因果、台词归属、资产需求和实际接口／资源预算 |
| QC② 资产／静帧 | 被审资产的身份／结构、用途与版本；对应镜头的构图、光源、接触和状态；基础设计通过不等于所有派生物通过 |
| QC③ 视频 | 片内动作顺序与路径、支撑与受力表达、身份／道具稳定、运镜与声音、实际起止态及采用的依赖版本 |
| QC④ 成片 | 正常速度连看、切点连续性、跨场信息有无遗漏／提前泄露、声音注意力与同步、字幕、规格和可播放性 |

跨段最低状态表：

```text
镜号｜前段实际末态｜后段实际首态｜位置/朝向/支撑脚/持握/光位
    ｜切点帧号与时间｜方向和速度趋势｜重复起势/倒退/瞬移｜人审结论
```

先正常速度观看，再针对出手、接触、回收、落地和切点连续帧慢查。首／中／末三张只够初筛；端点吻合不证明路径正确，静帧接上不证明速度接上。具体失败案例与操作见 [combat-motion-continuity.md](combat-motion-continuity.md)。

机器检测完成只记 `completed`，用户看过认可才记 `confirmed`；所有小样都交用户审核，而非只给用户看机器标红项。光流大不等于连贯，脸分低／骨架漏检先查尺度、遮挡与模型适配。无法测量记“不可测／需复核”，不冒充通过或已判废。明确未查项目，不把抽样当全片逐帧验收。

## 交接与修订

创作顺序与资产／分镜两条工作线统一引用 [production-protocol.md](production-protocol.md)，本文件不再复制一条不同的流水线。

每次审核应绑定对象版本、用途和依据，实际依赖与修订影响按 [asset-and-resume.md](asset-and-resume.md) 维护。上游采用新版本后，不能仅因旧镜“已过审”就跳过；先标受影响项待复核，确认无影响的分支保留。待复核不授权自动重跑。

视觉和身份基线先审定，局部变化有依据；后续展开仍需判断，不把帧级拆解强加给所有场景。清单检查不能冒充专业决策，具体方法见 [craft-foundations.md](craft-foundations.md)。
