# 预算方案与预估消耗

## 成本变量

- **N** = 镜头数
- **T** = 总时长（秒）
- **K** = 每镜平均关键帧数（首尾帧=2，含中间关键帧 4~6）
- **r** = 重跑率（失败/漂移镜占比，经验 15%~30%）

## 单价参考（选型靠同帧实测 + 用户盲选，非一次比价定死）

| 项 | 通道 | 单价 |
|---|---|---|
| 出图 | 火山 arkcli Seedream（`--input` 参考图 i2i） | ¥0.3/张 |
| 出图 | 本地 FLUX（有可用 LoRA 时） | 0（时间成本） |
| 视频 | 混元 | ¥0.1/s |
| 视频 | 即梦 frames2video/multimodal2video | 积分制（见账号） |
| 视频 | 本地 HunyuanVideo 1.5 i2v | 0（时间成本） |
| 后期 | 超分/插帧/调色/字幕 | 本地为主，云端超分按量 |

## 成本公式

1. 出图 = N × K × P_img
2. 视频 = T × P_vid
3. 3D previz = 本地，主要为时间成本（无增量货币成本）
4. 后期 = 本地为主（可选云端超分增量）
5. 重跑 buffer =（出图 + 视频）× r

**总预算 = 出图 + 视频 + 后期增量 + 重跑 buffer**

## 落地规则

- 开工前给出**预估消耗区间**（下限=零重跑，上限=含 r buffer）。
- 每阶段审核门处复核实际消耗。
- 比价只做初筛，选型靠同帧实测 + 用户盲选。
- 只重做失败镜，不整批重跑。

## 算例（单集 23 镜 / 115s）

N=23，T=115s，K=2，r=20%：
- 出图 = 23×2×0.3 = ¥13.8
- 视频（混元）= 115×0.1 = ¥11.5
- buffer = (13.8+11.5)×0.2 ≈ ¥5.1
- **总预算 ≈ ¥30**（即梦积分通道另算，含重跑上浮）
