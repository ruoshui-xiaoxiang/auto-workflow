# 云端 SD 提示词模板（中文十块）

> **适用**：**云端**通道——Seedance 2.5 视频（r2v）＋ 云端出图（首帧图／定妆图）。
> **不适用**：本地 MiniMax H3。H3 一律用官方 I2VA 骨架（见 `H3提示词工程规则方案.md` §3.3）。
> **来历**：本模板源自 **Seedance 的 sd25-pe 分块写法**，随项目早期云端流程建立；2026-09-28 从 H3 规则中**剥离**，独立成本文档。

---

## 一、十块清单

```
【生成目标】 【参考素材职责】 【未采用素材】 【主体与关系】
【场景与环境】 【事件脚本】 【保持一致】 【镜头】 【声音】 【风格与光影】
```

**必填核心五块**：`【主体与关系】【事件脚本】【保持一致】【镜头】【声音】`

**写作顺序铁律**：先写**不变量**（主体/一致）→ 再写**事件** → 再写**摄影** → 最后补**质感**。

## 二、每块写什么

| 块 | 写什么 |
|---|---|
| 【生成目标】 | 这条为什么存在：从首帧出发／横屏 16:9／单镜／多少秒／一镜到底／场景一句话／本镜事件一句话 |
| 【参考素材职责】 | 每张参考图负责什么、冲突以谁为准（"图1管身份、图2管道具、冲突以图1为准"） |
| 【未采用素材】 | 明确**不采用**参考图的哪些部分（背景／布光／排版）——云端出图必须写，否则像素级继承 |
| 【主体与关系】 | 谁在场、什么关系、谁高手谁菜（能力层次）、站位关系不变 |
| 【场景与环境】 | 场景材质、光、氛围；招牌无字 |
| 【事件脚本】 | 本镜实际发生什么：带时间戳的拍链（起始姿态→轨迹/接触点→受力证据→新几何） |
| 【保持一致】 | 什么绝不能漂：身份／服装／发型／武器状态／道具形态数量／说话人编号／无字 |
| 【镜头】 | 运动**类型＋幅度＋速度**，一条相机指令；禁器材名词（稳定器/摇臂会被实体化画进画面） |
| 【声音】 | 环境底噪＋动作物理声＋非语言人声；明说不要音乐 |
| 【风格与光影】 | 它属于什么世界：光／色／材质／媒介 |

## 三、与 H3 的分工（2026-09-28 起）

| 通道 | 提示词格式 | 首行 |
|---|---|---|
| **本地 H3 视频** | 官方 I2VA 骨架（首行指令＋恰三字段＋正文以 `[Shot 1]` 开头） | `For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.` |
| **云端 SD 视频/出图** | 本模板（中文十块） | 无强制首行 |

**为什么分开**：2026-09-28 A/B 实测（`wzy/ab_tenblock.py`，同首帧/同 seed/同 LoRA，5 seed × 2 臂）

| 臂 | 写法 | 出现乱码条数 |
|---|---|---|
| A | 中文十块（含【生成目标】复述＋`**`加粗＋【】标签＋【保持一致】元叙述句） | **4 / 5** |
| B | H3 官方骨架（同样的正文内容，无标签/无加粗/无元信息块） | **0 / 5** |

乱码原文直接指认来源：`他只说上面上了写说观断的那一句台词`（来自【保持一致】"他只说上面写出的那一句台词"）、`其余时间没有任何他`（来自"其余时间没有任何说话声"）——**H3 会把"写给流程/人看的元叙述句"当台词念出来**。

⇒ 十块不是"格式不兼容"，而是**它的元信息块（【生成目标】复述、【参考素材职责】/【未采用素材】的否定式指令、【保持一致】里的元叙述）会给 H3 多开口子**。所以：**十块留给云端，H3 用官方骨架**。

## 四、在云端沿用十块时的三条注意

1. **【未采用素材】必须写**——云端出图/出片是像素级继承参考图，不写就照抄（例：锚图背景是灰棚，不写"不采用其背景与布光"就会带进来）。
2. **否定式指令在云端有效、在 H3 无效**——云端模型对"不采用X"响应正常；H3 上实测禁令会被当成点名（写"招牌不得有文字"照样长字）。这条差异是分开模板的核心原因之一。
3. **对白仍用 `(S1)` 编号 ＋ `<d>[中文] 原句</d>`**，全片编号统一。
