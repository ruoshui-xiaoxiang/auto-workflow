# 《无音》提示词工程系统模板 v1

> 用途：分镜/场景/运镜/人物/神态/表情/动作/情绪/打光/画质/质感 十一维度的统一提示词写法。
> 依据：Seedance 2.0 / 即梦 3.0 / Vidu Q3 官方指南 + 即梦影视级四要素 + 《无音》项目已冻结的代码体系（ZHU/HAND/BLANK/TAIL/SPEED + 场景代号 + 铁律）。
> 适用：即梦（Seedream 生图 / Seedance 视频）、可灵（I2V）、本地 ComfyUI（FLUX/SDXL）。

---

## 0. 总公式（一切提示词的骨架）

```
[锚] ＋ [主体] ＋ [空间] ＋ [时间] ＋ [镜头] ＋ [风格] ＋ [约束]
```

- **锚**：参考图（定妆/场景锚/前帧）决定"像不像"——只锁需要的维度，锁得过多会覆盖动作/服装。
- **主体**：谁 + 固定特征（身份块，全镜头复用，一字不改）。
- **空间**：场景在哪 + 道具布局 + 时辰/天气（场景块，全镜头复用）。
- **时间**：动作怎么随时间发生（分镜时序，节拍化）。
- **镜头**：景别 + 角度 + 运镜 + 速度。
- **风格**：光影调性 + 色彩叙事 + 质感细节 + 画质参数。
- **约束**：负面清单 + 本项目硬规则（AI 不产字 / 禁武戏等）。

> 对应业界公式对照：
> - Seedance 2.0 进阶：`精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件`
> - 电影感四要素：`光影调性 + 镜头语言 + 色彩叙事 + 质感细节`

## 1. 分镜层（Storyboard）

**一镜一个文件行**，项目导演表已固化字段：

```
镜号 | 起 | 秒 | 幕 | 景别 | 角度 | 运镜 | 画面内容(因果四层欲→阻→行→果) | 挂钩 | 声音 | 灯
```

**分镜时序化写法**（跨秒的多动作镜，按时间轴拆）：
```
0-1秒：<谁><在哪个位置><做什么> → 1-2.5秒：<接着发生什么> → 2.5-4秒：<收束/静止>
```
- 模型内部空间与时间解耦：**空间层**（画面有什么）与**时间层**（怎么随时间变化）分开喂，不要写在一句里。
- 铁律：**一镜一动作**——双主体同框、含字+手部同时、2 个以上主动作 → 一律拆。

## 2. 场景层（Scene）

场景是**可插拔块**，全剧复用，逐镜复述（项目"一景一锚"铁律）。

```
<环境定词> + <关键道具及位置> + <时辰/天气> + <空间关系/方位轴线>
```

项目场景代号（权威副本在 `资产\场景\00_场景定稿与定稿提示词.md`）：

| 代号 | 场景 | 关键不可漂移点 |
|---|---|---|
| `GATE` | 家宅外·崖边柴门院坝 | 屋孤立崖边、石阶小径折进山、门闩麻绳 |
| `HOUSE` | 家宅内 | 三格窗/矮榻/旧木桌/贴地火塘 四件相对位置 |
| `SHOP` | 药铺内 | 百子柜满壁、柜台磨亮、抽屉面无字 |
| `STALL` | 代笔摊（全剧核心） | 矮案非高桌、无字木牌、纸左砚中笔筒右 |
| `STREET` | 暮色长街 | 门板嵌门框、街上无人、影子拉长 |
| `BRIDGE` | 石板桥 | 单孔、石桩系缆、乌篷船 |
| `NIGHT` | 屋内夜（HOUSE 追加） | 火塘唯一光源、贴地光、桌左半照亮 |

**写法要点**：
- **具体胜过抽象**：不写"代笔摊""她家里"→ 模型自由发挥（矮案变高桌实证）。逐字复述场景代号。
- 每镜必须**挂该场景锚图当参考图**（一景一锚），防止背景被重新发明。
- 特写也挂场景锚、不挂角色锚（桌面/地面特写最容易背景飞）。

## 3. 人物层（Character）

**角色身份块**：所有出现该角色的镜头，身份块一字不改（全镜头一致性）。

```
<年龄+骨相气质> + <发式3件> + <衣饰3件> + <配件> + <防漂移从句>
```

《无音》`ZHU`（主角锚，唯一权威）：
```
21岁年轻女子清冷骨相眼尾略长唇色淡不施脂粉面无表情眼下淡青身量高挑坐姿极直，
及腰黑长直发头顶半盘发髻插银质步摇横穿外露两侧蓝花钗额间一点朱砂莲花钿，
月白与鸦青渐变宽袖襦裙料旧洗得发白腰间淡蓝织带末端磨得起毛挂米色小布袋，
交领闭合白色中衣交领最低点只到胸上不露肤裙摆垂坠无开衩
```
- **五件永锚**（步摇/蓝花钗/朱砂钿/渐变襦裙/米色布袋）任何套服必复述。
- **防漂移写部位，不写气质**：只写"端庄""素净"管不住领口裙子（实证三次失效），必须写 `交领闭合…无开衩`。
- **年龄变体**：同脸不同龄 → `ZHU18`（18 岁减龄版：面容更青涩、皮肤更细、气质少年感、禁少女卡通脸/成熟女性）。
- **部件级锚**：手部特写用 `HAND`（纤长/指节分明/指甲齐/白皙/右手食指侧薄茧）＋同 seed，**不挂 ZHU 参考图**（i2i 会拉成胸像并泄漏花钿发髻）。
- **挂参考锁脸**：首帧/视频挂定妆图当参考，提示词写 `必须与参考图1中的女子是同一人，面容骨相严格一致`（可锁脸不锁衣：参考强度调低 0.2-0.3）。

## 4. 神态表情层（Expression）

**表情动词化、局部化**——只写结果（伤心/微笑）模型脸谱化；写过程与部位。

```
<部位/器官> + <可数动作> + <微反应/止住点>
```

| 要表达 | 弱写法（弃） | 强写法（用） |
|---|---|---|
| 伤心忍住 | 她很难过 | 嘴唇颤了一下，下颌微收，目光停在纸上两秒后又移开，眼眶泛红但不给泪 |
| 震惊 | 她很震惊 | 眼睛睁大，眼睫不眨，瞳孔定住，呼吸停了一拍 |
| 拒绝 | 她拒绝 | 手没有落笔，笔尖悬在纸上方，抬眼直视画外，下颌绷紧一线 |

**项目"寄存器"写法**（人设：面无表情为默认，情绪走动作不走脸）：
- 情绪走指节（握笔收紧）、研墨圈数（第 5 圈停顿）、药碗、纸的去向、口型有无。
- 长凝视只给无人对象（纸/糖凤凰/石头）；看人 ≤1s。

## 5. 动作层（Action）

**动作节拍化，禁情绪形容词**：

```
<0-1秒：起始动作> → <1-2.5秒：主动作(可数节拍)> → <2.5-3秒：收束动作>
```

| 规则 | 说明 |
|---|---|
| 给可数节拍 | 不写"慢慢研墨"，写"墨锭绕砚走完三圈，停住" |
| 禁"缓/慢/极缓" | 是导演语气不是速度指令，写进 I2V 会生成慢动作 |
| 加 `SPEED` | 全局正向 `人物动作以正常真实速度自然进行`（负面词无效） |
| 只追加到 I2V | `SPEED` 不进首帧提示词 |
| 静物镜补环境动 | 特写/静帧必须给环境动态（火苗跳/糖浆冒泡/墨面反光晃/窗纸起伏），否则 4s 里画面是死的 |

## 6. 情绪层（Emotion）

情绪**不直说，靠三件套搭建**：

```
情绪 = 上下文事件 + 身体反应 + 环境渲染（光/声/节奏）
```

- **上下文**：因果四层（欲→阻→行→果）先把"为什么"定下来，情绪自明。
- **身体反应**：走 §4 神态或 §5 动作，不写形容词。
- **环境渲染**：用光（暖橙=有人气/冷蓝=疏离）、声音（全静=最重的情绪）、节奏（快慢差）映射。
- 项目例：S43 喝药——事件（白天慢半拍的反面）＋身体（一饮而尽、碗底朝天、下颌动一下）＋环境（炉火明显跳动），情绪出来是"在撑"，无需写"苦"。

## 7. 运镜层（Camera）

**运镜术语**（面板运镜与提示词运镜二选一，勿叠加）：

| 类型 | 词 | 效果 | 使用场景 |
|---|---|---|---|
| 推 | 推近 / push in | 聚焦、张力 | 情绪收紧、强调 |
| 拉 | 拉远 / pull back | 揭示环境、孤独 | 空镜收尾、个体渺小 |
| 摇 | Pan（水平）/ Tilt（垂直） | 展空间 / 上下对比 | 全景展示 |
| 移 | Truck | 横向跟随 | 伴随运动 |
| 跟 | Tracking | 临场记录 | 行走/奔跑 |
| 环绕 | Orbit | 360° 全貌 | 人物登场 |
| 升降 | Crane | 宏大开场 | 史诗感 |
| 固定 | Static | 稳定克制 | 《无音》主流（静/慢/稳） |
| 变焦 | Dolly Zoom | 眩晕恐惧 | 悬疑（慎用） |

**景别**：大远景/远景/全景/中景/中近/特写/大特写。
**角度**：平/俯/仰/侧/背/过肩/鸟瞰；正反打不许越轴。

《无音》风格纪律：**固定机位为主**，全剧仅在 S18 一处允许"缓推"运镜。运动交给主体，镜头保持克制（符合人设）。

## 8. 打光层（Lighting）

```
<主光源类型+方向> + <色温/色调> + <光比/阴影占比> + <氛围光> + <时辰>
```

| 布局 | 写法示例 | 情绪 |
|---|---|---|
| 写"黄昏侧逆光，阴影约 60%" | 不写"夕阳西下" | 电影感、主观 |
| 写"暖黄油灯光，贴地光源，桌面左半照亮" | 夜室内 | 有人气/安全 |
| 写"冷白月光，面部微弱轮廓光，其余全黑" | 深夜独处 | 疏离/恐惧 |
| 写"火光暖橙与夜色冷蓝强对比" | 梦境/宫变 | 记忆/毁灭 |

**项目夜间铁律**：屋里唯一光源=左墙根火塘（`NIGHT` 场景代号），光从画面左侧贴地往上打，桌面左半边/下颌以下照亮，右侧沉黑——夜戏绝不出现右侧光源。
**时辰词**：晨（灰白低角侧光）/ 日（顶光）/ 黄昏（低角度暖橙长影）/ 夜（单一暖源）/ 蓝调时刻（日出前，冷蓝+地平线暖边）。

## 9. 画质层（Quality）

```
<分辨率> + <构图比例> + <技术词> + <项目统一尾缀 TAIL>
```
- 项目尾缀：`写实3D CG渲染，皮肤质感真实，电影感，浅景深，竖幅9:16构图`（TAIL）。
- 比例：全剧竖幅 9:16（漫剧）。即梦：模型 5.0 Lite/5.0Pro，2k 或 4k；可灵：1080p。
- 技术词按需追加：`浅景深` / `深景深`（全景空镜） / `电影感` / `真实皮肤毛孔微纹理`（禁塑料感）。

## 10. 质感层（Texture）

**质感细节公式**——不写"写实"，写可读的材质语言：

```
<材质具体到介质> + <颗粒/镀膜/光晕/暗角 类细节>
```

| 要什么 | 弃 | 用 |
|---|---|---|
| 胶片感 | 写实 | 柯达胶片颗粒，边缘轻微暗角，高光带琥珀色 |
| 布料真实 | 真实布料 | 粗棉/麻，经纬可见，旧布毛边，褪色发白 |
| 皮肤真实 | 皮肤质感好 | 可见细纹与绒感，非塑料光滑 |
| 柔焦梦境 | 朦胧 | 轻微柔焦，边缘渐晕，画面四角微微发暗，雾霭感 |
| 反光 | 亮 | 墨面反光晃动，水面黄昏暖反光 |

**质感与情绪绑定**：梦境=褪色/颗粒/柔焦（S48a-e 已实践：冷青蓝+暗金余烬+雾霭）。

## 11. 约束层（Negative / Constraints）

**项目硬约束（进每条提示词或全局 negative）**：

| 约束 | 写法 |
|---|---|
| AI 一律不产字 | 含字镜写 `纸面空白无字、无图案、无涂鸦`（BLANK），字形后期叠 |
| 禁卡通/2D | `卡通,动漫,二次元,Q版,2D,插画,赛璐璐,塑料感,皮肤光滑无纹理` |
| 禁武戏 | 红线：全剧无刀剑搏杀；梦境的火/烟/宫墙只走意象 |
| 禁慢动作 | 兼容自动更正是 `人物动作以正常真实速度自然进行`（SPEED） |
| 禁服装漂移 | `交领闭合…裙摆垂坠无开衩`（写部位） |
| 手部镜禁挂 ZHU | `refs:[]`＋HAND＋同 seed |
| 禁文字招牌 | 场景一律 `不出现任何文字与招牌字样` |

## 12. 一只完整镜头的组装示例（S43 喝药）

> 场景：夜·家宅内 ｜ 人物：无音（21）｜ 动作：一饮而尽 ｜ 镜头：中近，正，固定 ｜ 3-4s

```
[锚] 参考图：char_e01.png(锁脸) + loc_home_in_fire.jpg(场景)
[主体] 21岁年轻女子清冷骨相…五件永锚…交领闭合裙摆无开衩（ZHU）
[空间] HOUSE 夜：炉火明显跳动暖光在土墙上摇，三格窗矮榻旧木桌火塘原位（场景代号复述）
[镜头] 正面中近景固定机位
[时间] 0-1秒：双手端起粗陶碗举到唇边 → 1-2.5秒：头仰起碗底朝天，喉结动一次 → 2.5-4秒：碗放下，下颌动一下
[风格] 写实3D CG渲染，皮肤质感真实，电影感，浅景深，竖幅9:16构图（TAIL）
[约束] 人物动作以正常真实速度自然进行（SPEED），画面中无任何文字
```

拼装成一条：
`21岁年轻女子清冷骨相眼尾略长唇色淡不施脂粉面无表情，及腰黑长直发头顶半盘发髻银质步摇横穿外露两侧蓝花钗额间朱砂莲花钿，月白与鸦青渐变宽袖襦裙交领闭合白色中衣交领最低点只到胸上不露肤裙摆垂坠无开衩，双手端着粗陶碗仰头把黑药汁喝尽碗底朝天，下颌动了一下，炉火明显跳动暖光在土墙上摇，正面中近景固定机位，写实3D CG渲染，皮肤质感真实，电影感，浅景深，竖幅9:16构图`

## 13. 生产前 checklist（生成每镜前对照）

- [ ] 锚：该镜挂了几张参考图？（锁脸/锁场景/锁动作起点；锁得太碎会覆盖动作）
- [ ] 主体：ZHU 或对应角色块是否一字未改？
- [ ] 场景：场景代号逐字复述？特写是否也挂了场景锚？
- [ ] 动作：一镜一动作？节拍可数（0-1s/1-2.5s/2.5-3s）？无"缓缓"？
- [ ] 表情：情绪走部位/动作，不写形容词？
- [ ] 打光：光源方向+时辰写了？夜间是否唯一贴地火塘光源？
- [ ] 运镜：与面板运镜是否叠加？越轴没有？
- [ ] 画质质感：TAIL 在尾？质感词具体到介质？
- [ ] 约束：含字镜 BLANK？negative 含卡通/塑料？SPEED 只进 I2V？
- [ ] 比例：全镜 9:16？
