# 提示词：可见状态、明确职责与镜头策略

## 统一块与逐镜块

先读项目已确认的风格、角色和场景基线。统一块只放所有适用镜头都成立的事实，逐字复用；逐镜块写人物数量、动作、表情、特殊道具与局部光效。不要把某镜特有的泪滴或“动作小而慢”扩散到全片。

先用 [专业决策卡](craft-foundations.md) 明确本镜功能和选择理由，再编译提示词。以下中文十块是可审规格，不自动等同任何引擎的原生提交格式：

```text
【生成目标】【参考素材职责】【未采用素材】【主体与关系】
【场景与环境】【事件脚本】【镜头】【风格与光影】【声音】【保持一致】
```

H3基础／全参考、Seedance、可灵的实际输出分别按 [引擎规范](prompt-specs-by-engine.md) 和当前接口核对；规格完整不代表必须给每家提交十块正文。

参考编号必须与实际上传槽位一致；逐份写明“采用什么，不采用什么”。普通参考图不能写成首帧硬锁，九宫格不能宣称逐帧条件。参见 [combat-motion-continuity.md](combat-motion-continuity.md)。

## 图像基线

首尾帧提示词＝角色身份锚定＋该镜构图／动作状态＋风格句＋光影三件套。指定角色先挂真实参考图派生；身份烘入首帧后可走fl2va，不在互斥接口强挂参考槽。服装随本镜设定，非必要不把衣服与身份绑定。

```text
身份：{年龄、面部特征、发型发饰、实际脸锚职责}
本镜造型：{服装、配饰、需要保持的道具}
画面：{景别、朝向、起止状态、适用画幅}
```

光影三件套保留为检查类别，再按画面写具体句，不把装饰效果塞满每镜；专业依据与例外见 [专业决策卡](craft-foundations.md) C：

1. 影调／质感：描述本镜实际需要的亮暗关系、高光与暗部信息；柔和高光、颗粒等服从已审项目基线，剪影或死黑可以有明确用途。提示词“8K”不代表实际输出分辨率。
2. 主光动机：交代主导光源方向、相对冷暖与软硬；只在脸可见且画面适用时写眼神光。非自然主义光线须有风格意图，不把三点光当每镜必需。
3. 空间层次：前中后景亮暗关系、遮挡、空气透视，按场景选择体积光和景深。武打全身验证优先看清手脚、武器和接触，不让浅景深遮掉关键动作。

每幕色调、主光动机可变，全片画风与质感基线保持一致或解释其变化；不要以固定光比、饱和度或冷色比例代替审图。其他示例见 [examples.md](examples.md)。

## 动作事件：不是堆姿势，是解释如何到达

```text
【事件脚本】
开头：A在左、B在右，相向站立；A左脚承重，双手护在胸前。
中段：A右膝抬起，右脚向B腰侧伸出；B向画面右侧撤半步，
      A的脚在B身前明确落空。A随即屈右膝收脚，不停留展示伸腿。
结尾：A右脚落回身前，双脚重新站稳；B在撤步后的距离保持戒备。
```

这是单招提示写法示例，不是已验证的生成配方。实际左右与角色职责须跟参考一致；选清接触还是落空，不同时要求“踢中”与“完全避开”。旋转、支撑与回收看不明白时，先补设计而非盲目加帧。完整拆解与接段表见 [combat-motion-continuity.md](combat-motion-continuity.md)。

## 直白、单一的物理状态

用户要求：“避免血泪这种不分明或者夸张的描述……尽量给直白好理解的描述。”概念词可能造成多解，不能代替可见约束；不宣称模型完全无法理解情绪。

- 关键情绪配可见表演：如“下唇压住、视线落下”，而非仅写“破碎感”。细节须在当前景别可见，不把眨眼次数等微小变量当必达指标。
- 物质写颜色、数量、位置／路径和恒定性。例如“右眼角只有一滴透明泪水，沿右颊滑下；始终透明，不变成红色，不出现第二滴”。若需要淡红液体，明确只用那个状态，不来回称作血与泪。
- 判据：没看过剧本的人能否从画面描述这句话？不能就拆成可观察结果；不堆互相抵消的负面词。
- 含字镜逐字锁内容、版式、出现时点；字幕与画内文字分别校对。接口不支持独立负面词时，把必要的“不得”放正文。

## 原生对白：核对画面中的说话者

本地H3曾把女主台词配给画面里的男主特写；这是本项目需要规避的风险，不是所有模型的绝对能力边界。

逐镜并排检查台词、在画人物和开口者。优先让说话者在画；画外音可移至无脸镜，或后期TTS叠加。不要指望“她画外说”一定能防止另一张脸开口；双人镜明确发言次序和非发言者的反应，再审核音画同步。

## 全片统一块的五类陷阱

1. **角色槽位不匹配**：当前本地自审闸曾把统一块里的注册角色名当作必须挂图的声明；fl2va只有首帧时会误拦。按实际人数写“同首帧中的男子／女子”等身份指代，核对闸门规则，不能删除真正必要的角色锚。此为本地工具现象。
2. **全局慢动作限制**：不要统一写“所有动作幅度小而慢”。安静镜与关键出手分开；必要时限定“除事件脚本明确动作外”，不能压住应当发力的那一拍。
3. **人数／场景不适配**：“呼气形成白气”仅在人物在画且环境适用时写，不给器物空镜强加人物。
4. **哑角字面触发**：当前闸门曾以“哑角／无声／全程不出声”等角色词触发检查。真正不开口的镜写全“不出声、不张嘴”；只是张嘴未发声则直写“嘴唇张开一条缝，却没有发出任何声音”。不能为通过检查改变剧情或套用到允许说话的独立剧。
5. **特殊元素全片污染**：眼角液滴、伤痕、局部暖光等只写对应镜；统一段不得替所有镜新增这些元素。

## 每镜明确镜头策略，而非每镜强制运镜

运动镜只选一条主路径，写“起幅→怎样移动→在哪里停”，至多加一个质感／焦点修饰；固定镜同样是明确策略。避免所有镜头都省略策略交给模型，也避免整片都机械锁死。

```text
运动镜：从双人全身画面开始，向右侧平移，保持双方手脚可见，
        在A收腿落地后停止平移。
固定镜：保持双人全身构图，视角不移动，检查出手、格挡和落地；
        人物仍按事件脚本完成整招，不停成姿态展示。
```

可用表述：向前靠近、向后退远、向侧面平移、绕主体沿一条弧线移动、视角向下移动、构图保持不动；焦点转换单独说明，不把它误算成机位位移。不要在正向提示词加入器材名称来代替路径，例如稳定器、斯坦尼康、摇臂、云台、轨道车、滑轨、摄影机、摄像机、三脚架、无人机、dolly、steadicam、gimbal、crane、slider、rig；本地经验中它们可能被画进场景。该禁表是写词提醒，不要整段复制进每镜。

B1／B2的2.2倍／3.4倍是单镜全图光流变化，不是“固定机位必然死板”的结论。武打动作验证可固定机位隔离变量。增强动态先设计清楚人物动作及合理环境响应；更大动作与运镜都可能影响质量，不能承诺身体动作增加没有代价。数据与限度见 [local-render-budget.md](local-render-budget.md)。

## 提示词审核与同步

正式生成先给用户审实际要提交的提示词，改后同步完整审核文档；测试／对照手填提示词、关闭LLM润色。统一块＋逐镜块可从单一真源生成，但先确认项目确有生成器并核对输出，不能口头假设双副本已自动同步。没有生成器就显式同步两份并比对。只保留有效最新版，不留旧版提示词／别名／备份混用；不因此删除原素材。修改规则不等于获准生成。
