# 角色锚定方法与身份复核

## 锚定规则

- 指定角色先带真实参考图，再写素材职责。纯文字不能保证同一张脸；可先用脸锚派生首帧，把身份烘入图像后走fl2va，不强迫互斥接口同时挂图。
- 身份锚定段逐字复用，动作／表情逐镜写。服装、光照随项目确认的本镜设定，不把所有外观变量当成身份；点名要求符合完整人设时才锁相应造型。
- 批量前核对定妆原稿，不用被简化的错误人物描述。逐槽确认身份、职责和重复图；脸锚、造型锚、道具锚不混用。

## 路线选择与局部证据

本地AI优先。既有本地方法对某张目标脸达不到要求时，可用已获认可的云端i2i派生，不把“本地优先”误解为必须重复失败方法，也不把历史失败写成“所有锁脸只能走云端”。云端调用仍需预算与启动授权。

此前FLUX／FaceID等在特定风格化角色上的测试不佳，不能证明所有CG脸嵌入不可用。方法、模型、锚图或脸尺寸改变后，结论需要小样验证；不未经用户同意继续投入失败路线。

参考图是否能做脸锚取决于脸的有效像素、朝向、遮挡和检测结果，不只看整图分辨率。按实际画幅取图，避免让人物卡排版／九宫格冒充高清脸锚；参考图含不需要的姿态、光照或画风时限定职责并实测，不能承诺文字一定排除继承。

参考杂物必要时从干净素材重制；对偶镜保持同通道同源和可比条件。画风不同的参考可只借身份，但须检查输出实际风格是否统一。

## 双人／多人镜：逐脸对锚，分离度只是初筛

1. 不只取最大脸。检查设计在画的每个人，每张可测脸对全部身份锚比较；记录哪个角色、哪帧、脸框尺寸和检测置信信息。
2. 两张脸就近匹配不同锚是有用信号，不是自动合格线；都匹配同一锚提示身份混淆，也可能是遮挡、锚图问题或小脸误差，先复核后判。
3. 同时测静态首帧基线。既有双人首帧相似度约他0.662／她0.521，成片抽样约0.513／0.484，提示不能仅凭统一0.6阈值重跑；不据此直接判整片合格。
4. 检脸数只触发检查：双人只检出一张可能漏检／遮挡／出画；器物镜检出脸可能是真新增人物或误检。须打开画面确认，不能把检测数直接当事实。
5. 端点像素差受运镜、裁切与构图影响；人脸对齐后身份相似度也受转头、模糊、小脸与风格影响。两类分数分开解释，都不替代人审。
6. 用你环境里已装且确认可用的人脸识别库（例如 insightface）；生成进行时判分优先CPU，避免抢显存。抽样报告写抽样数量，不把低分样本数量说成整条漂移帧数。

2026-09-21 W2记录为30个身份抽样中5个低于0.45，尚待画面复核，不能写成“确定5帧换脸”。详见 [local-render-budget.md](local-render-budget.md) 的脚本、产物路径与指标口径。

机器完成记 `completed`；用户看过并认可才记 `confirmed`。身份过关也不等于武打路径过关，分别走 [script-and-qc.md](script-and-qc.md) 的检查。
