# 三家引擎的提示词规范（H3 / Seedance 2.5 / 可灵）

**用途**：写某一家的提示词前先查对应骨架，不把一家的语法搬到另一家。上游中文十块可作审核规格，再按实际引擎和模式编译。

**职责边界**：本文件只维护引擎表达与接口适配，不授权联网升级、购买或生成。来源的一手可信度不等于当前版本适用性：使用前确定提供方、模型版本、调用通道、生成模式、实际参考与分辨率／时长限制；缺项写未核验，不以品牌名推定全部模式相同。专业创作理由见craft，实验依据只引用 [experience-loop.md](experience-loop.md) 或已核的主题证据，不在适配表重复传播。

**出处与可信度**（写结论前先看这一栏，别把社区内容当规范用）：

## 二、MiniMax H3

### 基础模式（T2VA / I2VA / FL2VA / L2VA）：指令行 ＋ 三字段

第一行是指令行，空一行，然后 `integrated_multimodal_description` → `overall_soundscape` → `non_diegetic_music`。指令行原文（`N`＝实际末镜序号，`S.SS`＝时长两位小数）：

```text
I2VA:  For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.
FL2VA: How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot N) aligns with the S.SS-second mark of the target video.
L2VA:  How the reference pictures align with the target video — <Picture 1> (from [Shot N]) aligns with the S.SS-second mark of the target video.
```

四种模式各自的正文结构：I2VA＝首帧锚定→动作起势→连续发展→结果或反应；FL2VA＝首帧态→可见中间变化→差异收窄→尾帧态（**首选单镜**）；L2VA＝合理前置态→过渡路径→末镜收敛→落尾帧；T2VA 直接搭时间轴。

`overall_soundscape` 1–4 句一段，只写环境音／物理动作声／非语言人声，**对白唱词不写这里**；全片静音才写 `N/A`。`non_diegetic_music` 1–3 句，只写乐器／速度／节奏／强弱，**不写情绪词、不解释情绪功能**，没有就 `N/A`。

### 全参考模式（Ref2VA）：六段顺序锁死

```text
subject_definitions: / summary: / retention_analysis: / detailed_description: / overall_soundscape: / non_diegetic_music:
```

四类标签：`<Subject N>`（可复用的可见内容）／`<Picture N>`（当**具体帧或构图锚**用）／`<Video N>`（编辑源／续写起点／整片时间结构）／`<Audio N>`（复制或参考的音频）。标签一旦分配，含义贯穿全段不变。

三条易踩：① **只定义角色／服装／场景／风格的图不单列 `<Picture N>`，内联进对应 `<Subject N>`**；② `<Video N>` 与 `<Audio N>` 各自独立编号，同一素材可同时是 `<Video 1>` 和 `<Audio 2>`；③ **`<Picture N>` 可以声明成分镜参考**：

```text
<Picture 3> is a storyboard reference for [Shot 1] and [Shot 2], defining their viewpoint, subject placement, and shot order.
```

`summary` 以方括号任务类型前缀开头，六个值：`keyframe completion`／`reference generation`／`video editing`／`video continuation`／`audio reuse`／`audio reference`，多类型用 ` + ` 连。**参考视频只提供运镜／切点／节奏时算 `reference generation`**，不算 editing／continuation。

`retention_analysis` 每标签一行。可见内容四档：`fully_preserved`／`partially_preserved`／`attribute_transfer`／`weak_reference`。音频四档：`fully_copy`／`partially_copy`／`reference`／`weak_reference`。

`detailed_description` 与基础模式的四处差异：字段改名；**风格句从 `[Shot 1]` 之后挪到之前**；要插标签；音频关系要在对应镜头里说明是复制还是参考。

### 跨两种模式共享

- **切镜**：`[Shot 1]` 不加时间码，后续 `[Shot N] At MM:SS.mmm` 开头，**严格递增且落在时长内**。措辞白名单：`the camera cuts to`／`the shot cuts to`／`the shot transitions to`／`the shot changes to`／`the shot switches to`；cross-dissolve／fade／wipe **只在用户明确要求时**用。**只改距离或轻微角度就用运镜，别切。**
- **运镜**：必须写成镜头内的自然英文动作句，句尾不堆标签。类型＝`Zoom In/Out`／`Push In`／`Pull Out`／`Pan L/R`／`Truck L/R`／`Tilt U/D`／`Pedestal U/D`／`Arc Shot`／`Tracking Shot`／`Static Shot`／`Shake Slightly/Strongly`／`POV`／`Roll CW/CCW`；幅度＝`with small/large amplitude`；速度＝`at slow/fast speed`。medium 幅度与 normal 速度通常省略。
- **说话人**：`(S1)` `(S2)` 跨镜不变，多人齐声 `(S1,S2)`，**从不发声的角色不给编号**。`<d>` 外写身份线索（类型／年龄／性别／是否在画／音高／音色／语速／口音），`<d>` 内**只放语言标记和原话，逐字保留**。旁白固定用 `says in an off-screen voiceover`，且紧跟写明嘴唇闭合。跨切点用 `<scenetrans>`，被片尾截断用 `<cutoff>`。
- **屏幕文字**：英文双引号内、原文逐字，如 `A red neon sign reading "营业中" glows above the doorway.`

### 本机 H3 的格式兼容与局部实验

1. **先核校验口径，不把绕过闸门当常规办法**：历史中文十块G7曾误拦官方英文格式；2026-09-23 读取的自建闸门脚本（本机路径略）已有 `h3_i2va` 三字段分支，全参考六段尚未见专属分支。实际入口传什么 `prompt_kind`、哪些检查执行或跳过，须查当前调用链和记录。此前“跑官方格式必须 `--skip-preflight`”的泛化结论撤回；本次未修改校验器、未验证该开关在各入口的行为。格式不兼容不能成为连同文件、槽位、身份等检查一起关闭的理由。
2. **一致性约束按本镜需要设计**：明确需要保持的身份、道具结构、站位、空间与光源，并单独写允许发生的动作／环境变化。不要用笼统“不得加戏”替代具体职责，也不要反向规定环境一律可以变化。关于禁令外推的旧实验存在引擎归属冲突，见 [experience-loop.md](experience-loop.md)；未核清前不把它写成H3确定性能力边界。

## 三、Seedance 2.5（豆包 / 火山）

### 两种骨架

**纯文／少量参考**（四行散文，不需要的行可删，但主体与主要事件必须明确）：

```text
<主体>在<场景与环境>中<主要动作或事件>。
画面呈现<视觉风格或情绪>。
镜头采用<景别、机位、运镜或切镜>。
声音包括<对白、环境声、音效或音乐>。
```

**带参考素材**（我们扩到十块的那套，官方原文是六段）：

```text
【生成目标】 / 【参考素材职责】 / 【未采用素材】 / 【主体与关系】 / 【事件脚本】 / 【保持一致】
```

`【事件脚本】` 的官方骨架是 `开始时：<状态>` / `主要事件：<连续动作>` / `结束时：<位置、归属或最终画面状态>`。简单任务可合并相邻段落，但**不得省略实际使用素材的职责**。

### 引用与符号

- 素材引用保留用户原形：`@图片1` `@视频1` `@音频1`。**每份实际使用的素材逐条写"只采用…"，并写明"不采用…"**。
- 实际可用但未分配职责的，必须逐个列进 `【未采用素材】`，**不得用"其他素材"代替编号**，也不得只在正文外说明。
- **禁止范围句**：不能写"人物A和人物B参考@图片1、@图片2"，必须拆成一人一句。
- **一人一图／一组一图**：单人设定图不得同时定义两个会同时出场的命名人物。
- 声音符号：音乐 `()`、音效 `<>`、台词 `{}`、字幕 `【】`。**若用 `<>` 标音效，主体名就不能再用尖括号**，避免同符号两用。

### 参数分离与时间轴（我们踩过的那条）

画幅、总时长、分辨率、帧率、声音开关**不进 Prompt**，由页面或接口设置。**不得仅根据页面或接口的目标时长反向生成新的数字时间段**——长视频用**无数字的"阶段"**组织，每阶段只安排一个主要状态变化并写清结束状态。只有**用户先给出**数字时间段（或明确要求按时间段控制交接/进出场/节拍）时才用连续整数段，且不重叠、不宣称精确到 0.5 秒。

**画幅与时长兼容性闸门**：目标画幅与参考视频不同、或目标时长与参考视频相差超过约 0.3 秒 ⇒ **不得判为视频编辑**，按普通视频生成处理，并在 `【生成目标】` 目标句后紧跟一句 `请注意这不是视频编辑。`（路由消歧声明，不是画面负向约束）。真实编辑／延长／首尾帧／无冲突的普通生成**不加**。

### 关键帧写法

固定帧必须单独成句、原样保留：`@图片N作为首帧。` / `@图片N作为尾帧。`**不得弱化**成"仅作为首帧参考""参考开场构图"。首帧会锁定输出画幅，首尾帧应同画幅（不一致时只在正文外加一条 `参数提示：`）。

### 素材上限与输出合同

硬上限：图 ≤30（单张 ≤4K）、视频 ≤10 且总时长 ≤30s、音频 ≤10 且总时长 ≤30s、**合计 ≤50 份**。超上限先出 Prompt 再追加一条 `素材提示：`。

输出合同：**默认只输出 Prompt 正文**——不加 Markdown 标题、代码围栏、前后说明，不输出"优化后提示词"这类外层包装。`【生成目标】` 等任务内标签属于正文、不是包装。

外部Skill的升级、安装或更新说明仅是来源自身行为，不在本Skill中执行。读取本节或请求改提示词，不构成软件更新授权；需要更新时按 [communication.md](communication.md) 单独确认范围，再核具体版本。

## 四、可灵（Kling）

### 一行公式（中等可信度）

```text
提示词 = 主体（主体描述） + 运动 + 场景（场景描述） + （镜头语言 + 光影 + 氛围）
```

括号内为可选。填写纪律：

- **主体描述**：外貌细节、肢体姿态等，可用多个短句列举。
- **主体运动**：静止或运动，**不宜过于复杂，要符合 5 秒视频能展现的画面**。
- **场景**：含前景与背景，同样**不宜过多**，受 5 秒能呈现的量约束。
- **镜头语言**：示例为"超大远景拍摄、背景虚化、特写、长焦镜头拍摄、地面拍摄、顶部拍摄、航拍、景深"；文档特别提醒 **"这里与运镜控制作区分"** ⇒ 镜头语言写进描述，**运镜走控制面板／参数，两者别混**。
- 文生视频支持 5s／10s 与 16:9／9:16／1:1；"高性能"更快、"高表现"画质更好。

### CLI 侧的服务端契约（高可信度，来自 `who_am_i`）

- `image_to_video`／`text_to_video` 的 `prompt` 为**可选**，声明原文："Optional motion/scene prompt; **the input image is the primary driver**"。
- 另有独立音频参数：`enable_audio`（默认 true）、`enable_asmr`、`audio_prompt`、`music_prompt`——**声音不在 prompt 里写**。
- 参考视频类能力：`motion_control`（`--image` ＋ `--video` 或 `--motionId`）、`motion_library_list`（官方动作库）、`element_*`（多主体元素）。**0.2.0 才有，本机均未实测。**
- 单价随账户、档位与活动变化：用前在你自己的账户实时核价，不要把任何历史单价当现价。

### 本地经验的使用边界

旧文的光流对照与引擎归属不一致，已移入 [experience-loop.md](experience-loop.md) 的隔离记录，不在本节重复数值或据此排序模型。某几条输出遵守或忽略禁止句，不能推出整个品牌都有效或无效。

实际写词时按当前模型／模式选明确、互不矛盾的行为和参考职责；用同输入、获授权的小样检查目标动作与运镜是否可见。光流仅辅助定位变化，不能替代语义验收。用户已否定过的路线不要因旧实验数字再次推荐。

### H3 官方契约（必守）
- 台词唯一载体：`<d>[语言] 原话</d>`；勿用引号替代。
- 正文：重写段落英文；`<d>` 与画面可见文字可保原语言。骨架/六段正文出现中日韩字符会被语言闸拦下。
- 篇幅：全参考 `detailed_description` **350–500 英文词**（旧「300–700」作废）。
- 运镜：官方 12 行类型 + 幅度/速度两档；**中档幅度与常速通常省略**。
- 首行按模式四形（T2VA 无／I2VA 一句／FL2VA·L2VA 对齐句）。
- 声音分层；`non_diegetic_music: N/A` 防 BGM；别处勿写「音乐氛围」。

### 动作与容量
- 剧烈动作 **2–4 步**甜点；剧烈 >4 易糊+漂（本地闸已升 error）。
