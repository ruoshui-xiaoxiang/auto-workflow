# 预算方案与预估消耗

## 成本变量

- **N** = 镜头数
- **T** = 总时长（秒）
- **K** = 每镜平均关键帧数（首尾帧=2，含中间关键帧 4~6）
- **r** = 重跑率（失败/漂移镜占比，经验 15%~30%）
- **P_img / P_vid** = 你所选通道的**实时**单价

## 单价：只给计价方式，不写死数字

任何具体金额都随账户、档位、活动、汇率和时间变化。本副本刻意不保留历史单价——**用前在你自己的账户实时核价**，并把核到的数字与日期记进当次预算表。

| 项 | 常见通道类型 | 计价方式 | 备注 |
|---|---|---|---|
| 出图 | 云端文生图／图生图 | 按张 | 参考图 i2i 与纯文生图可能不同价 |
| 出图 | 本地扩散模型 | 0 货币成本 | 成本是时间与显存；有可用 LoRA 时优先 |
| 视频 | 云端图生视频 | 按秒，或按 token／积分 | 分辨率、帧率、时长、是否含音频都会改变单价 |
| 视频 | 本地视频模型 | 0 货币成本 | 成本是时间；长序列可能触发显存或耗时悬崖 |
| 后期 | 超分／插帧／调色／字幕 | 本地为主 | 云端超分按量另计 |

选型靠**同帧实测 + 用户盲选**，不靠一次比价定死；比价只做初筛。

## 成本公式

1. 出图 = N × K × P_img
2. 视频 = T × P_vid
3. 3D previz = 本地为主，主要是时间成本
4. 后期 = 本地为主（可选云端超分增量）
5. 重跑 buffer =（出图 + 视频）× r

**总预算 = 出图 + 视频 + 后期增量 + 重跑 buffer**

## 落地规则

- 开工前给出**预估消耗区间**（下限=零重跑，上限=含 r buffer），并写明单价取自哪一天、哪个账户。
- 每阶段审核门处复核实际消耗，约 80% 暂停汇报，上限强制停。
- 只重做失败镜，不整批重跑。
- 本地通道也要估时间、显存和存储，不要只算钱。

## 算例（只给数量结构，不含金额）

单集 N=23 镜、T=115s、K=2、r=20%：

- 出图张数 = 23 × 2 = 46 张
- 视频秒数 = 115 s
- buffer = (出图 + 视频) × 0.2
- 代入你核到的 P_img / P_vid 即得总预算

先把张数与秒数算清楚，再乘实时单价；不要反过来用旧金额估算新任务。
