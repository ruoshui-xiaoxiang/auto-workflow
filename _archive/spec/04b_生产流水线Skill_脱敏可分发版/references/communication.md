# 沟通机制（分级 + 节奏）

先讨论再动手的总纲，落到「什么该问、什么默认、什么自动」上，既不越权硬做，也不反复追问细粒度。

## 沟通分级（什么该问、什么不该问）

| 级别 | 场景 | 处理 |
|---|---|---|
| 必问 | 不可逆 / 高成本 / 付费 / 外部发布 / 删改他人资产 / 账户闸门 | 先确认再动，不擅自 |
| 先问后做 | 承重墙决策（篇幅 / 基调 / 主角锚定 / 戏剧钩子等「错一个全废」项） | 只问尚缺的信息，≤4 问/批，不重复已答事项 |
| 默认兜底 | 细粒度选项（风格光影等已有默认值的） | 不追问，用默认值兜底 |
| 自动执行 | 计划与本次启动范围已明确授权 | 用户说「开始」后在该范围内自主执行，不再逐项确认 |

## 启动授权与修改范围

- 方向谈定、样片好评、修改规则，都不等于批准下一批生成。每个新批次／提交生成／长任务需对应的明确启动许可；许可已涵盖的批次内部不反复逐镜问。
- 非平凡搭建先写计划待审；正式生成提示词先给用户审。测试／对照手填提示词、关闭润色，也仍需试跑授权。
- 用户明确要求完善skill时，可完成所需技能编辑与静态校验，不必重新问同一事项；不得借此开新生成、安装模型、上传材料或修改源项目。
- 阶段样片须人审，机器打分不能放行全量。预算、素材范围或方向变更超出已授权范围时暂停确认。

## 不确定性操作

- 操作不确定 → 多沟通、别硬做；宁可先问一句，不猜着往下跑。
- 推荐建议必带权威来源，用户拍板才执行。
- 阶段中遇阻塞 / 方向变更 / 成本逼近阈值 → 及时主动同步，不憋着。

## 沟通节奏（不刷屏、不沉默）

- 阶段前：必要时的外部核验结果 + 待拍板项；不重复已完成且仍适用的研究。
- 试点后：单镜/单张样本 + 人工审核门。
- 全量后：自查汇报 + 可优化项（重点交流）。
- 里程碑 / 成本 80% 阈值 / 上限强制停：主动报。
