# 实时成本监控 + 内容/版权合规预检

## 实时成本监控与止损

预算从「被动预估」升级为「主动监控」。

- **实时累计**：每出一张图/一条视频，累计实际消耗，对比预算区间。
- **阈值触发**：累计消耗达到预算上限约 80% 时暂停，汇报「已用 vs 预算」，问用户继续/收缩。
- **阶段结算**：每阶段审核门处同步报实际消耗。
- **超支止损**：达预算上限 → 强制暂停，用户拍板。

## 内容合规预检

生成前先预检，避免花钱出审核废片。

- **prompt 预检**：预检是否可能命中云端审核（敏感内容/版权角色/文字乱码），先改词再生成。
- **角色/形象合规**：避免直接生成现实名人或受版权保护的角色。

## 版权合规预检

成片可能商用，第三方资产用前核对授权。

- **素材授权**：Sketchfab CC / Mixamo / 视频动捕库，用前核对授权条款（CC 许可类型、是否允许商用、是否需署名）。
- **商用前复核**：成片交付前列第三方素材清单 + 授权状态。
