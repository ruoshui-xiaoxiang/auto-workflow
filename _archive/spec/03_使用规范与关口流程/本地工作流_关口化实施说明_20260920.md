## 2. 关口停住时会发生什么

引擎抛 `GateAwaiting` → 进程退出码 3（被否是 4），状态记 `awaiting_human`，同时：

- HTML 报告那一格变橙色 `awaiting_human`（报告 2 秒自动刷新）；
- `D:\AIWorkflow\logs\workflows\待批关口.txt` 追加一段人话：关口编号、项目、run_id、主题、待审素材编号表、提示词全文（H3 会附）；
- Windows 气泡弹一条（20 秒，不阻塞）；
- `gate_approvals.json` 记一条 pending。

批准三条路，任选：

1. 在这儿跟我说一句「过」（我执行批准 + 续跑）；
2. 双击桌面 **`关口一键批准.bat`** —— 先列待批，按键确认后**只批最近一条**并自动续跑它那次运行（不用 ALL，全批会把你没看的那条一起放过去）；
3. 手敲：`py run.py --approve last H3` → `py run.py --resume last`。

`--resume` 会自动回放上次台账里记的参数（不用再敲一长串 `--set`），并且**跳过已完成的步骤**——漂一镜不再整批重烧。批准按"内容指纹"记：提示词/锚点/分辨率/帧数/LoRA/主题任一改变 → 旧批准失效，重新上报。

### 素材怎么呈给你审（H2 / H4）

会话里给你两份东西，都由 `tools\make_review_sheet.py` 生成，每张图每列片都带编号：

```
py D:\AIWorkflow\tools\make_review_sheet.py ^
   --files "候选1.mp4,候选2.mp4" --labels "说明1,说明2" ^
   --clip 4.2 --height 460 --out-name shot5_AB ^
   --also-copy-to "E:\图像影音资源池\<项目>\批次\<run_id>\呈审"
```

产出 `grid.png`（每条 × 12%/50%/88% 三个取样点的静帧表）与 `clip.mp4`（两条同高并排、时间对齐的无声短片，左上角数字＝编号），并打印编号映射表。你回编号即可。为什么两种都要：静帧能比形态与服装，比不了流畅度；动效只有并排短片能看出来。

## 4. 验到什么程度（实测，不是"应该可以"）

- **历史废片回溯**：9-18 那四条的原参数重放，G2 报「槽2 与槽4 md5 全等」，G3 报「声明薇拉、槽内实挂白玖璃」（补了身份卡之后，不需要我手工标注就能判）。这四条当时白烧约 30 分钟 GPU。
- **A/B 原参数**：864×1536 那条 → error 0，warn 4（189px 脸、102→90 截帧、"蝶形/羽翼"字面化）。全是真问题，不是误报。
- **故意做错**：768×1344、少挂一张、写"稳定器/摇臂"、挂 fl2v LoRA → 四条 error 全中。
- **端到端**：`selftest_gates` 停关口(退3) → 待批清单/报告状态 → 一键批准 → 续跑跳过已完成步骤 → 成功。这条已固化成测试 `tests\test_gate_e2e.py`，跑一遍 0.6 秒。
- **真实主通道干跑**：`h3_ref2va_video --project 仙戮 ...`（B 臂参数）→ 交付根自动切到 `仙戮\批次`、跑前自审通过（4 条警告）、停在 H3 等你。**没提交生成，GPU 未动。**
- **手机端媒体实测**：会话里发的编号图与 mp4 短片，你回"都能看" → H2/H4 就此定在会话里审，飞书退出关口链路。
- 测试总数：引擎 40 → **64**（`test_gates_phase1.py` 12 项、`test_gates_phase3.py` 10 项、`test_gate_e2e.py` 1 项、`test_review_sheet.py` 1 项，余为原有）。
- 顺手修掉两条**一直红着**的陈旧断言：一个 mock 的是 `requests.post` 而代码早已改走 `SESSION.post`；一个把交付根路径钉死成 9-14 换掉的旧值（改成按语义断言暂存/交付分离）。

## 5. 还差什么（没做的都在这）

1. **G9 出片后技术自检**（分辨率/帧率/音轨有无/静帧占比/光流幅度）——没实现。设计里它是"H4 之前先把明显废片挡掉"，但需要你点头再建（判据：它立刻产出一条镜的客观指标报告，不用先建别的）。
2. **H1 分镜表 / H2 锚点选定 / H5 重做范围 / H6 成片验收** 四个关口未接进引擎。H1、H2 本来发生在引擎之外（写分镜、挑锚点是跟我对话做的），要接就得先规定这两步的产物格式。
3. **10 个裁判件仍躺在 `tools\`**（structure/pose/depth/temporal_referee、qwen_judge、vl_judge、best_of_n、check_continuity、annotate_shot、score_generation_style）。按你的规矩：搬走算清理，需要你圈范围。
4. **`ComfyUI_H3\output\` 那 31 条视频（49.9MB）源文件仍在**，A/B 已复制进仙戮批次夹并 sha256 复核过；删不删等你一句话。
5. **引擎路径的 `ref_videos` 建图只做了离线核对**（节点接线与 run_h3.py 完全一致，图从 18 节点变 22 节点），**没有真提交过一条**。第一次真跑请盯一眼。
6. 300px 脸锚阈值是启发式，不是硬界（实测 189px 仍保住身份，128px 偏弱），报的时候带限定词。
7. 服务器那摊（登录限流 + 目录 707 + root 跑站 + 内核跟踪）一律未动，等你单独发话。
