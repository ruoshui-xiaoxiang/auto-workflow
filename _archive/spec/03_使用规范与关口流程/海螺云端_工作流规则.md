# 海螺／MiniMax 云端 · 工作流规则（通道真源）

★ 存在理由同 `可灵云端_工作流规则.md`：2026-10-02 用户裁定 `kling`／`vidu`／`hailuo` 各立独立通道。
本条是三条里**最容易读错**的一条，所以第一行先把混淆点钉住。

🔴 **与本地 H3 同源、不同契约**：同一个厂商（MiniMax），但——
- 本地 H3＝自部署权重（pruned INT8，16GB 显存档，跑的是 ComfyUI 工作流），
  提示词走**官方 I2VA 骨架五条**（首行指令＋空行＋三字段各恰一次），由 G7 的 `_g7_skeleton` 把关。
- 海螺云端＝API 调用，参数面与计费面都不一样，**不吃那五条骨架**，也不该被骨架判据审。
⇒ 把 `hailuo` 路由进 `cloud`（现状）会让它的稿子吃**云端 SD 中文十块**判据；
   路由进 `h3` 会更糟（那是把云端稿按本地骨架审）。两种错配都出现过，这正是本通道被单列的理由。

- 通道 id：`hailuo_cloud`
- 上游登记：`08\reference-minimax-api.md`（API 接入与密钥文件位置）、
  `08\reference-minimax-h3-local.md`（**本地**部署，别混用）、`08\reference-hailuo-design-tool.md`
  （海螺 AI 设计工具＝Electron 桌面 GUI，黑盒、无稳定可编程入口）、`08\reference-ai-pricing.md`（云端价）

## 一、已经确证的

1. 本机有 MiniMax 云端 API 通路（凭证在 `E:\密钥文件\` 下，具体文件名见 `reference-minimax-api.md`；
   本文件**不写凭证内容、不写路径细节到可分发副本**）。
2. 云端价有真实账单口径（例：某档按 token 计价、15s／480p 一次的实际花费已记录在
   `reference-ai-pricing.md`）⇒ 报价前必重查目录，不拿旧数算新账。
3. 海螺 AI 设计工具是 GUI 黑盒 ⇒ 它**不是**本通道的自动化入口，别把"工具里能点出来"当"流里能跑"。
4. 本地 H3 的 T2VA／I2VA 参数与耗时**已在本地实测**，但那些数属于本地通道，不适用于本条。
