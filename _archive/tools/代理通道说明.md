# 云服务器浏览通道（SOCKS5）

基于 `47.250.138.158`（阿里云马来西亚）的 SSH 动态转发，零服务端安装、密钥认证、随时可关。

## 一键用法

```powershell
# 开通道（默认 127.0.0.1:1080）
powershell -ExecutionPolicy Bypass -File D:\AIWorkflow\tools\proxy_start.ps1

# 用代理启动浏览器（edge / chrome / firefox）
powershell -ExecutionPolicy Bypass -File D:\AIWorkflow\tools\browser_via_proxy.ps1 edge https://github.com

# 关通道
powershell -ExecutionPolicy Bypass -File D:\AIWorkflow\tools\proxy_stop.ps1
```

## 浏览器手动配置

| 项 | 值 |
|---|---|
| 代理类型 | SOCKS5 |
| 主机 | 127.0.0.1 |
| 端口 | 1080 |
| 远程 DNS | 勾选（Firefox：使用 SOCKS v5 时代理 DNS） |

- **Firefox**：设置 → 网络设置 → 手动代理 → SOCKS Host
- **Chrome/Edge**：`--proxy-server="socks5://127.0.0.1:1080"`（启动器已带）
- **系统全局**（可选）：设置 → 网络 → 代理 → 手动，地址 `127.0.0.1` 端口 `1080`（Windows 系统代理对 SOCKS 支持有限，优先用浏览器级）

## 验证

```powershell
curl.exe -x socks5h://127.0.0.1:1080 -s -o NUL -w "%{http_code}\n" https://www.google.com
# 预期 200
```

## 原理与边界

- 原理：`ssh -N -D 127.0.0.1:1080 root@47.250.138.158`，流量经服务器出网
- 只在本机监听，不对公网暴露；断开或关掉即可
- 密钥：`%USERPROFILE%\.ssh\server_deploy_key`（已有，未改）
- 服务端未装任何代理软件，未改防火墙/SSH 配置
- 断线重连：重跑 `proxy_start.ps1`（脚本会先清旧隧道）
