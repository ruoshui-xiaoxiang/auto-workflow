# FaceDetailer 画质增益实测（2026-11-04 晚）

## 结论先说

FaceDetailer 能用、便宜、不换脸、不漂画风，**但它只在"基图是插值放大/原生直出"这条路上有真收益**；
对已经过 USDU 生成式精修的图再叠一层，肉眼看不出差别，不值得叠。

用户 11-04 定：**精修与 FD 不是二选一，是两个档**。三档如下（都是 8 步，28 步无收益只是贵）：

| 档 | 链路 | 单张耗时 | 用在什么时候 | 代价 |
|---|---|---|---|---|
| 挑图 | 原生 1152×2016 → 4× 插值 | 12.2s | 批量出候选（画风分最高 0.9475） | 脸是"假清晰"，瓷面磨皮 |
| 快速成片 | 原生 1440×2560 → **FD g768 d0.55** | 27.2 + 12.0s | 批量正式版 | 🔴 额间花钿等小件会被重绘 |
| 高保真单张 | 原生 1440×2560 → **USDU 精修 0.22/1024** | 27.2 + 153.3s | 封面 / 特写 | 慢十五倍 |

FD 参数：**guide_size 768 / denoise 0.55 / steps 8 / cfg 1.0 / crop_factor 3.0 / cycle 1 / res_multistep+simple**。

## 目检（判据以此为准）

- C1 原：皮肤塑料、睫毛是色块、唇上方有一处深色杂点（插值放大带出来的缺陷）。
- C1 FD g512/g768 d0.55：睫毛成根、唇面有起伏、皮肤出现颗粒感，唇上杂点被抹掉。**真提升。**
- C1 FD g1024 d0.55：开始自己长雀斑与鼻翼腮红斑，左太阳穴出现贴回接缝（一条竖硬边），
  发际多出一串本该在脑后的珠链。身份余弦同步掉到 0.977。⇒ **guide_size 上限取 768。**
- T8 精修 + FD：六格网格里 d0.35 与 T8 原几乎分辨不出；d0.55 只是柔化了一点，
  花钿由银变蓝。MAD 6.5–8.9 说明"动了"，但动出来的是**改动**不是**增益**。⇒ **不叠。**

## 必须记的代价

FD 会把 mask 内的**装饰件一起重绘**：C1 原的额间花钿是一根竖条，FD 之后全变成金色三瓣，
g1024 d0.55 甚至改成红色。身份尺说"还是同一个人"（0.987），但小件设计变了。
要保住原装饰件，只能把 `bbox_crop_factor` 从 3.0 往下压（缩 mask）或接受改动 —— 这条本轮没测。
