# engine/comfy 模板命名说明（2026-10-21）

> 文件名里的 `fl2va` **不等于**官方 FL2VA。判模式看节点的输入槽，不看文件名。
> 官方首行四形见 `ComfyUI_H3/prompts/official_h3/base-en.txt` §2.1；G7 自 2026-10-21 起按首行识别模式。

## 模板 → 实际模式

| 文件 | 实际模式 | 判据 |
|---|---|---|
| `h3_i2v_fl2va_api.json` | **I2VA**（单首帧） | 只有 `first_frame` |
| `h3_i2v_fl2va_nolora_api.json` | **I2VA**（单首帧） | 只有 `first_frame` |
| `h3_i2v_fl2va_dual_api.json` | **FL2VA**（首尾帧） | `first_frame` + `last_frame` |
| `h3_i2v_fl2va_dual_nolora_api.json` | **FL2VA**（首尾帧） | `first_frame` + `last_frame` |
| `h3_i2v_fl2va_dual_lora.json` | **I2VA + 双 LoRA** | 只有 `first_frame`；dual 指双 LoRA，不是双端 |
| `h3_i2v_fl2va_triple_lora.json` | **I2VA + 三 LoRA** | 只有 `first_frame` |
| `h3_i2v_ref2va_api.json` | **Ref2VA**（4 图） | 走六段契约，不是三字段 |
| `h3_i2v_refvideo_api.json` | **Ref2VA + 1 参考视频** | 走六段契约 |
| `h3_relay_parent_api.json` / `h3_relay_cont_api.json` | 接力父段/续段 | 各自的 EXPT8 节点，不套本表 |

## prompt_kind 对应

| 模式 | prompt_kind | 首行 |
|---|---|---|
| I2VA | `h3_i2va` | `For the target video, at 0.00 seconds... <Picture 1> (from [Shot 1]) is fully referenced.` |
| FL2VA | `h3_fl2va` | `How the reference pictures align... Picture 1 (from Shot 1) ...; Picture 2 (from Shot N) ...`（首行里的 Picture **不带尖括号**） |
| L2VA | `h3_l2va` | `How the reference pictures align... <Picture 1> (from [Shot N]) ...` |
| T2VA | `h3_t2va` | 无首行，直接三字段 |
| Ref2VA | `h3_ref2va` | 六段，无首行 |

## 现行 yaml 的归属

- `h3_fl2va_dual_play.yaml` / `h3_fl2va_dual_clean_play.yaml` → 真首尾帧，`prompt_kind: h3_fl2va`
- `h3_fl2va_clean_play.yaml`（single）→ I2VA，`h3_i2va`
- `h3_fl2va_fight_play.yaml`（dual_lora，双 LoRA 单首帧）→ I2VA，`h3_i2va`
- `h3_i2va_video.yaml` / `h3_i2va_batch.yaml` / `h3_jimeng_shot.yaml` / `h3_one_click_movie.yaml` → I2VA
- `h3_ref2va_video.yaml` / `h3_ref2va_play.yaml` → Ref2VA 六段
